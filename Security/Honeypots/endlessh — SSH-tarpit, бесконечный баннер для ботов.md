# 🕳️ endlessh — SSH-tarpit

[**endlessh**](https://github.com/skeeto/endlessh) — не совсем honeypot, а **tarpit** («смоляная яма»): он притворяется SSH-сервером и **бесконечно медленно шлёт случайный баннер**, так и не доходя до обмена ключами. SSH-клиент бота зависает в ожидании на часы и дни. Идея — перевесить настоящий SSH на другой порт, а на 22-й поставить endlessh, чтобы сканеры и переборщики застревали здесь вместо реального сервера.

| | |
| :--- | :--- |
| Что это | SSH-tarpit (задержка ботов), не сбор данных |
| Язык/лицензия | один файл на C, Unlicense (public domain); ~8,6 тыс. звёзд |
| Особенность | до криптообмена → не нужны крипто-библиотеки; однопоточный `poll()` |
| Отличие от honeypot | команды/пароли не собирает — только держит и тратит время атакующего |

## Как работает

Баннер шлётся по одной строке с большой задержкой (`Delay`, по умолчанию 10000 мс). Один процесс на `poll()` держит до 4096 клиентов разом, расход ресурсов копеечный. Основные ключи:

```
endlessh [-46] [-d задержка_мс] [-p порт] [-l длина_строки] [-m макс_клиентов] [-f конфиг] [-s в_syslog]
```

Порт по умолчанию — 2222 (чтобы повесить на 22-й, запускать от root или дать capability). `SIGHUP` перечитывает конфиг, `SIGUSR1` печатает статистику.

## Установка по платформам

Крошечная программа на C — собирается почти везде.

| Система | Как ставить |
| :--- | :--- |
| Debian / Ubuntu | есть пакет `endlessh` (`sudo apt install endlessh`), либо `make` из исходников |
| Gentoo | сборкой из исходников (`make`), либо поискать в оверлеях (guru и т. п.) |
| Arch | в AUR (`endlessh`), либо `make` |
| Entware | реально: один `.c`-файл без зависимостей компилируется под armv7 — хороший «наказатель» для ботов прямо на роутере |

Для Entware/embedded это редкий случай, когда приманку уместно держать именно на роутере: памяти почти не ест. Переведите настоящий SSH на другой порт, а на внешний 22-й повесьте endlessh.

Есть форк **endlessh-go** (shizunge/endlessh-go) с метриками Prometheus — удобно, если хочется графиков «сколько ботов застряло».

## Чтобы не подставиться

- Это оборонительный инструмент: он **никого не атакует**, только тянет время на своём порту — законно.
- Не вешать endlessh на порт, которым реально пользуетесь: клиент-человек тоже застрянет. Сначала перенесите рабочий SSH.
- Данных об атакующих он почти не даёт — для разбора команд нужна настоящая приманка ([Cowrie](Cowrie%20%E2%80%94%20SSH-Telnet%20honeypot%20%28%D0%BF%D1%80%D0%B8%D0%BC%D0%B0%D0%BD%D0%BA%D0%B0%29%3A%20%D1%87%D1%82%D0%BE%20%D0%BB%D0%BE%D0%B3%D0%B8%D1%80%D1%83%D0%B5%D1%82%2C%20medium%20vs%20proxy%2C%20%D0%B7%D0%B0%D0%BF%D1%83%D1%81%D0%BA%20%D0%B2%20Docker%2C%20%D0%BA%D0%B0%D0%BA%20%D0%BD%D0%B5%20%D0%BF%D0%BE%D0%B4%D1%81%D1%82%D0%B0%D0%B2%D0%B8%D1%82%D1%8C%D1%81%D1%8F.md)).
