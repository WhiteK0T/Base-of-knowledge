# 🍯 Galah — веб-приманка на LLM

[**Galah**](https://github.com/0x4D31/galah) (произносится «гу-ла́») — веб-honeypot, который **не эмулирует конкретное приложение заранее**, а на лету генерирует правдоподобный HTTP-ответ (заголовки и тело) на любой входящий запрос с помощью LLM. Там, где классический веб-honeypot надо вручную настраивать под определённую CMS или уязвимость, Galah выдаёт «что-то похожее на настоящий сервер» для чего угодно.

## Как работает

- Поддерживает основных LLM-провайдеров: **OpenAI, GoogleAI, GCP Vertex AI, Anthropic, Cohere, Ollama** (Ollama — для локальной модели без оплаты по API).
- Ответы **кэшируются** на заданный срок и отдельно по каждому порту, чтобы не генерировать одно и то же и не жечь токены.
- Опционально сверяет входящие запросы с правилами **Suricata** (по методу, URI, заголовкам, кукам, телу) — поддержка ключевых слов неполная.
- Ключевое в настройке — промпт: можно менять, но нельзя убирать часть, которая требует ответа строго в формате JSON.

```bash
git clone https://github.com/0x4D31/galah.git && cd galah
go build -o bin/galah ./cmd/galah
./bin/galah -p ollama -m llama3 -u http://localhost:11434   # пример с локальной моделью
```

## Установка по платформам

| Система | Как ставить |
| :--- | :--- |
| Debian / Ubuntu / Gentoo / Arch | поставить Go (`apt`/`emerge`/`pacman install go`) и собрать бинарник, либо через Docker |
| Entware | не рекомендуется: нужен доступ к LLM, роутеру это не по силам |

## Чтобы не подставиться

- **Обязательно задайте лимиты расходов у LLM-провайдера** — иначе поток запросов превратится в «Denial of Wallet» (счёт за API).
- Автор честно предупреждает: это «проект выходного дня», приманку можно распознать (сетевой фингерпринт, задержки ответа, нестандартные ответы) — не рассчитывать на неё как на незаметную.
- Ставить в изоляции, как и любую приманку.
