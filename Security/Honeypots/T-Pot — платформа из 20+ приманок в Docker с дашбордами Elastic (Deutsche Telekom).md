# 🍯 T-Pot — платформа «всё в одном» из 20+ приманок

[**T-Pot**](https://github.com/telekom-security/tpotce) — не отдельная приманка, а целая платформа: она разворачивает **20+ honeypot'ов в Docker** на одной машине и сводит все их события в единую панель на базе Elastic Stack (Kibana), с анимированной картой атак в реальном времени. Делает её команда безопасности Deutsche Telekom; это де-факто эталон, когда нужно «поставить одну коробку и смотреть, кто и чем ломится по всему периметру».

| | |
| :--- | :--- |
| Что это | многоприманочная платформа на Docker Compose |
| Язык/лицензия | Shell, GPL-3.0; ~9,7 тыс. звёзд, активен |
| Архитектуры | amd64 и arm64 (в т. ч. Raspberry Pi 4 8 ГБ) |
| Свежий стабильный | 24.04.1 (декабрь 2024) |

## Что внутри

Под капотом — готовые образы известных приманок (Cowrie, Dionaea, Conpot, [Galah](Galah%20%E2%80%94%20%D0%B2%D0%B5%D0%B1-%D0%BF%D1%80%D0%B8%D0%BC%D0%B0%D0%BD%D0%BA%D0%B0%20%D0%BD%D0%B0%20LLM%2C%20%D0%BE%D1%82%D0%B2%D0%B5%D1%87%D0%B0%D0%B5%D1%82%20%D0%BD%D0%B0%20%D0%BB%D1%8E%D0%B1%D0%BE%D0%B9%20HTTP-%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81.md) и десятки других) плюс инструменты анализа: Kibana-дашборды, карта атак, CyberChef, Elasticvue, Spiderfoot. Поддерживаются и **LLM-приманки** (ответы через Ollama или ChatGPT). Данные по желанию можно отдавать в сообщество (opt-in HPFEEDS).

Режимы развёртывания:
- **Standard / Hive** — всё на одной машине.
- **Distributed** — центральный «улей» (hive) собирает события с удалённых сенсоров.

## Требования и установка

T-Pot ставится на **отдельную выделенную машину или ВМ** — он занимает почти все порты и не рассчитан на соседство с другими сервисами.

- **Минимум:** 8–16 ГБ RAM, 128 ГБ диска, исходящий интернет без фильтрации.
- **База:** один из поддерживаемых дистрибутивов (Debian 12, Ubuntu 22.04/24.04, и др. из списка `Choose your distro`), установленный минимально, с SSH.

```bash
sudo apt install curl                         # если ещё нет
# запуск от обычного пользователя из $HOME:
env bash -c "$(curl -sL https://github.com/telekom-security/tpotce/raw/master/install.sh)"
```

Про платформы владельца: T-Pot — это не пакет для `emerge`/`pacman`/`opkg`. На **Gentoo, Arch** и тем более на роутере с **Entware** его разворачивают не напрямую, а в отдельной виртуальной машине с поддерживаемой базой (Debian/Ubuntu). На слабом железе (роутер, Pi без 8 ГБ) полноценный T-Pot не поднять — там уместнее одиночная лёгкая приманка ([OpenCanary](OpenCanary%20%E2%80%94%20%D0%BB%D1%91%D0%B3%D0%BA%D0%B8%D0%B5%20%D1%81%D0%B5%D1%82%D0%B5%D0%B2%D1%8B%D0%B5%20%D0%BF%D1%80%D0%B8%D0%BC%D0%B0%D0%BD%D0%BA%D0%B8-%D0%BB%D0%BE%D0%B2%D1%83%D1%88%D0%BA%D0%B8%20%D0%B4%D0%BB%D1%8F%20%D0%B2%D0%BD%D1%83%D1%82%D1%80%D0%B5%D0%BD%D0%BD%D0%B5%D0%B9%20%D1%81%D0%B5%D1%82%D0%B8%20%28Thinkst%29.md), [qeeqbox/honeypots](honeypots%20%28qeeqbox%29%20%E2%80%94%2030%20%D0%BF%D1%80%D0%B8%D0%BC%D0%B0%D0%BD%D0%BE%D0%BA%20%D0%BF%D0%BE%20%D0%BF%D1%80%D0%BE%D1%82%D0%BE%D0%BA%D0%BE%D0%BB%D0%B0%D0%BC%20%D0%BE%D0%B4%D0%BD%D0%B8%D0%BC%20%D0%BF%D0%B0%D0%BA%D0%B5%D1%82%D0%BE%D0%BC%20Python.md)).

## Чтобы не подставиться

- Ставить **только в изолированный сегмент**, из которого не добраться до продакшена; на борту — никаких реальных секретов.
- Платформа намеренно выставляет наружу много уязвимых на вид сервисов, поэтому доступ к самой панели управления (порт 64294/64297) закрывать и держать за VPN.
- Собранные образцы вредоноса — разбирать только в песочнице.
