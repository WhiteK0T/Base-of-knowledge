# 🍯 Dionaea — приманка для захвата вредоноса

[**Dionaea**](https://github.com/DinoTools/dionaea) — приманка, заточенная не на логи брут-форса, а на **сбор образцов вредоносного ПО**. Она притворяется уязвимыми сетевыми службами, даёт эксплойту «отработать» и перехватывает то, что он пытается загрузить, сохраняя сам файл для анализа. Классика для изучения сетевых червей и ботнетов; наследник старого nepenthes.

| | |
| :--- | :--- |
| Что это | low/medium honeypot для захвата малвари |
| Язык/лицензия | C + встроенный Python, GPLv2+ |
| Статус | ~800 звёзд, обновляется редко (последние правки 2024), но остаётся стандартом; входит в T-Pot |
| Детект шеллкода | через libemu; поддержка IPv6 и TLS |

## Что эмулирует

Протоколы-приманки: **SMB** (главная цель — именно по нему шли EternalBlue и черви), FTP, HTTP, MSSQL, MySQL, SIP (VoIP), TFTP, UPnP, MQTT, epmap, PPTP, memcache. Пойманные образцы складываются на диск; события можно выгружать через **hpfeeds**, в JSON, SQLite и в **fail2ban** ([Network/Fail2ban](../../Network/Fail2ban)).

## Установка по платформам

Dionaea собирается из исходников (C с кучей зависимостей), поэтому на практике её почти всегда запускают в контейнере.

| Система | Как ставить |
| :--- | :--- |
| Debian / Ubuntu | официальная инструкция собирает из исходников (`cmake`, libemu, libev, Python-dev); подробности в документации |
| Gentoo / Arch | сборка из исходников теми же шагами (зависимостей много — закладывайте время) |
| Любая с Docker | проще всего: готовый образ `dinotools/dionaea` или в составе [T-Pot](T-Pot%20%E2%80%94%20%D0%BF%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D0%B0%20%D0%B8%D0%B7%2020%2B%20%D0%BF%D1%80%D0%B8%D0%BC%D0%B0%D0%BD%D0%BE%D0%BA%20%D0%B2%20Docker%20%D1%81%20%D0%B4%D0%B0%D1%88%D0%B1%D0%BE%D1%80%D0%B4%D0%B0%D0%BC%D0%B8%20Elastic%20%28Deutsche%20Telekom%29.md) |
| Entware | неприменимо — слишком тяжёлая сборка для роутера |

## Чтобы не подставиться

- **Всё пойманное = живой вредонос.** Не запускать, хранить и разбирать строго в изолированной песочнице.
- Приманку намеренно эксплуатируют, поэтому держать её в сегменте без доступа к продакшену.
- Самплы по желанию уходят в hpfeeds-сообщество — проверьте, что согласны этим делиться.
