# 🧬 TrID — определение типа файла по бинарной сигнатуре

**TrID** ([mark0.net/soft-trid-e.html](http://mark0.net/soft-trid-e.html), автор **Marco Pontello**) — утилита, которая определяет реальный формат файла **не по имени/расширению, а по бинарной сигнатуре**: сравнивает начало и структуру файла с большой базой шаблонов и выдаёт ранжированный по вероятности список кандидатов. Полезно, когда расширение потеряно, подделано или файл принесли «как есть» — типичная задача DFIR-триажа и разбора подозрительных вложений.

На 27.09.2026: версия **v2.48** (03.05.2026), база **22 291 формат** (`TrIDDefs.TRD`, ~2.7 МБ, обновляется). Пост описал суть верно; ниже — то, что важно знать перед использованием и чего в посте нет.

> [!warning] Это freeware, а не open-source
> TrID — **бесплатная, но закрытая** программа: «free for personal / non-commercial use». Исходников нет, коммерческое использование не разрешено. Это отличает её от большинства инструментов в этом хранилище. Для рабочих/коммерческих задач и там, где нужен аудируемый код, — смотри FOSS-альтернативы (`file`/libmagic) ниже.

## 🔬 Как работает и как выглядит вывод

- **База сигнатур** (`TrIDDefs.TRD`) — набор шаблонов «какие байты и в какой структуре характерны для формата». Бинарь без этой базы бесполезен: качать их надо **вместе** и держать актуальными.
- Чем больше определений, тем точнее — отсюда упор в посте на «постоянно обновляется».
- Вывод — **проценты уверенности** по каждому кандидату:
  ```
  trid unknown_file
  70.7% (.DOC) Microsoft Word document
  16.7% (.) Generic OLE2 / Multistream Compound
  ...
  ```
  Важно: TrID даёт **вероятностную догадку с ранжированием**, а не однозначный вердикт. Первый кандидат — самый правдоподобный, но смотреть стоит на весь список и на разрыв в процентах.
- **TrIDScan** — отдельный модуль: скармливаешь ему пачку файлов известного формата, он **сам генерирует новое определение**. То есть базу можно расширять под свои экзотические форматы — редкая для таких утилит возможность.

## ⚠️ Практический нюанс на Linux: нативная сборка устарела

Это в посте не сказано, а на практике мешает:

| Вариант | Версия | Комментарий |
| :--- | :--- | :--- |
| Windows x86-64 | **v2.48** (актуальная) | основная поддерживаемая сборка |
| Нативный Linux x86 / x86-64 | **v2.24** (старая) | нативные Linux-бинарники давно не обновлялись |
| **Мультиплатформенная Python-версия** | **v2.48** | ⬅ **способ получить актуальный TrID на Linux**: чистый Python + та же `TrIDDefs.TRD` |
| Online TrID | v2.48 | в браузере, но см. предупреждение о приватности ниже |

**Вывод для Linux-хостов:** ставить не старый нативный бинарь, а **Python-версию v2.48** с актуальной базой.

## 🔒 Приватность: онлайн-версию — не для чувствительных файлов

Online TrID удобна, но **файл уходит на сервер mark0.net**. Подозрительные образцы, малварь, документы с приватными данными через неё гонять **нельзя** — только локальный бинарь/Python-версия. Для «обезвреживания» самих опасных документов есть отдельный инструмент — [Dangerzone](../Dangerzone%20%28Freedom%20of%20the%20Press%29%20%E2%80%94%20%D0%BE%D0%B1%D0%B5%D0%B7%D0%B2%D1%80%D0%B5%D0%B6%D0%B8%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5%20%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D1%8B%D1%85%20%D0%B4%D0%BE%D0%BA%D1%83%D0%BC%D0%B5%D0%BD%D1%82%D0%BE%D0%B2%20%D0%B2%20%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D1%8B%D0%B9%20PDF%20%28CDR%2C%20%D0%BF%D0%B5%D1%81%D0%BE%D1%87%D0%BD%D0%B8%D1%86%D0%B0%29.md).

## 🆚 TrID против `file` (libmagic) — что когда

На всех системах владельца уже есть штатный **`file`** (пакет `sys-apps/file`, FOSS, движок libmagic). Он определяет тип тоже по «магическим» байтам. Разница:

| | `file` (libmagic) | TrID |
| :--- | :--- | :--- |
| Лицензия | **FOSS** | freeware, closed |
| Формат вывода | одна строка-вердикт | **ранжирование по вероятности** |
| Число форматов | сотни правил | **~22 000 определений** |
| Экзотика/подделки | ловит частые | сильнее на редких/экзотических форматах |
| Свои сигнатуры | правишь magic-файлы вручную | **TrIDScan обучает автоматически** |
| Везде из коробки | да | нет, ставить отдельно + база |

**Практика:** для быстрой проверки — `file unknown` (мгновенно, везде). Если `file` сказал «data» или ответ подозрителен — прогнать через TrID: 22k форматов и вероятности часто решают там, где libmagic пасует. Инструменты **дополняют** друг друга. На Windows аналогичную нишу закрывает DiE (Detect It Easy).

## 🖥️ Установка/запуск на системах владельца

TrID — просто распаковываемый бинарь (или Python-скрипт) + `TrIDDefs.TRD` рядом; менеджерами пакетов обычно не ставится.

| Система | Как | Нюанс |
| :--- | :--- | :--- |
| **Gentoo** (основная) | скачать **Python-версию v2.48** + база; либо старый нативный. `file` — `emerge sys-apps/file` (уже стоит) | нативный бинарь только v2.24; для актуального — Python |
| **Debian / Ubuntu** | так же (Python-версия + база). В репозиториях самой TrID нет | некоторые дистрибутивы клали старый `trid` в пакеты — версия древняя |
| **Arch** | AUR: `trid` + `tridupdate` для базы; либо Python-версия вручную | AUR-пакет может отставать — проверить версию базы |
| **Entware / RT-AX56U** (armv7) | ➖ нативной ARM-сборки нет. Теоретически — Python-версия под `python3` из Entware + `TrIDDefs.TRD`, но проверить, что скрипт заведётся | на роутере практической нужды в TrID почти нет; для определения типа хватит `file` из Entware (`opkg install file`) |

## 🧭 Когда доставать TrID (кейсы)

- расширение **потеряно или подделано** (`.jpg`, который на деле PE-исполняемый);
- **карвинг**: из дампа/флешки вытащили безымянные куски — что это;
- **триаж вложений/малвари** — быстро понять природу файла до глубокого анализа (локально, не онлайн!);
- редкий/старый/игровой/проприетарный формат, который `file` не знает.
