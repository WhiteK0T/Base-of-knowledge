# 🧬 REA — Reverse Engineer Anything (morluto)

**REA** ([morluto/rea](https://github.com/morluto/rea), сайт [rea.tools](https://rea.tools/), npm-пакет [`rea-agents`](https://www.npmjs.com/package/rea-agents), MIT) — это **MCP-сервер и CLI для реверс-инжиниринга**, которые подключают ИИ-агента к инструментам анализа: дизассемблерам и декомпиляторам (Hopper, Ghidra, IDA), разбору JavaScript/Electron, .NET, APK, прошивок, трафика и сайтов.

Типичный сценарий из README: «вижу в приложении функцию, хочу понять, как она устроена, вплоть до бинарника» — агент исследует программу без исходников, объясняет механизм **с уликами** и помогает написать свою реализацию. Анализ идёт **локально**; модели уходят только результаты инструментов.

**Состояние на 21.10.2026:**
- **Версия и разработка:** версия 6.7.0, проект ведётся с апреля 2026, очень активно (коммиты ежедневно, основной автор — morluto).
- **Популярность:** ~347 тыс. звёзд, ~87 тыс. форков, ~1,5 тыс. открытых issue.
- **Документация:** README переведён на 20 языков, включая русский.
- **Важно о копиях:** README прямо предупреждает, что официальные источники — только `morluto/rea`, `rea.tools` и npm `rea-agents`. Похожее название репозитория или скопированный README — не признак официальности.

## Как устроено

1. **Связь с агентом.** Агент вызывает инструменты REA через MCP: просмотреть цель, найти функцию, проследить вызовы, получить псевдокод.
2. **Что возвращает REA.** Находки **с уликами и ограничениями** — что видно, что выведено, что неизвестно. По ним агент задаёт уточняющие вопросы, объясняет поведение или пишет и тестирует реализацию.
3. **CLI.** Те же сценарии доступны из терминала (`rea …`), включая JSON-вывод для скриптов.
4. **Скилл.** Вместе с MCP ставится «workflow-скилл» `reverse-engineer-anything` с инструкциями по расследованию.

**Что можно анализировать** (сокращённо по таблице README):

| Цель | Что возвращает | Что нужно |
| :--- | :--- | :--- |
| Нативные бинарники | псевдокод, ассемблер, строки, символы, вызовы, ссылки | **Hopper, Ghidra или IDA**; офлайн — GNU objdump или Rizin |
| JavaScript / Electron | модули, импорты, source maps, маршруты, IPC, связи с нативными аддонами | Node.js; на Linux — `ps` из procps |
| Go / Rust | версия компилятора, модули, crates и их версии | встроено, сам Go не нужен |
| .NET | метаданные, CIL, нативные зависимости, сравнение сборок | ничего (только статика) |
| Android APK / устройство | манифест, классы, декомпиляция; пакеты, логи, дампы, скриншоты | JADX + JDK; `adb`; Apktool |
| Flutter, Unity IL2CPP, Godot PCK | хэш Dart-снапшота, имена типов и методов, содержимое архивов | встроено |
| WASM, SQLite, EVM-байткод | секции и WAT, схема и строки, селекторы функций | WABT 1.0.42, Node 24.15+ |
| Прошивки | регионы, распаковка, передача в нативный анализ | Binwalk / Unblob на Linux |
| Трафик, HAR, pcap, логические сигналы | запросы, DNS, SNI, протоколы, декодеры | tshark 4.x, mitmdump, sigrok-cli |
| Сайты | структура, скрипты, сеть, скриншоты | браузер семейства Chrome |
| Процессы, крэши Linux | вывод, взаимодействие, файловые эффекты; регистры и сигналы из core | PTY; pwntools, GDB/pwndbg |
| Модели | метаданные GGUF / safetensors, тензоры | встроено |

**Движки нативного анализа:**
- **Hopper** — коммерческий, у демо-версии ограничения производителя. Установщик REA ставит его на macOS 12+, Ubuntu 24.04+, Fedora 41+ и 64-битный Arch.
- **Ghidra 12.1.x** с полной JDK 21+ — на Linux x64/arm64 и macOS, на Windows экспериментально. Адаптер даёт 26 операций только на чтение, плюс переименование и комментарии, которые живут до закрытия сессии.
- **IDA, JEB, Kuna** — подключаются, если у вас есть их установки.

REA **не выдаёт лицензий** на коммерческие инструменты. Взломанные копии и чужие ключи README прямо запрещает.

**Витрина проекта** ([showcase](https://rea.tools/showcase/)):
- **DX-Ball:** восстановлен расчёт панорамы звука из x86 — реконструкция проходит 3205 тестов и байт-в-байт воспроизводит 63 байта исходной функции.
- **Notion:** путь буфера обмена через preload и IPC Electron.
- **TH04:** расчёт кольца пуль из 16-битной DOS-игры для PC-98.

## Установка и подключение к агенту

```bash
# нужен Node.js 22.19+ / 24.11+ / 26+ и npm
npx rea-agents setup                       # интерактивно: выбор агентов, план изменений, подтверждение
rea setup --client claude_code --dry-run   # только показать план (после npm i -g rea-agents)
npm install --global rea-agents && rea --help
rea doctor --json                          # готовность движков и агентов
rea update                                 # обновление (релизы частые, в них много исправлений)
```

**Что делает `setup`.** Добавляет в выбранные агенты (Claude Code, Codex, Cursor, Gemini CLI, Grok Build и др.) MCP-сервер `rea` и устанавливает скилл.

Сделано аккуратно:
- **План до записи:** перед записью показывает точные пути, внешние источники и команды пакетных менеджеров.
- **Бэкапы:** старая конфигурация сохраняется в `.rea.backup`, сторонние записи и комментарии не трогаются.
- **Без молчаливых добавлений:** новые обнаруженные агенты по умолчанию **не выбраны**.
- **Hopper:** ставится только после отдельного подтверждения.
- **Флаги:** `--skill=false` — без скилла, `--dry-run` — только план, без записи.

**Пример запроса агенту:**

```text
Разберись, как работает поиск в приложении Notes, покажи улики и сделай похожую функцию в моём проекте.
```

**Без агента, из терминала:**

```bash
npx -y rea-agents@latest analyze-javascript-application /abs/path/to/app --json
```

## Цена в контексте

REA — **большой MCP-сервер**: в версии 6.5.0 было **207 инструментов**, а их JSON-схемы занимают **3,35 МБ** (замер в бенчмарке leanrea). Сколько это стоит агенту, зависит от того, грузит ли он схемы сразу.

| Режим | Расход |
| :--- | :--- |
| Claude Code с **отложенной загрузкой инструментов** (tool search, по умолчанию) | ~+3,5 тыс. токенов на пустой запрос — почти бесплатно |
| Tool search **выключен** — например, Claude Code с `ANTHROPIC_BASE_URL` на стороннем Anthropic-совместимом API | все схемы в каждом запросе. Документация REA: 172 инструмента ≈ 496 КБ ≈ **120 тыс. токенов**, с `compact` ≈ 290 КБ ≈ 68 тыс. Замер leanrea: **+369 тыс. токенов и $1,60 за «ответь OK»** |

**Что делать, если tool search недоступен** (рекомендации из [client-configuration](https://github.com/morluto/rea/blob/main/docs/client-configuration.md)):
- добавить `"REA_MCP_INPUT_SCHEMA_PROFILE": "compact"` в `env` записи `mcpServers.rea` в `~/.claude.json`;
- указать реальный размер окна через `CLAUDE_CODE_MAX_CONTEXT_TOKENS`;
- включить `ENABLE_TOOL_SEARCH=true`, если эндпоинт поддерживает `tool_reference`.

Иначе схемы заново заполняют контекст после каждого сжатия, и автосжатие начинает работать вхолостую.

**REA против leanrea.** В [бенчмарке leanrea](https://github.com/aicodeking/leanrea/blob/main/bench/BENCHMARK.md) — Sonnet 5.5, macOS, 4 точечные задачи, без Ghidra и Hopper — REA дала **75/75 баллов**, но была медленнее и дороже. Скилл leanrea на 8 КБ с голыми CLI-утилитами набрал 74/75, на 38 % быстрее и на 35 % дешевле.

Как выбирать:
- **REA сильна** там, где нужен **настоящий декомпилятор** с сессией (Hopper, Ghidra, IDA), большой охват форматов (IL2CPP, Godot, EVM, сигналы, Android-устройство) и структурированные улики.
- **leanrea** закрывает быстрые вопросы, на которые отвечают `strings`, `nm`, `asar` и `go version -m`.

Подробнее — в [заметке про leanrea](leanrea%20%28aicodeking%29%20%E2%80%94%20%D1%81%D0%BA%D0%B8%D0%BB%D0%BB%20%D1%80%D0%B5%D0%B2%D0%B5%D1%80%D1%81-%D0%B8%D0%BD%D0%B6%D0%B8%D0%BD%D0%B8%D1%80%D0%B8%D0%BD%D0%B3%D0%B0%20%D0%BD%D0%B0%208%20%D0%9A%D0%91%20%D0%B2%D0%BC%D0%B5%D1%81%D1%82%D0%BE%20MCP%20REA%20%28%D0%B4%D0%B5%D1%88%D0%B5%D0%B2%D0%BB%D0%B5%20REA%2C%20%D0%BD%D0%BE%20%D0%BD%D0%B5%20%D0%B3%D0%BE%D0%BB%D0%BE%D0%B9%20%D0%BC%D0%BE%D0%B4%D0%B5%D0%BB%D0%B8%3B%20%D0%BF%D0%BE%D0%B4%20macOS%29.md).

## 🐧 По системам

REA работает на любом Linux, где есть apt, dnf или pacman. **Обязательно для Linux:** `ps` из **procps** — без него не запустятся Ghidra, JADX, инструменты прошивок и анализ JavaScript/Electron.

| Система | Node.js и procps | Ghidra 12.1 + JDK 21 | Hopper | Прочее (по задаче) |
| :--- | :--- | :--- | :--- | :--- |
| **Gentoo** (OpenRC) | `net-libs/nodejs` (22.x и новее есть), `sys-process/procps` | в дереве нет → архив с GitHub, JDK `dev-java/openjdk:21`, путь сохранит `rea setup` | автоустановщик не поддерживает → поставить вручную и указать `HOPPER_LAUNCHER_PATH` | `app-misc/binwalk`, `net-analyzer/wireshark`, `dev-util/rizin` |
| **Debian 13** | в репозитории Node 20 — **мало**, нужен NodeSource или `nvm`; `procps` | архив с GitHub, `openjdk-21-jdk` | автоустановщик — только Ubuntu 24.04+, на Debian вручную | `binwalk`, `tshark`, `apktool`, `wabt` |
| **Ubuntu 24.04+** | NodeSource или `nvm`; `procps` | архив с GitHub, `openjdk-21-jdk` | **автоустановка** через `rea setup` | как в Debian |
| **Arch** | `pacman -S nodejs npm procps-ng` | `pacman -S ghidra` (тянет JDK) | **автоустановка** | `binwalk`, `wireshark-cli`, `jadx`, `wabt`, `rizin` |
| **Entware** (RT-AX56U) | неприменимо: Node в репозитории 18.x, нет JDK и Ghidra, 512 МБ RAM | — | — | — |

## Право и безопасность

- **Позиция проекта** ([DISCLAIMER.md](https://github.com/morluto/rea/blob/main/DISCLAIMER.md)):
  - **Для чего:** законные исследования, анализ malware и инцидентов, поиск уязвимостей с ответственным раскрытием, CTF и обучение, совместимость, сохранение старого ПО, аудит своего или разрешённого ПО.
  - **С чем проект не помогает и закрывает такие запросы:** обход DRM, проверок лицензий и анти-читов; читы и вмешательство в онлайн-сервисы; обход авторизации; копирование проприетарного кода и ресурсов; обход политик ИИ-провайдеров.
- **Закон:** в России декомпиляция ради совместимости допускается ст. 1280 ГК РФ в узких рамках, в ЕС — ст. 6 Директивы 2009/24/EC. Лицензия анализируемой программы может запрещать больше.
- **Технически:**
  - Анализ локальный, но **результаты уходят провайдеру модели** — не разбирайте так чужие секреты и конфиденциальные сборки на облачной модели.
  - Динамический анализ (захват процесса, Android-устройство, сайт) **запускает цель с вашими правами** — подозрительное разбирайте в ВМ без сети.
