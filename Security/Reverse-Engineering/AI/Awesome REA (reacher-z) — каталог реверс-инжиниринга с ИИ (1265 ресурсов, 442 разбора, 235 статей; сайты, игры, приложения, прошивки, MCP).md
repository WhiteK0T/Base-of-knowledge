# 🧭 Awesome REA (reacher-z) — каталог реверс-инжиниринга с ИИ

[**Awesome REA**](https://github.com/reacher-z/Awesome-REA) — курируемый каталог инструментов, разборов и научных работ по реверс-инжинирингу сайтов, игр, приложений, нативных программ, прошивок и протоколов, с упором на работу с ИИ-агентами. Описания на английском и китайском, есть сайт [awesomerea.org](https://awesomerea.org/) с поиском и фильтрами. Заметка по посту [«Не баг, а фича»](https://t.me/bugnotfeature/28886) от 7 ноября 2026 года, сверена с репозиторием и его данными.

## 2. Как отбирают

Каталог называет себя «source-reviewed»: каждого кандидата смотрят по исходникам, а решение и причину записывают в данные. Пример отказа: мод для GTA III, включающий радио во всех машинах, исключён с пометкой «game-mod-no-re» — в репозитории нет никакого анализа, только сам мод. Поиск кандидатов и проверку ссылок выполняют автоматические workflow, решения записываются отдельно.

- **«Всё поделено по целям: сайты, игры, приложения, программы, прошивки, протоколы, MCP и агенты»** — да, это разделы каталога.
- **«Перенесли на ПК Zelda, Super Mario 64, Metroid Prime и inFAMOUS Second Son»** — эти проекты в каталоге есть:
  - Zelda — декомпиляция Ocarina of Time (`zeldaret/oot`) и нативный порт на её основе Ship of Harkinian; Majora's Mask портирован через статическую перекомпиляцию (Zelda 64: Recompiled), без полной декомпиляции исходников;
  - Super Mario 64 — декомпиляция `n64decomp/sm64`, собирающая побайтно тот же ROM;
  - Metroid Prime — побайтная декомпиляция PrimeDecomp, переписанный на её основе движок Metaforce и сделанный с помощью ИИ нативный порт;
  - inFAMOUS Second Son — проект нативного порта на ПК.
- **«Движок GTA III собрали заново с открытым кодом».** Речь, видимо, о re3 — но его в каталоге нет, записи про GTA III там только исключённые моды. Репозитории re3 в 2021 году удалили с GitHub по жалобе Take-Two.

## 4. Право

- **Допустимость реверс-инжиниринга** зависит от лицензии программы и законов страны. Где-то декомпиляция разрешена для совместимости, где-то её запрещает пользовательское соглашение. Каталог перечисляет проекты, а не даёт разрешения.
- **Игровые декомпиляции и порты** обычно не содержат ни игры, ни её ресурсов. Для сборки нужна собственная копия оригинала, а распространение образов игр — нарушение авторских прав.
- **Анализ вредоносов и своего ПО** — классическое законное применение этих инструментов. Часть записей каталога, например MCP для отладчиков и дизассемблеров, ровно для этого.
