# 🔧 ЭСУД 21179 — система управления двигателем Lada Vesta 1.8

**ЭСУД 21179** — электронная система управления двигателем ВАЗ-21179 (1,8 л, 16 клапанов, 122 л.с.) на Lada Vesta и XRAY. Главное отличие от 1,6-литрового 21129 — **регулировка фаз впускного распредвала (VVT)** вместо системы изменения длины впускного коллектора.

Заметка сверена с заводской технологической инструкцией: [ТИ 3100.25100.12056](%D0%A2%D0%98%203100.25100.12056%20%E2%80%94%20%D0%AD%D0%A1%D0%A3%D0%94%2021129%20%D0%B8%2021179%20Lada%20Vesta%20%D1%81%20%D0%BA%D0%BE%D0%BD%D1%82%D1%80%D0%BE%D0%BB%D0%BB%D0%B5%D1%80%D0%BE%D0%BC%20%D0%9C86%2C%20%D1%83%D1%81%D1%82%D1%80%D0%BE%D0%B9%D1%81%D1%82%D0%B2%D0%BE%20%D0%B8%20%D0%B4%D0%B8%D0%B0%D0%B3%D0%BD%D0%BE%D1%81%D1%82%D0%B8%D0%BA%D0%B0%20%28%D1%82%D0%B5%D1%85%D0%BD%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B0%D1%8F%20%D0%B8%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%86%D0%B8%D1%8F%20%D0%90%D0%B2%D1%82%D0%BE%D0%92%D0%90%D0%97%2C%20PDF%29.md) (раздел 3 — особенности ЭСУД 21179).

## 1. Как устроена

Три части:

1. **Датчики** — сообщают контроллеру состояние двигателя и автомобиля.
2. **Контроллер (ЭБУ)** — по сигналам датчиков определяет режим (пуск, холостой ход, нагрузка, торможение двигателем) и рассчитывает, когда и сколько подать топлива, когда дать искру, насколько открыть дроссель и как повернуть распредвал.
3. **Исполнительные устройства** — выполняют команды контроллера.

### Датчики

| Датчик | Что измеряет |
| :--- | :--- |
| **Положения коленчатого вала (ДПКВ)** | обороты и положение коленвала по задающему диску — основа синхронизации впрыска и зажигания |
| **Фаз** | положение впускного распредвала: для определения такта в первом цилиндре и **для работы VVT** — по нему контроллер следит, на какой угол повернул вал фазорегулятор |
| **Давления и температуры воздуха (ДДТВ)** | давление (разрежение) и температура воздуха во впускном коллекторе; по ним контроллер рассчитывает количество поступающего воздуха |
| **Температуры охлаждающей жидкости (ДТОЖ)** | температура двигателя: обогащение на холодном, обороты ХХ, вентилятор |
| **Положения педали акселератора** (электронная педаль, два канала) | желание водителя: какой нужен крутящий момент |
| **Положения дроссельной заслонки** (два канала, в электроприводном дроссельном патрубке) | фактическое открытие дросселя |
| **Кислорода до и после нейтрализатора** | состав смеси (управляющий) и эффективность катализатора (диагностический) |
| **Детонации** | детонацию — контроллер уменьшает угол опережения в нужном цилиндре |
| **Скорости** (сигнал по CAN от ABS) | скорость автомобиля |

### Контроллер

- Управляет форсунками, катушками зажигания, дроссельным патрубком с электроприводом, клапаном фазорегулятора (КПРВ), нагревом датчиков кислорода, клапаном продувки адсорбера, реле (главное, бензонасоса, вентилятора, стартера).
- Работает как часть **иммобилайзера**: обменивается кодами с центральным блоком кузовной электроники (ЦБКЭ) и без правильного ответа не даёт завести двигатель.
- Ведёт **самодиагностику**: при неисправности записывает код ошибки, зажигает лампу Check Engine и при необходимости переходит в аварийный режим.
- Обменивается данными с другими блоками (ABS, панель приборов, ЦБКЭ) по **шине CAN**; по ней же идёт диагностика через колодку OBD.
- **Расположение на Весте** — в моторном отсеке, на левой опоре стойки передней подвески.

### Исполнительные устройства

| Устройство | Назначение |
| :--- | :--- |
| **Форсунки** (4 шт.) | впрыск во впускной коллектор перед клапанами. Обычно — синхронно, один впрыск на цикл каждого цилиндра; на пуске и при резком нажатии педали — дополнительные асинхронные впрыски |
| **Дроссельный патрубок с электроприводом** | дозирует воздух, в том числе держит обороты ХХ (отдельного регулятора ХХ нет) |
| **Катушки зажигания** — **четыре индивидуальные**, по одной на свечу | |
| **Клапан регулирования положения распредвала (КПРВ)** | управляет маслом в фазорегуляторе |
| **Нагреватели датчиков кислорода** | быстро выводят датчики на рабочую температуру |
| **Клапан продувки адсорбера** | отсасывает пары бензина из адсорбера в двигатель |
| **Реле**: главное, бензонасоса, вентилятора, стартера | |

## 2. Особенности ЭСУД 21179 (фазорегулятор)

- На 21179 **нет системы изменения длины впускного коллектора**, как на 21129: модуль впуска без пневмопривода заслонок и без клапана управления ими.
- Вместо неё — **фазорегулятор впускного распредвала**: гидравлический механизм из статора (на шкиве распредвала) и ротора (на его наконечнике) с масляными камерами между ними. Подавая масло в одни камеры и сливая из других, система поворачивает распредвал относительно шкива.
- **КПРВ** — четырёхканальный гидроэлектрический клапан: подвод масла, сброс и две рабочие линии к фазорегулятору. Сопротивление обмотки — **8 ± 0,5 Ом при 20 °C**.
- Контроллер меняет фазу впускных клапанов в зависимости от оборотов и нагрузки: это улучшает наполнение цилиндров, тягу на разных оборотах и снижает токсичность.
- Свои коды ошибок: **P0011, P0012, P0016** (положение распредвала и рассогласование), **P0075–P0077** (цепь КПРВ).

> [!tip] От чего зависит работа VVT
> Фазорегулятор работает на моторном масле, поэтому важны **уровень, вязкость и свежесть масла**, чистота КПРВ и его сетчатого фильтра, а также правильная установка ремня ГРМ. С этого начинают при ошибках P0011/P0012/P0016.

## 3. Контроллеры

Все контроллеры для 21179 на Весте — производства **«Итэлма»**:

| Контроллер | Где применяется |
| :--- | :--- |
| **М86** | ранние Vesta и XRAY 1.8 с VVT; именно для него написана ТИ 3100.25100.12056 |
| **M74.9 / M74.91** | Vesta нового поколения («Веста Техно» по базе chiptuner.ru, 2023–2024 и новее). Например, **8450047190** — «Веста Техно 1.8MT E5 21179», 8450043733 и 8450044271 — «Веста Техно E5 1.8L 16V 21179» |

Оба поколения — Евро-5, с электронным дросселем и обменом по CAN. Схемы и назначение контактов у М86 и M74.9 **разные**: при работе с проводкой берите распиновку именно своего блока (M74.9 — в разделе 4). Номер контроллера и прошивки видно в OpenDiag на вкладке «Информация».

## 5. На что обратить внимание

- **Катушки зажигания и выходы контроллера.** По опыту владельцев, затянутая замена свечей (большой зазор, изношенные электроды) нагружает катушки и выходы контроллера, которые ими управляют. Свечи — по регламенту.
- **Жгуты проводки** в моторном отсеке могут перетираться о кронштейны — при плавающих ошибках по датчикам осматривайте их.
- **Масло**: у 21179 встречается заметный расход масла, а от уровня масла зависит фазорегулятор — проверяйте уровень регулярно.
- **Ремень ГРМ**: при его обрыве клапаны 21179 встречаются с поршнями.
- **Диагностика**: коды ошибок и живые параметры читаются через колодку OBD адаптером ELM327 — см. заметку [нормальные параметры двигателя 21179](Lada%20Vesta%20SW%20Cross%201.8%20MT%20%E2%80%94%20%D0%BD%D0%BE%D1%80%D0%BC%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B5%20%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B%20%D0%B4%D0%B2%D0%B8%D0%B3%D0%B0%D1%82%D0%B5%D0%BB%D1%8F%2021179%20%D1%87%D0%B5%D1%80%D0%B5%D0%B7%20ELM327%20%28OpenDiag%29%2C%20%D1%80%D0%B0%D0%B7%D0%B1%D0%BE%D1%80%20%D0%B7%D0%B0%D0%BC%D0%B5%D1%80%D0%BE%D0%B2.md).
