# 📕 ТИ 3100.25100.12056 — ЭСУД Lada Vesta с контроллером М86: устройство и диагностика

Для 21179 с контроллером **M74.9** (Vesta с 2023 года) официальная ТИ в открытом доступе не найдена — см. раздел «Что с M74.9» ниже.

## ⚙️ Раздел 3: чем ЭСУД 21179 отличается от 21129

- **Нет системы изменения длины впускного коллектора**: модуль впуска без пневмопривода заслонок и без электромагнитного клапана управления ими.
- **Есть регулировка фаз впускного распредвала (VVT)**: гидравлический фазорегулятор (статор на шкиве распредвала, ротор на его наконечнике, между ними масляные камеры).
- Контроллер управляет фазорегулятором через **клапан регулирования положения распредвала (КПРВ)**, а положение вала определяет по **датчику фаз**. КПРВ — четырёхканальный гидроэлектрический клапан (подвод масла, сброс, две рабочие линии). **Сопротивление обмотки КПРВ — 8 ± 0,5 Ом при 20 °C**.
- Дополнительные коды ошибок:

| Код | Значение |
| :--- | :--- |
| P0011 | положение распредвала: опережение или производительность системы |
| P0012 | положение распредвала: запаздывание |
| P0016 | рассогласование положения впускного распредвала (и коленвала) |
| P0075 | КПРВ: обрыв цепи |
| P0076 | КПРВ: замыкание цепи управления на массу |
| P0077 | КПРВ: замыкание цепи управления на бортсеть |

Частые причины P0011/P0012/P0016 на практике — старое или неподходящее масло, низкий уровень масла, загрязнённый КПРВ или его сетка, ошибка при установке ремня ГРМ.

## ❓ Что с M74.9

На Lada Vesta 1.8 (21179) нового поколения ставится контроллер **M74.9 / M74.91** («Итэлма»). По базе прошивок chiptuner.ru: артикулы 8450043733, 8450044271 — «Веста Техно E5 1.8L 16V 21179» 2023–2024 годов, **8450047190** и 8450046519 — «Веста Техно 1.8MT E5 21179».

Официальной ТИ «ЭСУД с контроллером M74.9» в открытом доступе нет. Что можно использовать:
- **эту ТИ** — устройство датчиков и исполнительных механизмов, принципы диагностики, раздел 3 про VVT и таблица значений как ориентир;
- **распиновку M74.9 для Весты NG** — в заметке про ЭСУД 21179 (раздел 4, по данным Drive2 и chiptuner.ru); назначение контактов у M74.9 своё, схему М86 из ТИ к нему не применять;
- **ТИ по ЭСУД с контроллером M74** для Granta и Kalina 2 — ближайший по семейству документ.
