# ▽ Triangle-Downloader — качать YouTube прямо из плеера (Chrome MV3)

**Triangle-Downloader** ([github.com/HelpFreedom/Triangle-Downloader](https://github.com/HelpFreedom/Triangle-Downloader)) — расширение для **Chrome (Manifest V3)**, добавляющее кнопку **▽** прямо в плеер YouTube: скачивает открытое видео (720p/1080p `.mp4`), аудио (`.mp3`), субтитры (`.txt`) и умеет **вырезать фрагмент** («начало—конец»). Работает **локально в браузере**, перехватывая уже расшифрованный поток самого плеера — **без `yt-dlp`, без сторонних сайтов/серверов**. GPL-3.0, JavaScript, использует `ffmpeg.wasm`.

> [!caution] Трезво: свежий проект-однодневка автора канала, и «нельзя заблокировать» — преувеличение
> - **Совсем новый и маленький**: репозиторий создан и залит **18 июля 2026** (первый = последний пуш в тот же день), на момент заметки **~52★**. Автор — **Black Triangle** ([@black_triangle_tg](https://t.me/black_triangle_tg)), код по README — **самим Claude**. Это hobby-проект, не поддерживаемый годами продукт (см. и его же [claude-ide.nvim](../../AI/Agents/Tooling/claude-ide.nvim%20%28Black%20Triangle%29%20%E2%80%94%20Neovim%20%D0%BA%D0%B0%D0%BA%20IDE%20%D0%B2%20%D1%81%D0%B2%D1%8F%D0%B7%D0%BA%D0%B5%20%D1%81%20Claude%20Code%20%28%D0%B4%D0%B5%D1%80%D0%B5%D0%B2%D0%BE%20%D1%81%20%D0%B1%D0%B5%D0%B9%D0%B4%D0%B6%D0%B0%D0%BC%D0%B8%20%D0%BF%D1%80%D0%B0%D0%B2%D0%BE%D0%BA%2C%20inline-%D0%B4%D0%B8%D1%84%D1%84%D1%8B%2C%20%D1%81%D0%BD%D0%B0%D0%BF%D1%88%D0%BE%D1%82%D1%8B%20%C2%AB%D1%81%D1%82%D1%80%D0%B0%D0%BD%D0%B8%D1%86%D0%B0%D0%BC%D0%B8%C2%BB%29%2C%20%D1%87%D1%82%D0%BE%20%D1%8D%D1%82%D0%BE%20%D0%B8%20%D0%BD%D1%8E%D0%B0%D0%BD%D1%81%D1%8B.md)).
> - **«Без возможности заблокировать» — маркетинг.** Оно **завязано на внутренности плеера YouTube (SABR/MSE, кодек VP9)**. YouTube регулярно меняет эти кишки и активно борется с обходами → **такой хук по своей природе хрупкий** и может отвалиться после любого обновления плеера. Это не «неубиваемо», а наоборот — потенциально капризнее серверного `yt-dlp`.
> - **Парадокс: для работы НУЖЕН адблок** (uBlock Origin). Без него YouTube вставляет рекламу **прямо в медиапоток** и захват рвётся. То есть расширение зависит от другого расширения, а YouTube-антиадблок может сломать и то и другое.

> [!warning] Как ставится и почему это про доверие
> - **Релизов нет / в Chrome Web Store нет.** Ставится вручную: `chrome://extensions` → **Режим разработчика** → «Загрузить распакованное» → папка `extension/`. То есть ты грузишь **непроверенный магазином JS-код** себе в браузер с доступом к YouTube. Код открыт (можно прочитать), но это твоя ответственность.
> - **Режим разработчика** в Chrome периодически показывает предупреждение «отключите расширения разработчика» — придётся мириться.
> - Внутри лежит **`ffmpeg.wasm`** (`@ffmpeg/ffmpeg@0.12.10` + `@ffmpeg/core@0.12.6`, однопоточная сборка) — им и собирается итоговый файл.

> [!info] Что реально умеет (по README)
> - **Видео** 720p/1080p → `.mp4`; **аудио** → `.mp3`; **субтитры** → `.txt` (без таймкодов, приоритет русскому).
> - **Выбор фрагмента** — скачать только отрезок ролика.
> - **Формат видео**: «Быстро» (VP9 в mp4 **без перекодирования**, секунды) или «H.264» (перекодирование для старых плееров, **медленно**).
> - Авто-отключение автовоспроизведения YouTube.
> - Работает на страницах `youtube.com/watch`.

> [!note] Как устроено (коротко)
> YouTube раздаёт HD по протоколу **SABR**: видео и звук — раздельные зашифрованные потоки, плеер расшифровывает их в памяти через **Media Source Extensions** (готовой ссылки на файл нет). Расширение подключается там, где данные **уже расшифрованы**: `content_hook.js` перехватывает сегменты в `SourceBuffer.appendBuffer` (плеер склоняют к **VP9**, т.к. `ffmpeg.wasm` не декодирует AV1), перематывает видео к краю буфера, собирая сегменты выбранного отрезка; `offscreen.js` через `ffmpeg.wasm` склеивает файл. Субтитры берутся из DOM-панели «Расшифровка видео» (без перехвата сети).

> [!warning] Ограничения (важно для ожиданий)
> - **Потолок 1080p** — ни 1440p/4K, ни высокого fps, ни AV1 (принудительно VP9).
> - **Длинные ролики — долго**: захват идёт через перемотку буфера, время растёт пропорционально длине.
> - **H.264 и `.mp3` перекодируются однопоточным `ffmpeg.wasm`** → до нескольких минут на длинных видео.
> - В режиме «Быстро» mp4 содержит **VP9/Opus** — играет в Chrome/VLC/современных плеерах, но **не в старых**; для них — «H.264».
> - **Только Chrome/Chromium**, Firefox не поддерживается.

## 🖥️ Применимость на системах владельца

Это браузерное расширение — живёт в Chromium на любом десктопе:

| Система | Как |
| :--- | :--- |
| **Gentoo (основная) / Debian-Ubuntu / Arch / Windows** | ✅ подойдёт **Chromium/Chrome** любой из систем: загрузить распакованное расширение из папки `extension/`, включить адблок. **В Firefox — не работает** |
| **Entware / RT-AX56U** | ➖ неактуально: это расширение браузера, не для роутера |

> [!tip] Тебе по профилю (Linux + CLI)
> У тебя наверняка есть **[yt-dlp](../Downloaders/yt-dlp.md)** — он мощнее по всем статьям (любые сайты, 4K/AV1, плейлисты, SponsorBlock, форматы), просто из терминала. Triangle-Downloader — про **удобство «в один клик из плеера»** и **вырезать фрагмент** того, что уже смотришь, без CLI. Если сидишь в Chromium и лень открывать терминал — сгодится как «быстрая кнопка», но для серьёзной/массовой качки и качества — `yt-dlp`. И держи в голове хрупкость: сломается на очередном апдейте YouTube. Сравнение вариантов — в [обзоре загрузчиков](../Downloaders/%D0%97%D0%B0%D0%B3%D1%80%D1%83%D0%B7%D1%87%D0%B8%D0%BA%D0%B8%20%D0%B2%D0%B8%D0%B4%D0%B5%D0%BE%20%E2%80%94%20%D0%BA%D0%B0%D0%BA%D0%BE%D0%B9%20%D0%B2%D1%8B%D0%B1%D1%80%D0%B0%D1%82%D1%8C.md).

> [!caution] Правовая рамка
> Массовое скачивание с YouTube нарушает **ToS сервиса**, а контент — чужой копирайт. Практично и легально — свои ролики, материалы под свободными лицензиями или личное офлайн-использование в рамках закона твоей юрисдикции.
