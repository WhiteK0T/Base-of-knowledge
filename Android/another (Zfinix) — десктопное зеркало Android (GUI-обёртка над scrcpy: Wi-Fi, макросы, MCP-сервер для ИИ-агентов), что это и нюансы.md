# 📱 another — десктопное зеркало Android (GUI над scrcpy + MCP для ИИ)

**another** ([github.com/Zfinix/another](https://github.com/Zfinix/another)) — десктопное приложение (**Tauri + React + Rust**) для **зеркалирования и управления Android** с компьютера: экран телефона на ПК, ввод мышью/клавиатурой, запись, скриншоты. MIT, ~640★, есть готовые сборки под все ОС. Ключевое, о чём пост молчит: под капотом — **штатный `scrcpy-server`** (Genymobile), а сверху — приятный GUI, **макросы** и **MCP-сервер для управления телефоном ИИ-агентом**.

> [!info] Правки к посту: это GUI-обёртка над scrcpy и НЕ только USB
> - **Внутри — scrcpy.** README прямо пишет: «uses a bundled `scrcpy-server`». То есть это **ещё один графический фронтенд к scrcpy** (в ряду с QtScrcpy/guiscrcpy), а не самостоятельный движок зеркалирования. Сам захват/H.264-H.265 и проброс ввода — это scrcpy; another даёт UX поверх.
> - **Не «только USB».** Пост говорит «через USB», но в фичах есть **Wi-Fi mirroring в один клик** (беспроводной ADB). USB нужен разве что для первого коннекта/спаривания.

> [!tip] Самое интересное (и по твоему профилю) — MCP-сервер для ИИ-агентов
> В another встроен **MCP-сервер** (Model Context Protocol): стартует на **порту 7070**, и **ИИ-агент (Claude Code, Claude Desktop, Cursor…) может управлять телефоном** — скриншот, тап/скролл/свайп, ввод текста, кнопки home/back/recents/power, `adb shell`, запуск приложения, открытие URL, Wi-Fi-подключение, запись/воспроизведение макросов. Есть даже готовый [скилл](https://clawhub.ai/zfinix/another) (`npx skills add Zfinix/another@another-android`). Это делает телефон «руками» для агента — см. связанное про [MCP](../AI/MCP%20%E2%80%94%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D1%8B%20Model%20Context%20Protocol.md) и другой подход [OpenDroid](OpenDroid%20%E2%80%94%20%D0%B0%D0%B2%D1%82%D0%BE%D0%BD%D0%BE%D0%BC%D0%BD%D1%8B%D0%B9%20%D0%98%D0%98-%D0%B0%D0%B3%D0%B5%D0%BD%D1%82%20%D0%BD%D0%B0%20%D1%81%D0%B0%D0%BC%D0%BE%D0%BC%20Android%20%28%D1%83%D0%BF%D1%80%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%82%D0%B5%D0%BB%D0%B5%D1%84%D0%BE%D0%BD%D0%BE%D0%BC%20%D1%87%D0%B5%D1%80%D0%B5%D0%B7%20Accessibility%2C%20%D0%BF%D0%B0%D0%BC%D1%8F%D1%82%D1%8C%2C%2012%20LLM%29%2C%20%D1%84%D0%B0%D0%BA%D1%82%D1%8B%20%D0%B8%20%D1%80%D0%B8%D1%81%D0%BA%D0%B8.md) (там агент живёт на самом телефоне).

> [!caution] Безопасность: MCP на 7070 = полный контроль над телефоном
> Пока MCP включён, **всё, что дотянется до `localhost:7070`, может делать с телефоном что угодно** (тапать, читать экран, гонять `adb shell`). Держи его **только на localhost**, не пробрасывай наружу, **выключай в настройках, когда не нужен**. И помни: `adb shell` через агента — это твой реальный телефон, а не песочница.

> [!info] Что умеет (по README)
> - Зеркалирование в реальном времени (**H.264/H.265**), **адаптивный битрейт**.
> - **Макросы**: запись/повтор/импорт/экспорт/переименование действий.
> - **Wi-Fi-зеркалирование** в один клик, **проброс звука** устройства (Android 11+).
> - **Запись экрана** (`.webm`), скриншоты, форвардинг тача/клавиатуры/скролла/навигации.
> - Командная строка с горячими клавишами на всё, настройка качества (разрешение/FPS/битрейт/кодек), автодетект устройств через **ADB**, темы, ник для устройства.

> [!note] Зрелость
> Проект **молодой, но живой**: создан **март 2026**, активен (июнь 2026), уже **7 релизов** (текущий `v0.4.0`, pre-1.0) с бинарями под macOS/Linux/Windows. 8 открытых issue. Для pre-1.0 — на удивление функционально, но края возможны.

## 🛠️ Что нужно для работы

- **ADB** на ПК и **включённая отладка по USB** на телефоне (для Wi-Fi — беспроводная отладка/спаривание, удобнее с Android 11+).
- `scrcpy-server` **уже вшит** в приложение — отдельно ставить scrcpy не нужно.
- **Root не требуется** (обычный scrcpy-путь).

## 🖥️ Применимость на системах владельца

| Система | Как |
| :--- | :--- |
| **Gentoo (основная) / Debian-Ubuntu / Arch** | ✅ есть **`.deb` / `.AppImage`** (или собрать Tauri). Нужен `adb` из `android-tools` (`emerge`/`apt`/`pacman`). Зеркало по USB и по Wi-Fi |
| **Windows / macOS** | ✅ `.msi`/`.exe`, `.dmg` (Intel/Apple Silicon) в релизах |
| **Entware / RT-AX56U** | ➖ это десктопный GUI, роутеру неактуально |

> [!tip] Тебе по профилю (Linux + Claude Code)
> Если нужно просто зеркало/управление — тебе может хватить **чистого `scrcpy`** из репозитория (легче, без Electron/Tauri-обвязки) или уже разобранной [aya](aya%20%E2%80%94%20%D0%B4%D0%B5%D1%81%D0%BA%D1%82%D0%BE%D0%BF%D0%BD%D1%8B%D0%B9%20GUI%20%D0%BD%D0%B0%D0%B4%20ADB%20%D0%B4%D0%BB%D1%8F%20%D1%83%D0%BF%D1%80%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F%20Android%20%28%D0%B7%D0%B5%D1%80%D0%BA%D0%B0%D0%BB%D0%BE%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%2C%20%D1%84%D0%B0%D0%B9%D0%BB%D1%8B%2C%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%2C%20%D0%BB%D0%BE%D0%B3%D0%B8%29.md). **another** выигрывает двумя вещами: **макросы** и **MCP-управление телефоном из Claude Code/Cursor** — вот это реально уникально и ложится на твой стек. Только отнесись к MCP на 7070 как к «руту по сети»: localhost, выключать после использования.
