# 🧰 FluentTweaker — прозрачный твикер Windows (WinUI 3)

**FluentTweaker** ([github.com/builtbybel/FluentTweaker](https://github.com/builtbybel/FluentTweaker)) — GUI-твикер Windows на **WinUI 3** (C#): отключает рекламу и лишние системные фичи, правит приватность, UI, панель задач, Explorer, «AI-фичи», игровые/производительные настройки и **скрытые политики** — то, что обычно меняют вручную через реестр/gpedit. От [builtbybel](https://github.com/builtbybel) (автор Bloatbox, Winpilot, FluentCleaner). ~3.3k★, C#, активен (с янв 2026, 27 релизов). Sibling проекта FluentCleaner (тот чистит файлы, этот — твикает саму систему).

> [!warning] Правка к посту: «отрубит НАВСЕГДА» — наоборот, фишка в ОБРАТИМОСТИ
> Пост подаёт как «отрубить навсегда любую системную фичу в 1 клик». Но философия самого инструмента (по README) — **прозрачность и обратимость**: каждый твик **инспектируется, категоризирован и откатывается**. Автор специально против «магических кнопок Optimize, которые тайком меняют 40 вещей». Так что это не «выжечь напалмом навсегда», а **управляемые обратимые изменения** — что как раз плюс. «Навсегда» из поста — преувеличение.

> [!caution] Главный риск: отключение Windows Update и Defender — это дыра в безопасности
> Пост радостно перечисляет «отрубит обновления, Defender, Edge». Трезво:
> - **Выключишь Windows Update — перестанешь получать патчи безопасности.** Это делает систему уязвимой; для машины в интернете — плохая идея по умолчанию.
> - **Отключишь Defender — останешься без штатного антивируса.** Если нет другого — риск заражения растёт. Отключать осмысленно только если ставишь замену.
> - **Удаление Edge/встроенных компонентов** может дестабилизировать систему и ломаться на следующем крупном апдейте Windows (часть твиков ОС может вернуть назад).
> - **Перед пачкой изменений — точка восстановления / бэкап.** Инструмент обратимый, но точка восстановления — страховка на случай «что-то пошло не так».

> [!info] Что заявлено (пост + README)
> - **60+ пунктов** к изменению; **не требует знаний** — выбрал, применил, перезагрузился.
> - **Предпросмотр**: перед применением видно, на что повлияет твик (совпадает с философией «сначала пойми, потом применяй»).
> - Категории: UI, taskbar, приватность, AI-фичи, поведение Explorer, гейминг, производительность, скрытые политики, системное поведение.
> - **Прозрачность/обратимость** каждого твика, современный Fluent-интерфейс.

> [!note] Доверие и лицензия
> - **Автор известный** (builtbybel: Bloatbox/Winpilot/FluentCleaner) — это плюс к доверию против безымянных «деблоатеров» с мутными скриптами. README прямо декларирует «без фейковых turbo-режимов и магии FPS».
> - **Но лицензии нет** (`License: None` = все права защищены). Исходники **видны**, но формально это **не open-source по лицензии** — переиспользовать/форкать «как открытое» нельзя. Скачивай **только с официального GitHub-релиза**, не с зеркал.
> - Требует **прав администратора** (правит реестр/политики).

## 🖥️ Применимость на системах владельца

| Система | Как |
| :--- | :--- |
| **Windows** | ✅ основной кейс: скачать релиз с [GitHub](https://github.com/builtbybel/FluentTweaker/releases), запустить от админа. **Сделай точку восстановления.** Update/Defender гаси осознанно (лучше не гасить или иметь замену) |
| **Gentoo (основная) / Debian-Ubuntu / Arch** | ➖ неактуально: это Windows-приложение (WinUI 3). Linux не нуждается в «деблоате» такого рода |
| **Entware / RT-AX56U** | ➖ нерелевантно |

> [!tip] Практичный вывод
> Из windows-твикеров — **аккуратный вариант**: известный автор, прозрачные обратимые твики, предпросмотр. Хорош для отключения рекламы/телеметрии/навязчивого UI. Но **не трогай Update/Defender бездумно** — экономия на «мусоре» не стоит открытой уязвимости.
