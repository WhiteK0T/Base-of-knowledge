# openGym — self-hosted трекер тренировок

Приложение для планирования и учёта тренировок: программы, подходы, суперсеты, кардио, вес тела, рекорды и прогресс. Работает в двух режимах — **отдельное Android-приложение без сервера** или **свой сервер в Docker** с синхронизацией между устройствами и входом по passkey.

Автор — [Duarte Santos](https://gitlab.com/DuarteSantos8), лицензия **AGPL-3.0**.

Проверено 09.09.2026: репозиторий склонирован, датасет пересчитан, лицензии и сетевые вызовы прочитаны в коде, доступность исходников проверена по трём площадкам.

## Что внутри

**Фронтенд:** React 19, Vite, zustand, роутинг на `react-router-dom`. Мобильная сборка — Capacitor (те же исходники), плюс нативные модули: защищённое хранилище, локальные уведомления, сканер штрихкодов ML Kit.

**Бэкенд:** Node без фреймворка, всего три зависимости — `@simplewebauthn/server` (passkey-вход по WebAuthn), `undici`, `web-push`.

**Качество для проекта возрастом в две недели неожиданно высокое:**

- **77 файлов тестов, около 1038 тест-кейсов**;
- к каждому релизу публикуется **SBOM в формате CycloneDX** — отдельно для `api` и `web`;
- APK выкладывается с файлом `.sha256`, в приложении есть проверка обновлений со сверкой контрольной суммы;
- 13 релизов за две с половиной недели.

**Русский язык поддержан полностью:** 14 локалей интерфейса, включая `ru`, и **все 1324 упражнения имеют русские инструкции** (`frontend/src/instr/ru.js`, 1 МБ). Переводы, кроме английского, — производная работа автора под AGPL; в `NOTICE.md` честно указано, что часть переводов сделана с помощью языковых моделей.

## Лицензии: главный подводный камень

Здесь у проекта редкая для хобби-разработки дотошность, и одновременно — реальная проблема, о которой стоит знать до самохостинга.

**Своё** — AGPL-3.0. Плюс отдельное исключение по §7: разрешено выкладывать мобильное приложение в магазины, чьи условия с AGPL несовместимы, пока исходники остаются открытыми.

**Данные упражнений** приходят из [`hasaneyldrm/exercises-dataset`](https://github.com/hasaneyldrm/exercises-dataset) (21,6 тыс. звёзд, жив), а тот, в свою очередь, — перепубликация [ExerciseDB v1](https://exercisedb.dev/). Тексты и метаданные распространяются под MIT, **AGPL на них не распространяется**. Автор openGym сам провёл расследование происхождения и описал доказательства: имена файлов сохраняют `exerciseId` исходной базы (`0001` → `0001-2gPfomN.jpg`), поля совпадают, инструкции идентичны с точностью до отрезанных префиксов `Step:N`.

**Картинки и анимации — вот здесь проблема.** Цитата из `NOTICE.md`:

> The exercise thumbnails (180×180) and animations are **not** covered by the MIT license above and **not** by openGym's AGPL. Their ownership is currently **unresolved** … **Until then, treat the media as third-party content licensed to neither openGym nor to you.**

Два правообладателя заявляют противоречащие права: исходный датасет приписывает медиа **© [Gym visual](https://gymvisual.com/)** с непередаваемым разрешением, а **ExerciseDB/AscendAPI** называет себя «оригинальным создателем и владельцем» и запрещает перераспространение сырого датасета. Автор запросил разъяснения и до ответа ничего не выдумывает.

Практическое следствие, и оно же ответ на «работает без инета»:

> **openGym does not redistribute it.** It is not in this repository, not in its history, and not in the published container images or the Android APK.

Медиа **скачивается при первом `docker compose up`** — отдельный сервис в `docker-compose.yml` клонирует ~140 МБ картинок и GIF с GitHub. Если захотите использовать эти изображения где-то ещё — права придётся выяснять самостоятельно.

## AI Coach — опционально и выключен по умолчанию

Отдельно, потому что это единственное место, где приложение может ходить наружу. Необязательный «тренер» составляет программу и предлагает правки по фактическим логам, каждое изменение нужно подтвердить вручную.

- по умолчанию **выключен**, в базовом образе AI-рантайма нет вообще;
- работает на **вашем** сервере под **вашим** ключом: Anthropic, OpenAI, Gemini или любая OpenAI-совместимая точка входа;
- **поддерживается локальная Ollama в LAN** — то есть приватность сохраняется полностью;
- жёсткое отключение на весь экземпляр — переменная `COACH_DISABLED=1`.

## Установка

### Самохостинг в Docker

```bash
git clone https://gitlab.com/DuarteSantos8/opengym.git
cd opengym
cp .env.example .env      # задать RP_ID и ORIGIN — на них ломается вход по passkey
docker compose up -d
```

Первый запуск скачает ~140 МБ медиа; дальше всё локально. Passkey требует HTTPS или `localhost` — по обычному HTTP в локальной сети вход и push-уведомления работать не будут, это отдельно оговорено в `docs/SELF_HOSTING.md`.

**Gentoo:**

```bash
sudo emerge -av app-containers/docker app-containers/docker-compose
sudo rc-update add docker default && sudo rc-service docker start
```

Актуальные версии в дереве — `docker` 29.8.0 и `docker-compose` 5.5.1.

**Debian / Ubuntu:**

```bash
sudo apt install docker.io docker-compose-v2
sudo systemctl enable --now docker
```

**Arch:** оба пакета в официальном репозитории `extra`, AUR не нужен:

```bash
sudo pacman -S docker docker-compose      # extra/docker 29.7.2, extra/docker-compose 5.5.1
sudo systemctl enable --now docker
```

**Entware / ASUS RT-AX56U — неприменимо.** В репозитории `armv7sf-k3.2` нет ни `docker`, ни `podman`, ни `containerd` — проверил, выборка пустая. На 256 МБ флеша 140 МБ одного только медиа тоже не легло бы. Роутер здесь не вариант ни в каком виде.

### Android без сервера

APK лежит в [релизах GitLab](https://gitlab.com/DuarteSantos8/opengym/-/releases) и на сайте проекта, рядом — файл `.sha256`. Проверяйте контрольную сумму перед установкой:

```bash
sha256sum -c openGym-1.3.5.apk.sha256
```

В этом режиме нет ни аккаунта, ни сервера, ни синхронизации — данные лежат на телефоне, есть локальные напоминания и встроенная проверка обновлений со сверкой суммы. В Google Play и F-Droid приложения нет.

**iOS:** готовой сборки не выкладывают, только самостоятельная сборка через Xcode (`docs/MOBILE.md`).

## Итог

| Кому | Стоит ли |
| :--- | :--- |
| Нужен приватный трекер тренировок на телефон | **Да** — APK без сервера и аккаунта закрывает задачу |
| Уже держит домашний сервер | **Да** — синхронизация между устройствами, профили для семьи, passkey |
| Категорически не хочет ставить APK мимо магазина | **Нет** — в Play и F-Droid его нет |
| Планирует использовать картинки упражнений в своём проекте | **Нет** — права на медиа не выяснены самим автором |
| Ждёт «обученную нейросеть» из поста | **Нет** — там статический JSON, а ИИ-тренер опционален и выключен |

Проект заметно серьёзнее, чем выглядит по посту: аккуратная лицензионная работа, SBOM, тысяча тестов, полная русская локализация. При этом ему **две с половиной недели**, и это главный риск — устойчивость, обратная совместимость данных и судьба зависимости от чужого датасета ещё ничем не проверены. Для трекера тренировок цена ошибки невелика, но бэкапы своей базы стоит делать с первого дня.

Отдельно стоит держать в голове, что **исходники живут только на GitLab**: GitHub-аккаунт автора заблокирован, а Gitea — зеркало, которое при проверке разок отдало 502.
