# Ghost in the SQL Data — детектив-тренажёр SQL в Steam

Детективная игра, где расследование ведётся настоящими SQL-запросами: есть консоль запросов, таблицы с уликами и «доска» для связей и графиков. Автор — французский соло-разработчик **Isaac MENARD**, он же издатель.

Пост в «Не баг, а фича» подаёт её так: *«игра будет БЕСПЛАТНОЙ и с кучей дел — поджоги, убийства и тд»*. Обе части этой фразы не выдерживают проверки: **бесплатна демоверсия, а не игра**, и дел не «куча», а **два**, причём убийств среди них нет.

## Что именно бесплатно и до каких пор

В Steam это **два разных приложения**:

| | Игра | Демо |
| :--- | :--- | :--- |
| appid | 5072430 | **5072550** |
| `type` | `game` | `demo` |
| `is_free` | **`false`** | **`true`** |
| Дата | October 2026 | **10 сентября 2026** |
| Цена | не объявлена | — |

Анонс самого разработчика от 03.09.2026 (единственная новость в карточке) не оставляет разночтений:

> The Ghost in the SQL Data **demo** comes out on September 10, for Steam Programming Fest. **It is free** and contains the first 2 cases, around 1 to 2 hours of play.

И там же — про срок жизни демки:

> **The demo stays available.** It stays online until the game comes out, and it gets exclusive updates after the festival.

То есть бесплатный доступ — это **2 дела и 1–2 часа игры**, и он живёт **до релиза полной версии в октябре**. Про цену полной игры автор не сказал ничего, но косвенный ориентир есть: обе его предыдущие игры платные (см. ниже).

Про сам «Steam Programming Fest»: название взято из анонса разработчика; страница распродажи на 09.09.2026 ещё не открыта (`/sale/programmingfest` отдаёт 302 на главную), так что независимо подтвердить событие пока нельзя — фестиваль должен стартовать 10 сентября.

## Что видно на скриншотах: SQL там настоящий

Это единственная часть поста, которая подтверждается полностью. На кадрах из магазина — рабочая консоль, а не имитация с выбором варианта:

**Дело 1, «The Ashgrove Fire».** Вкладка `QUERY 1` с нумерацией строк и подсветкой, кнопка `RUN`, запрос `SELECT * FROM dispatch_log`, под ним — `RESULT OF QUERY 1` с пометкой **`2400 ROWS · <0.01S`** и строкой `SHOWING THE FIRST 400 OF 2,400 ROWS`. Колонки таблицы: `id, on_date, at_time, district, site, subject, kind, source`. Сбоку — панель `GOAL` и счётчик **`CHECKPOINT 1 OF 7`**.

**Дело 2, «The Ticket And The Turnstile».** Отдельное окно `SQL QUERY CONSOLE`, вверху — `TABLES YOU CAN QUERY: validations, supports` (набор таблиц ограничен уровнем), и запрос с агрегацией:

```sql
SELECT station, count(*) as crossings
FROM validations
WHeRe card_id LIKe 'C%'
group by station
LIMIT 4
```

Регистр ключевых слов намеренно «кривой» — движок разбирает SQL регистронезависимо, как положено. Ниже — понятная человеку ошибка парсера: *«The query stops before it finishes. The last clause is still waiting for something: a column, a value, or a closing bracket»*. Результат можно вывести как `TABLE / BAR / LINE / PIE / KPI` с выбором осей X и Y, приколоть к доске (`PIN TO BOARD`) и проверить (`VERIFY`). Карта метро на доске подписана «Source: Île-de-France Mobilités» — то есть данные срисованы с реального открытого набора.

**Чего проверить нельзя до 10 сентября:** какой это движок и диалект. Требования упоминают «support WebGL / DirectX 11», что намекает на веб-технологии в основе (типовое решение для такого — SQLite, собранный в WASM), но ни в карточке, ни в анонсе движок не назван. Пока демка не вышла, это догадка, а не факт — а от диалекта напрямую зависит, насколько «навыки перейдут в профессиональную деятельность».

## Перевод и озвучка сделаны ИИ

В карточке заявлено 8 языков, и **все** помечены звёздочкой «озвучивание доступно на этих языках», включая русский. Рядом — обязательное раскрытие Steam про ИИ-контент, где автор пишет прямо:

> **AI was used on this game: to assist with the programming, and to produce the translations.** If a line reads wrong in your language, report it on the Steam community hub.

То есть русский текст (и то, что подаётся как «полная озвучка») — машинный перевод. Для игры, где надо точно понимать формулировку задания к запросу, это существенный риск: неточный перевод условия ломает саму задачу. Автор это осознаёт и просит сообщать об ошибках в хабе сообщества.

## Платформы: под Linux сборки нет

Ключевой момент для тех, кто не на Windows. И у игры, и у демки в Steam API:

```
platforms: {'windows': True, 'mac': True, 'linux': False}
```

Системные требования — Windows 10 64-bit, двухъядерный 2,0 ГГц, 4 ГБ RAM, Intel HD Graphics 4000 (support WebGL / DirectX 11), 1 ГБ на диске; для macOS — macOS 11, Apple M1 или Core i5, 4 ГБ RAM. Отчётов на ProtonDB по appid 5072430 нет вообще (API отдаёт 404) — игра ещё не вышла, статистики совместимости не существует.

Практически это значит: **запускать придётся через Proton**, и заранее никто не скажет, заведётся ли. Для игры на веб-стеке без античита шансы обычно высокие, но это ожидание, а не проверенный факт.

### Gentoo (основная)

Steam-клиента в основном дереве Portage нет, он живёт в официально зарегистрированном оверлее **`steam-overlay`** (`github.com/anyc/steam-overlay`, активен, последний коммит 15.08.2026):

```bash
emerge -av app-eselect/eselect-repository
eselect repository enable steam-overlay
emaint sync -r steam-overlay
emerge -av games-util/steam-launcher
```

Нужен `ABI_X86="32"` в `make.conf` и мультилиб-профиль — Steam-клиент 32-битный. Proton ставится самим клиентом (Steam Play → Proton Experimental в настройках). Из дерева при этом доступны полезные рядом лежащие вещи:

```bash
emerge -av app-emulation/wine-proton app-emulation/vkd3d-proton app-emulation/protontricks
```

### Debian / Ubuntu

```bash
sudo dpkg --add-architecture i386 && sudo apt update
sudo apt install steam-installer     # Debian: контрибная/несвободная секция
# Ubuntu: sudo apt install steam      # multiverse
```

Дальше — Steam Play для всех игр и Proton Experimental.

### Arch

Пакет в официальном `multilib` (версия на момент проверки — **1.0.0.87**), достаточно включить репозиторий `[multilib]` в `/etc/pacman.conf`:

```bash
sudo pacman -S steam
```

### Entware (ASUS RT-AX56U)

Неприменимо: роутер на armv7 без графической подсистемы, Steam и Proton — x86-64. Пункт закрыт.

## Что уже сейчас бесплатно и навсегда

Если цель — не подождать релиза, а поучить SQL сегодня, то ровно эта идея («детектив на SQL-запросах») уже давно реализована и раздаётся бесплатно. Всё ниже проверено — доступно на 09.09.2026:

| Ресурс | Что это | Нюанс |
| :--- | :--- | :--- |
| [SQL Murder Mystery](https://mystery.knightlab.com/) | Расследование убийства в SQL City от Knight Lab (Northwestern University). Полностью в браузере, база — **SQLite через sql.js** | Исходники открыты: [`NUKnightLab/sql-mysteries`](https://github.com/NUKnightLab/sql-mysteries), **MIT**, 2206 звёзд. Есть режим-прохождение для тех, кто SQL не знает совсем |
| [Select Star SQL](https://selectstarsql.com/) | Полноценный интерактивный учебник SQL с запросами прямо на странице | На него ссылается сам Knight Lab как на «полный туториал» |
| [SQLBolt](https://sqlbolt.com/) | Короткие уроки с упражнениями, от `SELECT` до подзапросов | Хорош как первый заход |
| [PostgreSQL Exercises](https://pgexercises.com/) | Задачи на настоящем PostgreSQL — с оконными функциями и рекурсией | Ближе всего к тому, что реально спрашивают на работе |
| [SQL Police Department](https://sqlpd.com/) | Ещё один детектив-тренажёр на SQL | — |

Разница принципиальная: SQL Murder Mystery бесплатен без срока и с открытым исходником, а бесплатность Ghost in the SQL Data — это демка на 1–2 часа, которая исчезнет с выходом платной версии.

## Итог

Игра выглядит симпатично и, судя по скриншотам, честно делает то, что обещает: настоящая SQL-консоль, ограниченный набор таблиц на уровень, визуализация результата, доска для версий. Претензий к автору нет — он всё описал точно.

Претензии к посту. «Бесплатная игра» — это на самом деле бесплатная **демка на два дела и 1–2 часа**, доступная с 10 сентября и только до релиза платной версии в октябре. «Куча дел — поджоги, убийства» — дел ровно два, и убийства среди них нет: поджог школы и слежка в парижском метро. Не упомянуты ни отсутствие сборки под Linux, ни то, что весь перевод (включая русский) сделан ИИ по признанию самого автора.

Разумный план: добавить в вишлист, 10 сентября пройти бесплатную демку за пару часов и уже по ней решать, стоит ли покупать полную версию. А учить SQL можно начинать прямо сейчас — на SQL Murder Mystery, которая бесплатна навсегда и с открытым исходником.
