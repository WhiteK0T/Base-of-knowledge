# 🧗 Роадмап подготовки к алгоритмическому интервью (Глеб Михайлов)

Последовательность изучения **паттернов** алгоритмов и структур данных для подготовки к техническому интервью — от «0 до оффера». Автор роадмапа — **Глеб Михайлов**. Ориентир по объёму: **~180 дней · ~200 часов · 200–300 задач**.

Идея: учить не разрозненные задачи, а **паттерны** (шаблоны решений) в правильном порядке — каждый следующий опирается на предыдущий. Рядом с каждым паттерном — стартовая задача (номер LeetCode) для входа. Похожий по духу, но по-другому сгруппированный список — в соседней заметке [19 паттернов ByteByteGo](19%20%D0%BF%D0%B0%D1%82%D1%82%D0%B5%D1%80%D0%BD%D0%BE%D0%B2%20%D0%B0%D0%BB%D0%B3%D0%BE%D1%80%D0%B8%D1%82%D0%BC%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D1%85%20%D0%B7%D0%B0%D0%B4%D0%B0%D1%87%20%D0%B4%D0%BB%D1%8F%20%D1%81%D0%BE%D0%B1%D0%B5%D1%81%D0%B5%D0%B4%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B9%20%28ByteByteGo%20Coding%20Patterns%29%20%E2%80%94%20%D1%87%D1%82%D0%BE%20%D1%83%D1%87%D0%B8%D1%82%D1%8C%20%D0%B8%20%D0%B3%D0%B4%D0%B5%20%D0%B1%D0%B5%D1%81%D0%BF%D0%BB%D0%B0%D1%82%D0%BD%D0%BE.md); эталонные реализации — [TheAlgorithms](TheAlgorithms%20%E2%80%94%20%D0%BE%D1%82%D0%BA%D1%80%D1%8B%D1%82%D1%8B%D0%B5%20%D1%80%D0%B5%D0%B0%D0%BB%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D0%B8%20%D0%B0%D0%BB%D0%B3%D0%BE%D1%80%D0%B8%D1%82%D0%BC%D0%BE%D0%B2%20%D0%B8%20%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85%20%D0%BD%D0%B0%20%D0%B4%D0%B5%D1%81%D1%8F%D1%82%D0%BA%D0%B0%D1%85%20%D1%8F%D0%B7%D1%8B%D0%BA%D0%BE%D0%B2%20%28%D1%87%D1%82%D0%BE%20%D0%B2%D0%BD%D1%83%D1%82%D1%80%D0%B8%2C%20%D0%B4%D0%BB%D1%8F%20%D1%87%D0%B5%D0%B3%D0%BE%2C%20%D0%BD%D1%8E%D0%B0%D0%BD%D1%81%D1%8B%29.md).

> [!note] Как пользоваться
> Идти **сверху вниз по уровням**: закрыл паттерн (решил стартовую + несколько похожих) → следующий. Уровни 0–2 — фундамент, 3 — связные структуры и обходы, 4 — «тяжёлая артиллерия», 5 — добивка. Не прыгать: ДП без уверенных рекурсии и хэшей не берётся.

## 🗺️ Паттерны по уровням (с пояснениями)

### Уровень 0 — старт
- **Повседневное программирование** — базовый синтаксис, циклы, условия, ввод-вывод. Уметь без запинки писать простой код.

### Уровень 1 — массивы и хэши (фундамент)
- **Массивы** `605. Can Place Flowers` — индексация, проход, изменение на месте. База всего остального.
- **Строки** `344. Reverse String` — массив символов: разворот, сравнение, подсчёт; помнить про неизменяемость строк в Java/Python.
- **Матрицы** `867. Transpose Matrix` — двумерные массивы: обход по строкам/столбцам, транспонирование, границы.
- **Префиксные суммы** `724. Find Pivot Index` — заранее посчитанные накопленные суммы → сумма любого отрезка за O(1).
- **Модуло и целочисленное деление** `66. Plus One` — работа с цифрами числа, перенос разрядов, `%` и `//`; ловушки переполнения.
- **Хэш-сеты** `217. Contains Duplicate` — проверка «видели ли уже» за O(1); дубликаты, уникальность.
- **Хэш-таблицы** `49. Group Anagrams` — ключ→значение за O(1): счётчики, группировка, кэш; основа половины задач.

### Уровень 2 — базовые техники
- **Два указателя** `977. Squares of a Sorted Array` — два индекса навстречу/в темпе друг друга → O(n) вместо вложенных циклов на отсортированном массиве.
- **Бинарный поиск** `34. Find First and Last Position…` — деление диапазона пополам за O(log n); не только в массиве, но и «по ответу».
- **Скользящее окно** `3. Longest Substring Without Repeating Characters` — подотрезок переменной длины, растёт/сжимается → подстроки/подмассивы за O(n).
- **RLE** (Run-Length Encoding) — сжатие подряд идущих одинаковых элементов (`aaab`→`a3b1`); счёт серий.
- **Куча** `215. Kth Largest Element…` — приоритетная очередь: быстрый доступ к min/max, top-K, потоковые задачи за O(log n) на вставку.
- **Интервалы** `252. Meeting Rooms` · `228. Summary Ranges` — сортировка по началу, слияние/пересечение отрезков; расписания, диапазоны.

### Уровень 3 — связные структуры и обходы
- **Связный список** `206. Reverse Linked List` — узлы и ссылки: разворот, быстрый/медленный указатель, обнаружение цикла.
- **Стэк** `20. Valid Parentheses` — LIFO: скобки, откат, «ближайший больший элемент», эмуляция рекурсии.
- **Деревья** `144. Binary Tree Preorder Traversal` — иерархия узлов: обходы (pre/in/post-order), базовая рекурсия по детям.
- **DFS** `104. Maximum Depth of Binary Tree` — обход в глубину (рекурсией/стеком): пути, глубина, связность.
- **Рекурсия** `509. Fibonacci Number` — функция через саму себя: база + шаг; мост к бэктрекингу и ДП.
- **Очередь** — FIFO; сама по себе проста, но это **основа BFS**.
- **BFS** `102/103. Binary Tree Level / Zigzag Order Traversal` — обход по уровням через очередь: кратчайший путь в невзвешенном графе, обход слоями.

### Уровень 4 — продвинутое
- **Графы** `200. Number of Islands` — вершины и рёбра: DFS/BFS по графу, компоненты связности, матрица/список смежности.
- **Бэктрекинг** `17. Letter Combinations of a Phone Number` — полный перебор с откатом: перестановки, комбинации, судоку; рекурсия + «отменить выбор».
- **Динамическое программирование** `322. Coin Change` — разбиение на перекрывающиеся подзадачи + мемоизация/таблица; самый сложный класс на интервью.
- **Жадные** `55. Jump Game` — локально-оптимальный выбор на каждом шаге; работает не всегда — уметь доказывать, что жадность корректна.

### Уровень 5 — добивка
- **Сортировка (под капотом)** — понимать merge/quick/heap sort, их сложность и устойчивость; когда писать свою компараторную логику.
- **Дизайн** `706. Design HashMap` — спроектировать структуру данных с нуля (LRU-кэш, HashMap, стек с min); проверяет понимание внутренностей.
- **Битовые операции** `461. Hamming Distance` — `&`, `|`, `^`, сдвиги, маски; XOR-трюки, подсчёт битов.
- **Математика и геометрия** `13. Roman to Integer` — арифметика, простые числа, НОД, точки/прямые; аккуратность с краевыми случаями.

## 🧠 Навыки, которые качаются параллельно

| Уровень | Навыки |
| :--- | :--- |
| 1 | Дебаггинг · **Big O** (асимптотика) · переход от брутфорса к оптимальному · декомпозиция · продумывать краевые случаи · структуры данных · презентация решения |
| 2 | Ручной дебаггинг · **распознавание паттернов** · шаблоны · рефакторинг |
| 3 | Рисование (схемы на бумаге) · базовый ООП |

Паттерны — это «что решать», навыки — «как думать и как вести себя на интервью» (проговаривать вслух, оценивать сложность, ловить краевые случаи).

## 🎯 Практический вывод

- **Порядок важнее охвата.** 200–300 задач по паттернам в этом порядке дают больше, чем 1000 случайных: закрываешь класс задач, а не отдельные кейсы.
- **Стартовая задача = вход**, но на каждый паттерн решить **несколько** похожих до автоматизма.
- **Big O и распознавание паттернов** (навыки 1–2 уровней) проверяют на интервью не меньше, чем код.
- На собеседовании код пишут на своём языке (у владельца — [Java](../Java/Java%20%E2%80%94%20%D0%BF%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D0%B0%20%D0%B8%20%D1%8F%D0%B7%D1%8B%D0%BA%20%28JVM%2C%20JDK-JRE%2C%20%D1%8D%D0%BA%D0%BE%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B0%29%20%D0%B8%20%D0%BE%D1%81%D0%BE%D0%B1%D0%B5%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D0%B8%20%D1%83%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B8-%D1%8D%D0%BA%D1%81%D0%BF%D0%BB%D1%83%D0%B0%D1%82%D0%B0%D1%86%D0%B8%D0%B8%20%D0%BD%D0%B0%20Gentoo%20%28eselect%20java-vm%29%20%D0%B8%20%D0%B4%D1%80.md)): знать `List/Map/Set/Deque/PriorityQueue` под эти паттерны обязательно.
