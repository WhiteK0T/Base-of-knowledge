## Установка Rust по системам

В учебнике описан только `rustup` — а на практике выбор между rustup и пакетом дистрибутива важен.

> [!tip] Правило выбора
> **Разработка на Rust → rustup.** Он даёт переключение stable/beta/nightly, компоненты (`rust-analyzer`, `clippy`, `miri`), кросс-таргеты и обновление одной командой. Rust выпускается каждые **6 недель**, пакет дистрибутива почти всегда отстаёт.
> **Просто собрать одну программу на Rust → пакет дистрибутива**, чтобы не плодить второй тулчейн.

### Gentoo (основная)

```bash
# вариант 1 — из исходников, «по-гентушному» (долго: Rust собирается часами)
sudo emerge --ask dev-lang/rust

# вариант 2 — rustup, рекомендую для разработки
sudo emerge --ask dev-util/rustup
rustup default stable
rustup component add rust-analyzer clippy rustfmt
```

> [!caution] Про `dev-lang/rust` и `dev-lang/rust-bin`
> `dev-lang/rust` собирается из исходников — это многочасовой билд, сопоставимый с chromium. `dev-lang/rust-bin` — готовый бинарник, но это ровно то, чего вы на Gentoo избегаете. Компромисс: поставить `dev-util/rustup` (сам по себе крошечный) и дальше жить в rustup-тулчейне, не трогая систему. Portage при этом продолжит собирать rust-зависимые пакеты своим `dev-lang/rust`.
>
> Если Portage требует Rust как зависимость (для `librsvg`, `firefox` и прочего), а вы поставили только rustup — пропишите в `/etc/portage/package.provided`, иначе будете держать два тулчейна.

### Debian / Ubuntu

```bash
# пакет дистрибутива (обычно отстаёт на несколько релизов)
sudo apt install rustc cargo

# либо rustup — актуальнее
sudo apt install build-essential curl
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

`build-essential` нужен обязательно: линковкой занимается системный `cc`, без него `cargo build` упадёт на этапе линковки.

### Arch (планируется с июня 2026)

```bash
sudo pacman -S --needed base-devel
sudo pacman -S rustup          # официальный способ в Arch, не пакет rust
rustup default stable
rustup component add rust-analyzer clippy rustfmt
```

В Arch пакеты `rust` и `rustup` конфликтуют — ставьте что-то одно. Для разработки правильнее `rustup`.

### Entware (ASUS RT-AX56U)

```bash
opkg update && opkg install rust    # проверьте наличие: opkg list | grep -i rust
```

> [!danger] Компилировать Rust на роутере не надо
> armv7 с 512 МБ ОЗУ — не та машина, где собирают Rust-проекты: `rustc` прожорлив по памяти, и линковка любого нетривиального крейта уйдёт в OOM. Правильный путь — **кросс-компиляция с десктопа**, там же, где вы уже собираете под роутер:
> ```bash
> rustup target add armv7-unknown-linux-musleabihf
> cargo build --release --target armv7-unknown-linux-musleabihf
> scp target/armv7-unknown-linux-musleabihf/release/myapp root@router:/opt/bin/
> ```
> Цель на `musl` выбрана намеренно: получается статический бинарник, которому не нужен glibc на роутере. Именно так распространяют большинство Rust-утилит под embedded.

## Чем дополнить: программа на самом деле

Учебник закрывает чтение, но не практику. Полный набор, всё бесплатное и официальное:

| Ресурс | Что даёт | Размер / статус |
| :--- | :--- | :--- |
| **[The Rust Programming Language](https://doc.rust-lang.org/book/)** («The Book») | Полный официальный курс, включая многопоточность, `async`, умные указатели, тесты, макросы | 182 828 слов — в 5,3 раза больше Learning Rust |
| **[Rustlings](https://github.com/rust-lang/rustlings)** | **Те самые упражнения**, которых нет в Learning Rust: сотни маленьких задач с компилятором в роли проверяющего | 63 878 ★, MIT, обновлён 11.08.2026 |
| **[Rust by Example](https://doc.rust-lang.org/rust-by-example/)** | Тот же материал через запускаемые примеры прямо в браузере | 8 077 ★, Apache-2.0 |
| **[Rust Playground](https://play.rust-lang.org/)** | Прогнать код без установки чего-либо | официальный |
| `rustup doc` | Вся документация офлайн, включая The Book | ставится вместе с rustup |

**Практическая связка, которую я бы предложил:** читаете главу Learning Rust → делаете соответствующий раздел Rustlings → непонятное добираете в The Book. Learning Rust здесь работает как быстрый конспект и справочник «куда посмотреть», а роль тренажёра берёт на себя Rustlings. По одному только тексту без задач система владения в голове не осядет — это тот случай, когда пальцы должны набить ошибки борроу-чекера.
