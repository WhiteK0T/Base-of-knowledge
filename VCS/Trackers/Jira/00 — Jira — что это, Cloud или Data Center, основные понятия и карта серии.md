# 🧭 Jira — обзор и карта серии

**Jira** — трекер задач и проектов от **Atlassian**. В ней ведут список работ (задачи, баги, истории), планируют спринты, двигают карточки по доске, строят отчёты, а через интеграции видят ветки, коммиты, pull request, сборки и деплои, связанные с каждой задачей.

> [!important] Jira — не CI/CD
> Jira **не собирает и не деплоит код**. Это делают CI-системы: **GitHub Actions, Bitbucket Pipelines, GitLab CI**, Jenkins. Jira с ними **связывается**: показывает в задаче статус сборки и куда она задеплоена, переводит задачу по статусам по событиям из репозитория, а правилом автоматизации может **запустить** пайплайн. Как это настроить — заметки 05–07 серии.

## 2. Cloud или Data Center

| | **Jira Cloud** | **Jira Data Center** (self-hosted) |
| :--- | :--- | :--- |
| Где работает | у Atlassian, `ваш-сайт.atlassian.net` | на вашем сервере (Java, PostgreSQL, от 8 ГБ RAM) |
| Стоимость | **Free — до 10 пользователей**; Standard ≈ $7.91, Premium ≈ $14.54 за пользователя в месяц | годовая лицензия от 500 пользователей, дорого; есть пробная |
| Обновления | автоматически, новые функции сначала здесь (ИИ Rovo, новые интеграции) | вручную |
| Интеграции с GitHub/GitLab/Bitbucket, MCP для ИИ | ✅ полные | частично, MCP-сервер Atlassian — **только Cloud** |
| Будущее | основной продукт | **сворачивается**: новым клиентам не продают с **30.03.2026**, продление для текущих — до **30.03.2028**, конец жизни — **28.03.2029** (лицензии станут только для чтения) |
| Jira Server | — | закрыт ещё в феврале 2024 |

**Вывод для обучения и своих проектов — Jira Cloud Free.** Ничего не нужно ставить на Gentoo/Debian/Arch, работает из браузера и мобильного приложения; ограничения бесплатного тарифа:

| Free | Что важно |
| :--- | :--- |
| до **10 пользователей** | для себя и небольшой команды хватает |
| **2 ГБ** под вложения | скриншоты и логи храните разумно |
| автоматизация — **100 запусков правил в месяц**, правила только в пределах одного проекта | для обучения хватает; для CI-интеграций экономьте запуски (заметка 04) |
| нет ролей и тонких прав проектов, нет аудита | всё видят все участники |
| поддержка — только сообщество | |

Цифры тарифов Atlassian меняет — актуальные смотрите на [странице цен](https://www.atlassian.com/software/jira/pricing).

> [!tip] Self-hosted без Atlassian
> Если принципиально нужно «всё у себя» без облака, Data Center сейчас — плохая инвестиция (до 2029). Открытые альтернативы с похожей моделью: **YouTrack** (JetBrains, бесплатно до 10 пользователей, есть self-hosted), **OpenProject**, **Plane**, **Redmine**, встроенные Issues/Boards в **GitLab** и **GitHub Projects**.

## 3. Ключевые понятия

С 2025 года в Jira Cloud **«issue» переименовали в «work item»** (рабочий элемент, по-русски в интерфейсе — «задача» или «рабочий элемент»), «issue type» — в **«work type»**. В JQL и REST API старое слово `issue` продолжает работать, в документации и сообществе встречаются оба. В серии пишу «задача».

| Понятие | Что это |
| :--- | :--- |
| **Сайт** (site) | ваш экземпляр Jira Cloud: `имя.atlassian.net` |
| **Проект** (project) | контейнер задач со своим **ключом** (`WEB`, `BOT`, `INFRA`) |
| **Задача** (work item / issue) | единица работы с ключом **`WEB-42`** — этот ключ потом пишут в ветках и коммитах |
| **Тип задачи** (work type) | Epic, Story, Task, Bug, Subtask и свои типы |
| **Эпик** (epic) | крупная цель, объединяет задачи |
| **Статус** и **workflow** | этапы жизни задачи (`To Do → In Progress → Done`) и разрешённые переходы |
| **Доска** (board) | визуальное представление: колонки = статусы |
| **Спринт** (sprint) | отрезок работы в Scrum (обычно 1–2 недели) |
| **Бэклог** (backlog) | очередь задач, ещё не взятых в работу |
| **JQL** | язык запросов: `project = WEB AND status = "In Progress"` |
| **Фильтр** | сохранённый JQL-запрос |
| **Компонент**, **метка**, **версия** (fix version / release) | способы группировки: часть системы, тег, релиз |
| **Автоматизация** | правила «триггер → условие → действие» |
| **Dev panel** («Разработка») | блок в задаче с ветками, коммитами, PR, сборками и деплоями |

## 4. Продукты Atlassian рядом с Jira

| Продукт | Зачем |
| :--- | :--- |
| **Jira** (бывшая Jira Software + Work Management) | задачи, доски, спринты — то, что изучаем |
| **Jira Service Management** | служба поддержки: заявки от пользователей, SLA, порталы |
| **Jira Product Discovery** | сбор идей и приоритизация продукта |
| **Confluence** | вики и документация, связывается с задачами |
| **Bitbucket** | Git-хостинг + **Bitbucket Pipelines** (CI) |
| **Rovo** | ИИ-поиск и агенты Atlassian внутри Jira/Confluence |
| **Atlassian MCP Server** | доступ внешних ИИ (Claude, ChatGPT, Cursor) к Jira — заметка 06 |
| **acli** (Atlassian CLI) | официальная консольная утилита для Jira — заметки 06 и 08 |

## 5. С чего начать прямо сейчас

1. Зарегистрироваться на https://www.atlassian.com/software/jira/free — получить сайт `имя.atlassian.net`.
2. Создать проект по шаблону **Kanban** (для своих проектов проще Scrum) — заметка 01.
3. Завести 5–10 задач, поводить их по доске, попробовать JQL — заметки 02 и 03.
4. Подключить GitHub-репозиторий и сделать коммит с ключом задачи — заметка 05.
5. Подключить Claude Code к Jira через MCP — заметка 06.
