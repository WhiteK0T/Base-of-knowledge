# 🪨 Strata — Qwen3.8-Flash-Next (125B) на игровой видеокарте

**[Strata](https://github.com/Niko1221/Strata)** — открытый движок инференса и установщик «в один клик», заточенный под одну модель: **[Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next)** — большую MoE-модель Qwen, которую обычно запускают на серверах. Strata раскладывает её по всему компьютеру: видеокарта + оперативная память + процессор + SSD — и поднимает на `127.0.0.1:8080` веб-чат и API, совместимые с OpenAI и Anthropic.

| | |
| :--- | :--- |
| Лицензия | Strata — **MIT**; модель — **qwen-community-1.0** (своя лицензия Qwen, не Apache) |
| Проект | с 24.09.2026; версия 0.1.44.1; ~2 170 коммитов, ~26 тыс. звёзд за три недели |
| Основа | части **llama.cpp / ggml**, свои ядра CUDA, HIP (AMD), Metal, SYCL |
| Системы | Windows 10/11, Linux; экспериментально — macOS (M1–M5), Intel Arc, старые GPU |

## 1. Что из поста подтверждается

| Пост | На деле |
| :--- | :--- |
| Модель на 125 млрд параметров | ✅ по карточке Qwen: **125B в MoE, из них 6B активны** на токен (512 экспертов, 10 + 1 общий). Плюс **51B** n-gram-эмбеддингов и **4B** MTP-слоя — всего в весах около **180B** |
| «Достаточно 12 ГБ памяти» | ⚠️ 12 ГБ — это **видеопамять**. Ещё нужно **32–64 ГБ оперативной памяти** (64 ГБ — для всех вариантов) и **~80 ГБ на диске**, желательно NVMe SSD |
| RTX 5070: 94 ток/с на Q2_0, 53 ток/с на IQ3_S | ✅ это замеры авторов, но на машине с **64 ГБ RAM** и Ryzen 5 7600, короткий чат |
| Q2 жертвует качеством — проверяйте на своих задачах | ✅ честная оговорка; README то же говорит про размеры |
| Windows и Linux | ✅ плюс экспериментально Mac, Intel Arc, AMD Strix Halo |
| Локальный API, совместимый с OpenAI и Anthropic | ✅ `/v1/chat/completions`, `/v1/messages`, `/v1/responses` (Codex CLI) |
| «Скилл Strata» | ⚠️ это не скилл, а **движок + установщик**. Для ИИ-агентов есть инструкция `docs/AI_SETUP.md` («поставь мне Strata») и MCP-сервер для запуска и остановки |

## 2. Как это помещается в 12 ГБ

- Модель — **MoE**: на каждый токен работают лишь ~10 экспертов из 512 в слое (всего 24 576 по всем слоям).
- **Видеокарта** держит несколько тысяч самых востребованных экспертов, **RAM** — все эксперты, **процессор** считает остальных параллельно, на **SSD** — большая таблица n-gram-эмбеддингов.
- **Спекулятивное декодирование** через MTP-слой: маленькая «угадайка» предлагает несколько токенов, большая модель проверяет их разом — ответ тот же, в 1,6–1,8 раза быстрее.
- Длинный промпт читается кусками до 8 192 токенов — больше 1 000 ток/с.

Та же идея, что и у ручного [MoE-оффлоада в llama.cpp](MoE-%D0%BE%D1%84%D1%84%D0%BB%D0%BE%D0%B0%D0%B4%20%D0%B2%20llama.cpp%20%28--n-cpu-moe%29%20%E2%80%94%20Qwen3.6-35B%20%D0%BD%D0%B0%2012%20%D0%93%D0%91%20VRAM%20%28%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B0%20%D0%BF%D0%BE%D1%81%D1%82%D0%B0%20%E2%80%94%20%D1%82%D1%80%D1%8E%D0%BA%D1%83%20%D0%BF%D0%BE%D0%BB%D1%82%D0%BE%D1%80%D0%B0%20%D0%B3%D0%BE%D0%B4%D0%B0%2C%20--fit%20%D0%B4%D0%B5%D0%BB%D0%B0%D0%B5%D1%82%20%D1%8D%D1%82%D0%BE%20%D1%81%D0%B0%D0%BC%2C%201080%20Ti%20%D0%BF%D0%BE%D0%B4%D1%85%D0%BE%D0%B4%D0%B8%D1%82%29.md), только с кэшем «горячих» экспертов, который подстраивается под ваши запросы, и ядрами под эту конкретную модель.

## 3. Требования и выбор размера

| | |
| :--- | :--- |
| Видеокарта | **NVIDIA** RTX 20/30/40/50 или **AMD** RX 6800/6900, 7700 XT–7900 XTX, 9060 XT, 9070 (XT), Radeon AI PRO R9700; **от 12 ГБ VRAM**. Драйвер NVIDIA **580+** |
| RAM | **от 32 ГБ**, 64 ГБ — для всех размеров |
| Диск | ~70–80 ГБ под модель (+~40 ГБ разово для Q2_0 на процессоре с AVX-512) |

| Ваша RAM | Что брать |
| :--- | :--- |
| 32 ГБ | **Coder** (IQ1_M) — версия для кода, половина экспертов удалена; ~91% SWE-bench Verified полной модели, вне кода слабее |
| 48 ГБ | **IQ2_XS** или Q2_0 (самый быстрый) |
| 64 ГБ | **IQ2_XS** (рекомендация), IQ3_XXS или IQ3_S (лучшее качество, медленнее) |
| 96 ГБ+ | IQ3_S или Unsloth UD-IQ4_XS (~4 бита) |

Замеры авторов («пишет ответ / читает промпт 32K»):

| Размер | RTX 5070 12 ГБ, 64 ГБ RAM | RX 9070 XT 16 ГБ, 47 ГБ RAM |
| :--- | ---: | ---: |
| Q2_0 | 94 / 2 650 ток/с | 60 / 1 160 ток/с |
| IQ2_XS | 79 / 2 090 | 52 / 1 110 |
| IQ3_XXS | 62 / 1 750 | — |
| IQ3_S | 53 / 1 620 | — |
| Coder | 55 / 2 180 | 44 / 1 420 |

4-8-битные файлы Unsloth, если не помещаются в RAM, читаются с SSD во время ответа — заметно медленнее (7–8,5 ток/с для UD-Q4_K_XL на 64 ГБ). Свою скорость покажет `./bench.sh` (5–10 минут).

## 4. Установка

```bash
git clone https://github.com/Niko1221/Strata.git
cd Strata
./setup.sh            # Windows: START-HERE.bat
```

Установщик спрашивает модель, размер, контекст и нужны ли картинки, качает ~70 ГБ (докачивает после обрыва) и открывает `http://127.0.0.1:8080`. Готовый движок берётся из релизов GitHub, при несовпадении — собирается из исходников.

| Система | Что подготовить |
| :--- | :--- |
| **Debian / Ubuntu** | всё ставится само: Python через `sudo apt`, при сборке — `build-essential` и CUDA (официально — Ubuntu 22.04/24.04, Debian 12/13) |
| **Arch** | заранее: `sudo pacman -S base-devel cuda python` (CUDA 13; `nvcc` в `/opt/cuda`) |
| **Gentoo** | заранее: `emerge --ask dev-util/nvidia-cuda-toolkit` (нужна ветка **13.x**, в дереве есть 13.4.1) и `x11-drivers/nvidia-drivers` 580+; `nvcc` ищется в `/opt/cuda*`. Установщик знает только apt/dnf/pacman — Python 3.10+ с venv должен уже быть. Для AMD — ROCm из `dev-util/hip` либо установщик сам положит ROCm (~10 ГБ) в `.venv` |
| **Entware** | не подходит: нужна видеокарта и десятки гигабайт RAM |

Docker (Linux): `docker run --rm --gpus all -p 8080:8080 --ulimit memlock=-1 -v strata-data:/data strata` после `docker build -t strata .`.

> [!warning] Первый запуск подвешивает компьютер
> Strata загружает 35–55 ГБ в RAM и закрепляет часть памяти за видеокартой — 1–3 минуты система может не отвечать. Это нормально; если висит больше 10 минут — закройте браузеры и прочее или возьмите размер поменьше.

## 5. Подключение приложений и агентов

| Клиент | Адрес |
| :--- | :--- |
| OpenAI-совместимые (Open WebUI, Continue, Cline, Aider…) | `http://127.0.0.1:8080/v1`, ключ и имя модели — любые |
| Anthropic API (в т.ч. Claude Code) | `ANTHROPIC_BASE_URL=http://127.0.0.1:8080` → `/v1/messages` |
| OpenAI Responses (Codex CLI) | `/v1/responses` |

```bash
ANTHROPIC_BASE_URL=http://127.0.0.1:8080 ANTHROPIC_AUTH_TOKEN=local claude
```

- **Размышления**: off / low / medium / high — через «reasoning effort» в клиенте. Off — самый быстрый.
- **Картинки** — если включены при установке (на AMD под Windows пока нет).
- **По умолчанию один запрос за раз**; `"parallel": 2` — несколько, но на 12 ГБ каждый ответ медленнее.
- **Первое сообщение длинного чата** читается целиком — ~1 минута на 30 000 токенов; дальше — секунды.
- **Освободить видеокарту** для игры: `--idle-unload 600` (выгружать после простоя) или `curl -X POST -H "Content-Type: application/json" localhost:8080/unload`.

> [!warning] Доступ из сети
> По умолчанию слушает только `127.0.0.1`. Для телефона или другого ПК: `./setup.sh --setup --host 0.0.0.0 --api-key <секрет>` — **ключ обязателен**, иначе модель и машина открыты всей сети. Лучше вообще оставить localhost и ходить через [SSH-туннель](../../Network/SSH/SSH-%D0%92%D0%B8%D0%B7%D1%83%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B5%20%D1%80%D1%83%D0%BA%D0%BE%D0%B2%D0%BE%D0%B4%D1%81%D1%82%D0%B2%D0%BE%20%D0%BF%D0%BE%20%D1%82%D1%83%D0%BD%D0%BD%D0%B5%D0%BB%D1%8F%D0%BC.md).

## 6. Стоит знать

- **Одна модель.** Strata заточена под Qwen3.8-Flash-Next и её кванты (плюс файнтюны вроде Swift 1.5 и «uncensored»-вариант, ставящийся вручную). Для других моделей — [llama.cpp](llama.cpp%20%E2%80%94%20%D0%B4%D0%B2%D0%B8%D0%B6%D0%BE%D0%BA%20%D0%BB%D0%BE%D0%BA%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B3%D0%BE%20%D0%B8%D0%BD%D1%84%D0%B5%D1%80%D0%B5%D0%BD%D1%81%D0%B0%20GGUF.md) или [Ollama](Ollama%20%E2%80%94%20%D0%BC%D0%B5%D0%BD%D0%B5%D0%B4%D0%B6%D0%B5%D1%80%20%D0%B8%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%20%D0%BB%D0%BE%D0%BA%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D1%85%20LLM.md).
- **Q2 и IQ1 — сильное сжатие.** На код и простые вопросы хватает, но на сложных рассуждениях и редких языках заметна разница с полной моделью. По данным авторов, 4-8-битные файлы совпадают с Q8_0 по следующему токену на 93–95%.
- **Строка «telemetry» в коде** — это локальный монитор GPU/CPU/RAM для вкладки Monitor, а не отправка данных; в коде установщика и сервера внешние адреса — только GitHub (готовый движок, проверка новых версий через api.github.com), Hugging Face (модель), PyPI и NVIDIA (CUDA при сборке).
- **Очень быстрый темп разработки** (по нескольку версий в неделю): после `git pull` установщик пересобирает движок. Для стабильной работы не обновляйтесь без нужды.
- **Без видеокарты NVIDIA/AMD 12+ ГБ** (например, на сервере без GPU) смысла нет — авторы прямо пишут, что на старых процессорах без AVX2 работает, но медленно.
