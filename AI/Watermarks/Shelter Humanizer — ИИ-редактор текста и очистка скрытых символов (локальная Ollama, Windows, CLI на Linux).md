# ✍️ Shelter Humanizer — ИИ-редактор текста и очистка скрытых символов

**[Shelter Humanizer](https://github.com/IT-Shelter-Labs/Shelter-Humanizer)** — приложение для Windows, которое делает две вещи:

1. **Редактура текста нейросетью** — убирает шаблонные обороты, канцелярит и повторы, сохраняя содержание. Работает с локальной моделью через Ollama (Qwen, DeepSeek), с любым OpenAI-совместимым API или через ваш ИИ-чат (ручной перенос задания и ответа).
2. **Очистка скрытых символов** — находит и удаляет невидимые вставки (пробелы нулевой ширины, BOM, мягкие переносы, некоторые управляющие знаки) и показывает их коды и позиции.

## 1. Что из поста подтверждается

| Пост | На деле |
| :--- | :--- |
| Работает локально | ✅ с локальной моделью текст не покидает компьютер. Мастер сам скачивает переносимую Ollama (≈1,4 ГБ, версия закреплена и сверяется по SHA256) и модель |
| Копирует ваш стиль | ✅ частично: можно дать **образец своего текста** (до 3000 символов) — модель ориентируется на него при переписывании |
| Удаляет скрытые символы, BOM, мягкие переносы, управляющие знаки | ✅ проверил CLI — см. раздел 3 |
| Подчёркивает, где нейронка наврала или поменяла смысл | ✅ в своём ИИ-режиме проверяет, сохранились ли числа, цитаты, ссылки, код и выбранные термины, и показывает замечания к смыслу. Полной проверки смысла нет — README прямо просит вычитывать ответ |
| Подсказывает, что переписать при ручном письме | ✅ режим «Без ИИ» и `analyze` дают замечания к стилю (например, пустые вступления «в современном мире…») |
| Под капотом API или локальные Qwen и DeepSeek | ✅ Qwen 3.5 4B по умолчанию, Qwen 3 1.7B, Qwen 3.5 9B, DeepSeek R1 8B (дистиллят на Qwen3) или любая модель Ollama/GGUF |
| «Подготовит текст для обхода любого ИИ-детектора» | ❌ этого программа не обещает: README прямо пишет, что она **не обещает прохождение ИИ-детекторов**, не измеряет плагиат и уникальность и не определяет авторство |

Про «спасение перед дипломом»: правила вузов об использовании ИИ стоит уточнить отдельно — инструмент задуман как редактор, а не как способ скрыть происхождение текста.

## 2. Установка

### Windows (основной вариант)

1. [Releases](https://github.com/IT-Shelter-Labs/Shelter-Humanizer/releases/latest) → `Shelter-Humanizer-1.1.1-windows-x64.zip` из **Assets** (не «Source code»).
2. Распаковать, запустить `Shelter-Humanizer.exe` — Python не нужен. Сборка не подписана, SmartScreen может предупредить.
3. **«Выбрать ИИ» → «Установить локальный ИИ»** → модель → подтвердить загрузку.

Файлы ИИ — в `%LOCALAPPDATA%\ShelterHumanizer\ai`, служб и автозапуска не создаётся.

| Модель | Загрузка | Памяти желательно |
| :--- | ---: | :--- |
| Qwen 3.5 4B (по умолчанию) | ≈3,4 ГБ | 16 ГБ RAM |
| Qwen 3 1.7B | ≈1,4 ГБ | 8 ГБ (качество ниже) |
| DeepSeek R1 8B | ≈5,2 ГБ | 24 ГБ или GPU |
| Qwen 3.5 9B | ≈6,6 ГБ | 24 ГБ или GPU |

На CPU обработка может идти несколько минут; лимит — 12 000 символов на ИИ-проход.

### Linux: из исходников

Готового бинарника и мастера установки ИИ для Linux нет — GUI и CLI запускаются из исходников, а Ollama ставится отдельно (см. [Ollama — менеджер и сервер локальных LLM](../Local-LLM/Ollama%20%E2%80%94%20%D0%BC%D0%B5%D0%BD%D0%B5%D0%B4%D0%B6%D0%B5%D1%80%20%D0%B8%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%20%D0%BB%D0%BE%D0%BA%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D1%85%20LLM.md)).

| Система | Python 3.11+ с Tk |
| :--- | :--- |
| **Gentoo** | `dev-lang/python` с USE-флагом `tk` (`echo "dev-lang/python tk" >> /etc/portage/package.use/python`) |
| **Debian / Ubuntu** | `sudo apt install python3 python3-venv python3-tk` |
| **Arch** | `sudo pacman -S python tk` |
| **Entware** | Tk нет, GUI не запустится. В репозитории есть `python3` 3.13, так что CLI-команды без ИИ (`analyze`, `clean`) теоретически подойдут, но на роутере я это не проверял |

```bash
git clone https://github.com/IT-Shelter-Labs/Shelter-Humanizer.git
cd Shelter-Humanizer
python3 launcher.py                      # графическое окно

python3 -m venv ~/.venvs/shelter && . ~/.venvs/shelter/bin/activate
pip install .                            # команда shelter-humanizer
```

## 3. CLI — проверено на Gentoo (Python 3.14)

```bash
shelter-humanizer analyze text.txt -o report.json   # скрытые символы и замечания к стилю (JSON)
shelter-humanizer clean   text.txt -o clean.txt     # только очистка символов
shelter-humanizer light   text.txt -o result.txt    # очистка + осторожные правки по правилам, без ИИ
shelter-humanizer prompt  text.txt --depth rephrase -o prompt.txt   # задание для внешнего ИИ-чата
shelter-humanizer rewrite text.txt --provider ollama --model qwen3.5:4b -o result.txt
```

Полезные ключи: `--spaces` — заменить специальные пробелы (неразрывный и т.п.) на обычные; `--nfc` — нормализация Unicode; `--confusables` — заменить похожие латинские буквы в русских словах (по умолчанию выключено: может испортить текст на других языках); `--voice` — файл-образец стиля; `--genre plain|business|academic|post`; для API — `--provider api --url https://openrouter.ai/api/v1 --model …` и ключ в `SHELTER_API_KEY`.

Проверка на строке с пробелом нулевой ширины (U+200B), мягким переносом (U+00AD), BOM (U+FEFF) и неразрывным пробелом (U+00A0):

- `analyze` нашёл все четыре знака с позициями: три — как предупреждения, неразрывный пробел — как информацию («часто полезен в типографике»); плюс замечание к штампу «В современном мире важно отметить…».
- `light` удалил U+200B, U+00AD и U+FEFF, неразрывный пробел оставил; `clean --spaces` заменил и его.
- Кавычки «ёлочки», тире и `ё` не тронуты — программа намеренно не считает UTF-8-типографику «следом ИИ».
- Штамп без ИИ не переписывается, только отмечается — глубокая правка есть только в ИИ-режиме.

Также в репозитории есть [portable-скилл](https://github.com/IT-Shelter-Labs/Shelter-Humanizer/blob/main/skills/shelter-humanizer-ru/SKILL.md) `shelter-humanizer-ru` — те же редакторские правила как инструкция для агента (Claude Code и др.), без GUI и сканера символов.

## 4. Стоит знать

- **Невидимые символы — не вотермарк ИИ-моделей.** Текстовый вотермарк Claude (с 02.08.2026) — статистический сдвиг в выборе токенов, а не скрытые символы; очистка Unicode его не снимает, а глубокое переписывание лишь размывает. Подробно — в заметке [Вотермарки Claude](%D0%92%D0%BE%D1%82%D0%B5%D1%80%D0%BC%D0%B0%D1%80%D0%BA%D0%B8%20Claude%20%28C2PA%20%2B%20%D0%BD%D0%B5%D0%B2%D0%B8%D0%B4%D0%B8%D0%BC%D1%8B%D0%B9%20%D1%82%D0%B5%D0%BA%D1%81%D1%82%D0%BE%D0%B2%D1%8B%D0%B9%29%20%E2%80%94%20%D0%BA%D0%B0%D0%BA%20Anthropic%20%D0%BC%D0%B5%D1%82%D0%B8%D1%82%20AI-%D0%BA%D0%BE%D0%BD%D1%82%D0%B5%D0%BD%D1%82%2C%20%D1%87%D1%82%D0%BE%20%D0%BF%D1%83%D1%82%D0%B0%D0%B5%D1%82%20%D0%BF%D0%BE%D1%81%D1%82%20%D0%B8%20%D0%BD%D0%B0%D1%81%D0%BA%D0%BE%D0%BB%D1%8C%D0%BA%D0%BE%20%D1%8D%D1%82%D0%BE%20%D1%81%D1%82%D0%BE%D0%B9%D0%BA%D0%BE.md). Сама очистка полезна по другим причинам: скрытые знаки ломают поиск, сравнение строк, код и вёрстку.
- **Цитаты, ссылки и код не чистятся** автоматически, чтобы не изменить их; подозрительные знаки в них остаются в отчёте.
- **Через API** выбранный сервис получает весь текст, образец стиля и защищённые фрагменты. История текстов и ключ автоматически не сохраняются; JSON-отчёт (с обоими текстами) создаётся только по команде.
- **Русский — основной язык правил**; качество на других языках зависит от модели и отдельно не проверялось.
- Выбор редакторского промпта подкреплён замерами на четырёх локальных моделях — [отчёт](https://github.com/IT-Shelter-Labs/Shelter-Humanizer/blob/main/docs/PROMPT_EVALUATION_2026-10-04.md) в репозитории.
- Проект молодой (две недели, один основной автор), но с тестами, CI и подробной документацией.
