# OpenCode Zen — бесплатные модели для агентов кода

**Что это.** Шлюз к моделям (AI gateway) от команды **OpenCode** (ныне компания Anomaly): один OpenAI-совместимый эндпоинт, за которым 61 модель — Claude, GPT, Gemini, Grok, DeepSeek, Kimi, Qwen, GLM, MiniMax. Основной режим платный, по факту потребления. Но среди моделей есть **восемь бесплатных**, и именно вокруг них построен пост-источник.

Главное, что нужно знать: **бесплатные модели реальны и работают**, но «миллиард токенов» — цифра, взятая из ниоткуда, а расплачиваетесь вы не деньгами, а своим кодом. Это написано в документации самого сервиса, просто не на той странице, которую открывают.

> [!danger] Короткий ответ, если читать некогда
> **Все восемь бесплатных моделей выведены из-под политики нулевого хранения данных.** Документация Zen прямым текстом: для каждой из них *«During its free period, collected data may be used to improve the model»*. А два эндпоинта NVIDIA снабжены отдельным предупреждением: *«Trial use only — do not submit personal or confidential data»*.
>
> Две из трёх моделей, которые пост советует поимённо, — из списка «обучаемся на ваших данных». Третья (`nemotron-3-ultra-free`) — та самая, где написано «не отправляйте конфиденциальное».

Честно заявлено — но «халявой» это назвать трудно.

> [!note] Заметьте, чего в бесплатном списке нет
> Ни Claude, ни GPT, ни Gemini, ни Grok, ни Kimi K3. Бесплатны только небольшие и дешёвые модели. Это важно для оценки экономии — см. раздел 3.

> Отдать исходный код проекта модели, которая на нём обучается, ради экономии порядка двадцати долларов в месяц. Для пет-проекта и учебных задач это может быть приемлемо. Для рабочего репозитория — нет.

## 4. Что там с лимитами: замер

Документация про лимиты бесплатных моделей **молчит полностью**. Раздел «Monthly limits» — про потолок трат платного баланса. Ни RPM, ни RPD, ни токенной квоты нигде нет.

Поэтому я замерил поведение сам, обычными запросами к `https://opencode.ai/zen/v1/chat/completions`:

```
req1  HTTP 200   0.75s
req2  HTTP 200   0.76s
req3  HTTP 200   0.70s
req4  HTTP 200   0.98s
req5  HTTP 429   0.44s   ← лимит
req6  HTTP 429   0.47s
```

Тело ответа с ошибкой:

```json
{"type":"error","error":{
  "type":"FreeUsageLimitError",
  "message":"Error from provider (Console): Rate limit exceeded. Please try again later."}}
```

**Что удалось установить:**

| Наблюдение | Результат |
| :--- | :--- |
| Запросов до срабатывания лимита | **4 подряд** |
| Тип ошибки | `FreeUsageLimitError`, HTTP 429 |
| Заголовки `RateLimit-*` / `Retry-After` | **отсутствуют** — сколько ждать, не сообщается |
| Восстановление | проверки на 60 с, 120 с, 240 с и ~10 мин — **везде 429** |
| Лимит по каждой модели отдельно? | **Нет, общий**: после блокировки `deepseek-v4-flash-free` модель `mimo-v2.5-free` тоже отдавала 429 |
| Источник лимита | по тексту ошибки — вышестоящий провайдер, не сам Zen |

> [!warning] Оговорка к замеру, важная для честности
> Я тестировал **без API-ключа** (см. следующий пункт — бесплатные модели отвечают и так). С зарегистрированным аккаунтом и ключом лимиты, скорее всего, выше. Проверить это я не могу: заводить аккаунт от вашего имени не стал.
>
> Но вывод от этого не меняется: **никакой публично объявленной квоты не существует**, лимит нигде не документирован, ответ 429 не сообщает время ожидания, и провайдер вправе изменить всё это в любой момент. Планировать на этом рабочий процесс нельзя.

### Неожиданное: ключ вообще не нужен

Запрос к бесплатной модели **вообще без заголовка `Authorization`** возвращает HTTP 200 и нормальный ответ:

```bash
curl -s -X POST "https://opencode.ai/zen/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v4-flash-free","messages":[{"role":"user","content":"hi"}],"max_tokens":5}'
# → HTTP 200, {... "cost":"0"}
```

При этом запрос с **неверным** ключом даёт 401 `AuthError`. То есть отсутствие ключа проходит, а плохой ключ — нет.

Практический смысл: весь ритуал из поста («залогиниться, сгенерировать ключ») для бесплатных моделей избыточен. И раз аккаунт не участвует, персональной квоты у вас нет — лимит общий и, судя по всему, привязан к IP.

## 5. Готовые конфиги под агентов

Ниже — рабочие конфигурации. Обратите внимание на протокол: **везде `https://`**.

### OpenCode

Файл `opencode.json` в корне проекта или `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "zen-free": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "OpenCode Zen (free)",
      "options": {
        "baseURL": "https://opencode.ai/zen/v1"
      },
      "models": {
        "deepseek-v4-flash-free":     { "name": "DeepSeek V4 Flash (free)" },
        "mimo-v2.5-free":             { "name": "MiMo V2.5 (free)" },
        "nemotron-3.5-lightning-free":{ "name": "Nemotron 3.5 Lightning (free)" }
      }
    }
  }
}
```

Дальше `/connect` в TUI (идентификатор провайдера должен совпасть с ключом в конфиге) и `/models` для выбора.

### Codex CLI

Файл `~/.codex/config.toml`:

```toml
model = "deepseek-v4-flash-free"
model_provider = "zen-free"

[model_providers.zen-free]
name = "OpenCode Zen (free)"
base_url = "https://opencode.ai/zen/v1"
env_key = "OPENCODE_ZEN_API_KEY"
wire_api = "chat"
```

> [!caution] `wire_api` здесь обязательно `"chat"`
> В примерах документации Codex часто стоит `wire_api = "responses"` — это формат GPT-моделей. Бесплатные модели Zen живут на `/v1/chat/completions`, поэтому нужен именно `"chat"`. С `"responses"` вы получите ошибку, которая выглядит как «модель не найдена».

Ключ кладём в переменную окружения (в `~/.bashrc`):

```bash
export OPENCODE_ZEN_API_KEY='ваш_ключ'
```

### Cursor

Settings → Models → Add custom model / OpenAI API Key:

```
Base URL:  https://opencode.ai/zen/v1
API Key:   ваш ключ
Model:     deepseek-v4-flash-free
```

Cursor переопределяет провайдера глобально, поэтому встроенные модели Cursor при включённом override перестанут работать — переключаться придётся вручную.

### Claude Code

> [!warning] Напрямую не заработает
> Claude Code общается по формату **Anthropic Messages** (`/v1/messages`). Zen такой эндпоинт предоставляет, но **только для платных моделей**; все восемь бесплатных доступны исключительно через `/v1/chat/completions`. Просто прописать `ANTHROPIC_BASE_URL` недостаточно — форматы запроса и ответа разные.

Нужен переходник, преобразующий Anthropic ↔ OpenAI. Проще всего — [LiteLLM](LiteLLM%20%E2%80%94%20%D0%B5%D0%B4%D0%B8%D0%BD%D1%8B%D0%B9%20%D1%88%D0%BB%D1%8E%D0%B7%20%28proxy%29%20%D0%BA%20100%2B%20LLM.md):

```yaml
# litellm-zen.yaml
model_list:
  - model_name: zen-free
    litellm_params:
      model: openai/deepseek-v4-flash-free
      api_base: https://opencode.ai/zen/v1
      api_key: os.environ/OPENCODE_ZEN_API_KEY
```

```bash
litellm --config litellm-zen.yaml --port 4000
export ANTHROPIC_BASE_URL=http://localhost:4000
export ANTHROPIC_AUTH_TOKEN=любая_строка
claude
```

Честная оценка: городить прокси ради модели уровня DeepSeek Flash, чтобы кормить ей код в обмен на обучение, — сомнительная затея. Claude Code разумнее оставить на нормальной модели, а Zen (если он вам нужен) использовать из OpenCode или Codex.

## 6. Безопасность: три вещи, которые легко сделать неправильно

**1. Протокол.** В посте базовый URL указан как `http://opencode.ai/zen/v1` — Telegram автоматически превратил текст в ссылку без TLS. Домен на обычном HTTP отвечает и не редиректит на HTTPS. Если вписать такой Base URL в агент, **API-ключ уйдёт по сети открытым текстом**. Всегда `https://`.

**2. Ключ там, где он не нужен.** Бесплатные модели работают без авторизации. Не вписывайте ключ в конфиги, которые потом окажутся в репозитории, — для бесплатных моделей он не даёт ничего.

**3. Ключ в файле конфигурации.** Codex и OpenCode умеют читать ключ из переменной окружения. Используйте `env_key`, а не строку в JSON, который легко закоммитить. Проверьте `.gitignore`.

## 7. Что нельзя отправлять в бесплатные модели

Раз данные явным образом идут на обучение, вопрос перестаёт быть теоретическим. Практический чеклист.

> [!danger] Категорически нельзя
> - **Рабочие репозитории под NDA** — код, схемы БД, бизнес-логика, внутренние API
> - **Секреты в любом виде** — `.env`, ключи API, токены, приватные ключи, строки подключения, сертификаты
> - **Персональные данные** — дампы с ФИО, телефонами, почтами, адресами; для NVIDIA-эндпоинтов это ещё и прямо запрещено их условиями
> - **Медицинские, финансовые и юридические документы**
> - **Проприетарные алгоритмы**, ради которых проект вообще существует
> - **Инфраструктурные конфиги** — топология сети, правила фаервола, доступы

**Можно относительно спокойно:** учебные задачи, публичный open-source код (он и так в интернете), генерация шаблонного кода без контекста проекта, разовые вопросы по языку и библиотекам, черновые заметки без чувствительного содержания.

### Как ограничить агента технически

Агенты кода читают файлы сами, поэтому «я просто не буду вставлять секреты» не работает — агент вставит их за вас. Минимальная защита:

```bash
# 1. Отдельный каталог под эксперименты с бесплатными моделями,
#    вне рабочих репозиториев
mkdir -p ~/sandbox-zen && cd ~/sandbox-zen

# 2. Проверить, что в проекте нет секретов, прежде чем пускать туда агента
grep -rIl --exclude-dir=.git -E '(API_KEY|SECRET|PASSWORD|TOKEN|BEGIN [A-Z ]*PRIVATE KEY)' . | head
```

В OpenCode ограничения задаются через `permission` в конфиге — например, запретить чтение за пределами каталога проекта. В Claude Code для этого есть `.claude/settings.json` с `permissions.deny`. Общий принцип: **если модель обучается на входе, вход должен быть таким, который не жалко опубликовать.**

Отдельно полезно: в Zen для команд есть управление доступом к моделям — админ workspace может **отключить конкретные модели**, и документация прямо называет это сценарием *«disable the use of a model that collects data»*. То есть сам вендор считает это осмысленной мерой.

## 8. Сравнение с альтернативами

Бесплатный доступ к моделям есть у многих. Существенно различаются условия по данным.

| Провайдер | Карта нужна? | Лимиты бесплатного уровня | Обучение на ваших данных |
| :--- | :---: | :--- | :--- |
| **OpenCode Zen (free)** | нет | **не документированы**; замер — 4 запроса подряд, дальше 429 больше 10 минут | ⚠️ **да, по документации для всех 8 моделей** |
| **OpenRouter** (`:free`) | нет | 20 запросов/мин; 50/сутки, а при пополнении от 10 кредитов — 1000/сутки | ⚙️ настраивается: в аккаунте есть **раздельные переключатели** «разрешить провайдеров, которые обучаются на данных» для платных и бесплатных моделей |
| **Gemini API** (free) | нет | квоты по моделям, публично документированы | ⚠️ **да**: условия Google для Unpaid Services — контент используется «to provide, improve, and develop Google products». На платном уровне явно нет |
| **Groq** | нет | бессрочный бесплатный уровень, ограничен частотой запросов | ✅ по заявлениям — не обучается; формально регулируется Services Agreement и DPA, в публичной политике конфиденциальности прямой формулировки нет |

**Вывод из таблицы.** Zen выделяется в худшую сторону не тем, что обучается на данных — так делают Google и многие другие на бесплатных уровнях, — а тем, что **лимиты нигде не объявлены**. У OpenRouter и Gemini вы заранее знаете, сколько запросов получите; у Zen узнаёте методом получения 429 без указания времени ожидания.

Если нужен именно бесплатный доступ с наименьшими вопросами к приватности — **Groq** выглядит предпочтительнее. Если важна предсказуемость лимитов — **OpenRouter**. Zen же по-настоящему хорош в своей основной, платной роли: единый шлюз с честными ценами без наценки и с нулевым хранением на платных моделях.

## 9. Итог

**Что в посте правда:**
- Бесплатные модели существуют, ID указаны верно, формат `chat/completions` для них правильный.
- Регистрация действительно без карты и телефона, через GitHub или Google.
- Совет брать точные Model ID из документации, а не с дашборда, — верный.
- Подключить к Codex или Cursor кастомным провайдером — да, работает.

**Что в посте неправда или умолчано:**
- **«Миллиард токенов» — вымысел.** Никакой токенной квоты не существует ни в каком виде.
- Реальный лимит — по частоте запросов, нигде не опубликован, наступает быстро и снимается небыстро.
- **Умолчано главное:** документация Zen явным образом выводит все восемь бесплатных моделей из-под нулевого хранения, а два NVIDIA-эндпоинта письменно просят не отправлять конфиденциальные данные.
- `big-pickle` — открытое тестирование stealth-модели на пользователях, а не подарок.
- Base URL в посте дан по `http://`, что означает передачу ключа открытым текстом.
- Экономия составляет единицы-десятки долларов в месяц: платная версия той же DeepSeek V4 Flash стоит $0.14 за миллион входных токенов и при этом не обучается на вас.

**Кому подойдёт:** для учёбы, пет-проектов, публичного open-source и разовых экспериментов — вполне рабочий бесплатный ресурс, особенно как способ пощупать модель перед покупкой. Для этого он и задуман.

**Кому не подойдёт:** любому рабочему коду. И если уж пользоваться Zen всерьёз — платный уровень с нулевым хранением стоит копейки и снимает весь этот раздел вопросов целиком.
