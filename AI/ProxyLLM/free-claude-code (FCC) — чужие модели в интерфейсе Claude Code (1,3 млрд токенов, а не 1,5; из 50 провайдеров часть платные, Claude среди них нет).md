# free-claude-code (FCC) — чужие модели в интерфейсе Claude Code

Локальный прокси на Python, который поднимается на `localhost:8082`, притворяется API Anthropic и переводит запросы к 50 другим провайдерам. Клиент настраивается двумя переменными:

```json
{ "ANTHROPIC_BASE_URL": "http://localhost:8082",
  "ANTHROPIC_AUTH_TOKEN": "freecc" }
```

Пост в «Не баг, а фича»: *«Claude Code, Codex, Hermes и других агентов сделали БЕСПЛАТНЫМИ… 1,5 миллиарда бесплатных токенов в месяц»*. Показательно, что топовая реакция под самим постом — 😁 (70 штук) при 👎 7: аудитория поняла подвох раньше, чем автор.

## Главное недоразумение: Claude бесплатным не стал

Заголовок поста читается как «Claude раздают даром». Это не так, и понять это можно за минуту.

**Anthropic отсутствует в списке 50 провайдеров.** Совсем. FCC не даёт доступа к Opus, Sonnet, Haiku или Fable — он подменяет собой их API, чтобы **клиент** Claude Code продолжал работать, а отвечали ему модели Qwen, DeepSeek, GLM, Gemini, Llama, Kimi и прочие. В README это сформулировано аккуратно: *«route Fable, Opus, Sonnet, and Haiku independently **with compatible models**»* — то есть слоты моделей Claude Code сопоставляются с чужими моделями.

Сам репозиторий сразу под шапкой пишет: *«Independent open-source project. Not affiliated with or endorsed by Anthropic. Claude and Claude Code are trademarks of Anthropic.»*

Формально бесплатны и сами агенты — CLI Claude Code, Codex, Aider и остальные скачиваются бесплатно и без FCC. Платными их делают именно модели. Так что «агентов сделали бесплатными» — подмена: бесплатной стала не программа, а замена её мозгов.

## Из чего состоят «50 провайдеров»

Каталог в README — таблица ровно на 50 строк. Разложение по смыслу:

- **Локальные, а не «бесплатные провайдеры»:** Ollama, LM Studio, llama.cpp — здесь всё считает ваше железо.
- **Платные и подписочные:** OpenAI / ChatGPT, GitHub Copilot, xAI (Grok), QwenCloud Coding Plan, Azure OpenAI, Google Vertex AI, Amazon Bedrock, Vercel AI Gateway, DeepSeek, Z.ai Coding Plan, Z.ai API (pay as you go), Poolside AI, Kimi Code, Ollama Cloud.
- **С реальными бесплатными тарифами:** NVIDIA NIM, OpenRouter, Groq, Google AI Studio, Cerebras, SambaNova, Cloudflare Workers AI, Hugging Face Inference Providers, Together, DeepInfra, SiliconFlow, Nebius, Chutes, Featherless, ZenMux, W&B Inference, OpenCode Zen/Go, Kilo.ai, TokenRouter, NaraRoute, LLM7.io, Mistral и другие.

И ключевое, что пост опускает: **ключи вы заводите сами**. FCC ничего не раздаёт — README для каждой строки даёт ссылку «сходи и получи свой ключ». Чтобы приблизиться к обещанным миллиардам токенов, нужно зарегистрироваться в двух десятках сервисов и вручную развесить их по слотам моделей.

## Чем на самом деле платишь

Это самая важная часть, которой в посте нет ни слова. Бесплатные тарифы бесплатны не просто так: у большинства из них данные уходят на улучшение моделей.

В базе знаний это уже проверено на двух провайдерах, которые входят в список FCC, — см. [OpenCode Zen — реальные лимиты и чем платишь вместо денег](OpenCode%20Zen%20%E2%80%94%20%D0%B1%D0%B5%D1%81%D0%BF%D0%BB%D0%B0%D1%82%D0%BD%D1%8B%D0%B5%20%D0%BC%D0%BE%D0%B4%D0%B5%D0%BB%D0%B8%20%D0%B4%D0%BB%D1%8F%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82%D0%BE%D0%B2%20%D0%BA%D0%BE%D0%B4%D0%B0%20%28%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B0%20%C2%AB%D0%BC%D0%B8%D0%BB%D0%BB%D0%B8%D0%B0%D1%80%D0%B4%D0%B0%20%D1%82%D0%BE%D0%BA%D0%B5%D0%BD%D0%BE%D0%B2%C2%BB%20%E2%80%94%20%D1%80%D0%B5%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B5%20%D0%BB%D0%B8%D0%BC%D0%B8%D1%82%D1%8B%20%D0%B8%20%D1%87%D0%B5%D0%BC%20%D0%BF%D0%BB%D0%B0%D1%82%D0%B8%D1%88%D1%8C%20%D0%B2%D0%BC%D0%B5%D1%81%D1%82%D0%BE%20%D0%B4%D0%B5%D0%BD%D0%B5%D0%B3%29.md): у OpenCode Zen все бесплатные модели выведены из-под политики нулевого хранения (*«During its free period, collected data may be used to improve the model»*), а эндпоинты NVIDIA снабжены отдельной пометкой *«Trial use only — do not submit personal or confidential data»*.

Кодинг-агент отправляет провайдеру не отдельные вопросы, а **содержимое файлов проекта**. Практический вывод тот же, что и в той заметке: рабочие репозитории с секретами и NDA-кодом через бесплатные тарифы не гонять.

Отдельно стоит отметить, что сами авторы FCC ведут себя аккуратнее, чем пост: у них заявлено *«ToS-friendly»*, обещание убирать интеграции, если провайдер перестаёт их разрешать, и оговорка *«Free-tier availability and limits are controlled by each provider and may change»*. В трекере репозитория я искал жалобы на блокировки аккаунтов — **подтверждённых репортов о банах нет**, совпадения по словам `ban`/`suspended` оказались текстом внутри несвязанных issue и PR.

## Про «−90 % токенов»

Экономию даёт **RTK** — отдельный проект [`rtk-ai/rtk`](https://github.com/rtk-ai/rtk) (Apache-2.0, Rust, 79 615 звёзд), который FCC предлагает поставить опционально. Его собственное описание: *«CLI proxy that reduces LLM token consumption by **60-90 %** on common dev commands»*. То есть он фильтрует вывод типовых команд (сборки, тесты, `ls` и подобное), чтобы простыни логов не улетали в контекст.

Плюс пять собственных оптимизаций FCC, которые отвечают без обращения к провайдеру: проверки квоты, определение префикса команды, заголовки, подсказки и пути к файлам.

Вещь полезная и честно описанная — но «экономия токенов 90 %» из поста звучит как «ваш диалог станет в 10 раз дешевле», а речь про верхнюю границу диапазона на одном классе данных.

## Что в проекте объективно хорошо

- **MIT**, исходники полные, дисклеймер про непричастность Anthropic на видном месте.
- Инженерная гигиена видна по бейджам и конфигам: `pytest`, тайп-чекер `ty`, форматтер `ruff`, логирование `loguru`, зависимости через `uv` с `uv.lock`, каталоги `tests/`, `e2e/`, `smoke/`.
- **10 агентов** из коробки: Claude Code, Codex, Pi, OpenCode, Cline, Hermes, DeepSeek Harness, Grok Build, Muse Code, Aider — установщик заводит их обёртками `fcc-claude`, `fcc-codex`, `fcc-pi` и так далее.
- Прокси можно закрыть bearer-токеном (**Proxy Authentication** в админке) — не оставляйте его открытым, если машина не только ваша.
- Установщики предлагают ознакомиться с собой до запуска, и это не пустая формальность: `install.sh` — 1423 строки.

## Установка на своих системах

Официальный путь — скрипт, который ставит `uv`, тянет Python 3.14 и разворачивает выбранных агентов:

```bash
curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh
```

Запуск того же скрипта повторно = обновление. Флаги: `--rtk`, `--voice-local`, `--voice-nim`, `--voice-all`, `--torch-backend cu130`.

| Система | Как | Нюанс |
| :--- | :--- | :--- |
| **Gentoo** (основная) | Python 3.14 в дереве есть (`dev-lang/python`, там же уже 3.15 в rc), `uv` тоже: `emerge -av dev-lang/python dev-python/uv`. Дальше можно не запускать чужой скрипт из интернета, а склонировать репозиторий и поднять через `uv sync` | Сборка из исходников тут естественна: чистый Python, зависимости фиксированы в `uv.lock` |
| **Debian / Ubuntu** | В штатных репозиториях Python 3.14 обычно ещё нет — тогда официальный скрипт подходит лучше всего, `uv` скачает нужный интерпретатор сам | Перед `curl … | sh` стоит открыть `install.sh` глазами |
| **Arch** | `pacman -S python uv`, дальше клон и `uv sync`. Отдельного пакета в AUR нет | — |
| **Entware (ASUS RT-AX56U, armv7)** | ❌ Не вариант. В репозитории armv7 `python3` версии **3.13.9**, а нужен **≥ 3.14.0**. Плюс на 512 МБ ОЗУ держать FastAPI-прокси с десятком агентов бессмысленно | Версия проверена по `Packages` для `armv7sf-k3.2` |

Порт по умолчанию `8082`, токен `freecc` — оба меняются в админке; в конфиге клиента их надо держать согласованными.

## Итог

Проект настоящий, живой и сделан аккуратнее, чем его реклама: MIT, тесты, честные оговорки про лимиты провайдеров и про ToS.

Но заголовок «Claude Code сделали бесплатным» — подмена понятий. **Anthropic в списке 50 провайдеров нет вообще**: бесплатным становится не Claude, а интерфейс Claude Code, к которому подключают чужие модели. Токенов не 1,5 миллиарда, а «1.3B+» по словам самих авторов, без единой публичной разбивки. Провайдеров 50, но бесплатные — не все: трое локальные, полтора десятка платные или подписочные. «Экономия 90 %» — верхняя граница диапазона 60–90 % у стороннего RTK и только на выводе команд.

И главное, о чём пост молчит: ключи вы регистрируете сами в двух десятках сервисов, а бесплатные тарифы у большинства из них означают, что **отправленный агентом код может пойти на обучение моделей**.

Как способ погонять разные модели в привычном интерфейсе на пет-проектах — годится. Как «бесплатный Claude для работы» — нет.
