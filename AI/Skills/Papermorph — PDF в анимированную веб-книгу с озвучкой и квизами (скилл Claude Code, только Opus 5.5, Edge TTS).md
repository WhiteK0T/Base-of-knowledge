# Papermorph — PDF-учебник в анимированную веб-книгу с озвучкой

> [!info] Что это
> **Скилл для Claude Code** (`SKILL.md` + скрипты на Python + JS-движок), который по PDF-книге собирает **статический сайт-учебник**. Каждая глава — анимированная SVG-сцена 1600×900 с озвучкой, субтитрами, проверочными вопросами внутри картинки и итоговой практикой со счётом. Бэкенда, БД и аккаунтов нет. Прогресс читателя хранится в `localStorage`.
>
> Пост в канале «Не баг, а фича» (2026-10-05) описывает суть верно. Он не говорит о четырёх вещах: работает только с **Opus 5.5**, озвучка идёт через **неофициальный Edge TTS**, книгу делают **по главам с вашим участием**, а демо-книги сделаны **по коммерческим учебникам**.

## 3. Как это работает

### Конвейер (из `SKILL.md`)

1. **Intake.** Скилл выбирает slug, создаёт `books/<книга>/BOOK.md` и спрашивает: кто читатели, тон, язык, объём, ассеты.
2. **Split.** `outline.py` достаёт оглавление PDF через PyMuPDF и строит `sections.json`. Если в PDF нет закладок, `split_pages.py` рендерит первые страницы, и карту составляют по ним. Текст глав извлекается в `pages/chNN/text.md`.
3. **Book map.** `chapters.md` с колонками `# | Title | Unit | Minutes | Status`, палитра и повторяющиеся визуальные модели. **Список глав и визуальный подход утверждаете вы.**
4. **Initialize.** Копируются движок, обложка/оглавление и шаблон главы.
5. **Pilot.** Глава 1 целиком. Вы её смотрите, принятые решения записываются в `BOOK.md` как конвенции.
6. **Остальные главы** по очереди, затем обложка, оглавление, эскизы разделов.

### Цикл одной главы

| Шаг | Что происходит |
| :--- | :--- |
| Read | Читается `text.md` главы; страницы с диаграммами рендерятся в PNG |
| Storyboard | `chapters/chNN.md`: список «битов», что меняется на картинке, на каких словах срабатывает анимация, вопросы |
| Narration | `narration.<lang>.json` → `tts.py` (Edge TTS) → MP3 на каждый бит + `timings.js` |
| Beats | Реализация в `site/<книга>/chNN/index.html` через API движка |
| Delivery pass | Playwright-скриншоты 4-в-1 (`shot.py`), проверка «пустого экрана» (`check_blank.py`), громкость (`check_volume.py`); явные дефекты Claude правит сам |
| Register | Глава добавляется в оглавление, обновляется статус |

### Синхронизация анимации с голосом

В тексте озвучки ставятся метки `[[mark]]` перед словом:

```json
{
  "voice": "en-US-AndrewMultilingualNeural",
  "rate": "-4%",
  "beats": {
    "idea": "Say the idea while the picture shows it. [[note]]The mark goes right before the word the animation waits for."
  }
}
```

`tts.py` запрашивает у Edge TTS события `WordBoundary` (время каждого слова). Из них он пишет в `timings.js` момент начала слова после каждой метки и субтитры по предложениям. Анимация ждёт нужного слова. Аудио пересинтезируется только для изменённых битов (кэш по SHA-1 от голоса, скорости и текста).

### Структура главы (`references/authoring.md`)

`intro` → учебные биты (одна идея на бит, 5–40 с) → `q1`, `q2`… (проверки между битами) → `wrap` (3–4 вывода) → `final1…N` («Chapter practice N of M») → `finish` (карточка со счётом с первой попытки).

Педагогические правила оттуда же: открывать бит сразу с предмета (движок сам сдвигает группу, если первые 0,8 с пусто); одна новая вещь за раз; один цвет — один смысл; всё в масштабе, а приближения писать как `≈`; показывать типичную ошибку, перечёркивать её и затем давать верный путь.

## 4. Установка и запуск

### Зависимости

`SKILL.md` требует: **`uv`**, **`ffmpeg`/`ffprobe`**, сетевой доступ к **Edge TTS**, **Playwright Chromium**. Для установки через `npx skills` нужен ещё **Node.js**. И, конечно, Claude Code с доступом к Opus 5.5.

| Система | Команды |
| :--- | :--- |
| **Gentoo** | `emerge --ask dev-python/uv media-video/ffmpeg net-libs/nodejs` (`dev-python/uv` есть в основном дереве). `edge-tts` и `pymupdf` ставить не нужно: скрипты тянут их сами через `uv run --with …` |
| **Debian / Ubuntu** | `apt install ffmpeg nodejs npm python3`; `uv` — официальным установщиком `curl -LsSf https://astral.sh/uv/install.sh \| sh` или `pipx install uv` |
| **Arch** | `pacman -S uv ffmpeg nodejs npm` |
| **Entware** | Не для роутера: нужны Claude Code, Chromium и Opus. Но **готовую книгу** (статику) можно раздавать с USB-диска роутера, см. раздел 7 |

Браузер для проверок (на всех дистрибутивах):

```bash
uv run --with playwright playwright install chromium
```

> [!warning] Gentoo и Playwright
> `playwright install` качает сборку Chromium под Ubuntu. `playwright install-deps` на Gentoo и Arch не работает: он вызывает `apt`. Если Chromium не стартует, недостающие библиотеки ставьте вручную по ошибке `ldd`. Обычно все они уже есть в системе, где стоит Firefox или Chromium.

### Установка скилла

```bash
cd ~/my-book-project
npx skills add DozenTwelve/Papermorph --skill papermorph --agent claude-code
```

Так ставится только папка скилла (~252 КБ). **Не клонируйте весь репозиторий ради скилла:** это ~320 МБ демо-аудио.

### Запуск (Claude Code, модель Opus 5.5)

```text
/papermorph Turn /path/to/book.pdf into
an animated interactive web book.

Target readers: [ваша аудитория].
Start with one English chapter for review.
```

### Просмотр

```bash
python3 -m http.server 8765 -d site
# открыть http://localhost:8765/<книга>/
```

Нужен именно HTTP-сервер, а не `file://`: иначе не играет аудио. В `references/review.md` есть нюанс: встроенный сервер Python не поддерживает Range-запросы, поэтому перемотка аудио на нём может работать плохо. Для публикации берите nginx, Caddy или lighttpd.

Посмотреть готовые демо без установки: https://papermorph.diamonddoge.org/ (на 2026-10-08 отвечает `200`).

## 5. А на русском можно?

В README написано: «No … multilingual support yet». Это про **одновременную** поддержку нескольких языков в книге. Сделать книгу **на одном другом языке** скилл позволяет: `site.md` говорит выбрать основной язык, переименовать `narration.<lang>.json`, выставить `CHAPTER.language` и перевести тексты интерфейса до пилота.

Проверено 2026-10-08: в Edge TTS есть русские голоса `ru-RU-DmitryNeural` и `ru-RU-SvetlanaNeural`, синтез работает без ключа:

```bash
uvx edge-tts --list-voices | grep ru-RU
uvx edge-tts --voice ru-RU-SvetlanaNeural --text "Проверка озвучки." --write-media test.mp3
```

Чего я **не** проверял: полную главу на русском. Есть два риска. Во-первых, разбиение субтитров в `tts.py` режет предложения по `[.?!]`, для русского это нормально. Во-вторых, сопоставление меток со словами ищет слово из `WordBoundary` в тексте подстрокой. Если Edge нормализует числа и формулы («3x + 2»), метка может не найтись, и скрипт упадёт с `mark … not matched`. Тогда ставьте метку перед обычным словом. В промпте задайте язык явно: «Narration and UI in Russian, voice ru-RU-SvetlanaNeural».

## 6. Подводные камни

> [!warning] Что важно знать до запуска
> - **Только Opus 5.5.** В README прямо: «Today: Opus 5.5 only». Sonnet или чужие агенты (через `npx skills` скилл ставится и туда) могут выдать сломанные анимации.
> - **Edge TTS — неофициальный канал.** Библиотека `edge-tts` ходит в бесплатный эндпоинт озвучки из браузера Microsoft Edge, без ключа и без SLA. Microsoft может закрыть или ограничить его в любой момент, и тогда весь шаг озвучки встанет. Для коммерческого использования это серая зона.
> - **Авторское право.** Скилл по умолчанию **пересоздаёт** объяснения, примеры и рисунки, а не копирует их. PDF и извлечённые страницы держит вне сайта и вне git (`.gitignore`: `*.pdf`, `books/*/pages/`). Но производная книга по чужому учебнику остаётся производной. Демо автора помечены как «Inspired by *Everything You Need to Ace Math / Pre-Algebra and Algebra 1 in One Big Fat Notebook*» — это коммерческие книги Workman Publishing (Hachette). Для публичного сайта берите материалы с открытой лицензией (например, OpenStax, CC BY) или свои.
> - **Заточено под точные науки.** Все демо — школьная математика. Движок и правила (числовые прямые, сетки, «всё в масштабе») сделаны под STEM. Гуманитарные книги и книжки с картинками — в планах автора, сейчас их нет.
> - **Ревью — на вас.** Скилл сам чинит только очевидные визуальные дефекты: наложения, пустой экран, обрезку. Эстетику, темп и **учебную корректность** оценивает человек. Ответы в квизах тоже стоит проверить.
> - **Тяжёлый результат.** Около 1,3 МБ на главу (в основном MP3). Книга на 60+ глав весит ~90 МБ.

## 7. Раздать готовую книгу

Результат — обычная статика, поэтому подойдёт любой веб-сервер. Главное — поддержка Range-запросов (нужна для перемотки аудио).

**Gentoo (OpenRC), nginx:**
```bash
emerge --ask www-servers/nginx
# в server { … }: root /srv/books;  (скопировать туда site/)
rc-update add nginx default && rc-service nginx start
```

**Debian/Ubuntu / Arch:** `apt install nginx` / `pacman -S nginx`, затем `systemctl enable --now nginx`, корень — `/var/www/html` (Debian) или `/usr/share/nginx/html` (Arch).

**Entware (RT-AX56U, USB-диск):** лёгкий `lighttpd` есть в репозитории Entware:
```sh
opkg update && opkg install lighttpd
# в /opt/etc/lighttpd/lighttpd.conf: server.document-root = "/opt/share/www/books"  (папка на USB)
/opt/etc/init.d/S80lighttpd start
```
Книгу на 60–90 МБ держите на USB-диске, а не во flash роутера.

**Без сервера:** любой статический хостинг (GitHub Pages, Cloudflare Pages). В `.gitignore` автора упоминается `.wrangler/`, то есть сам он публикует на Cloudflare.

## 8. Итог

Papermorph — сильный по замыслу и аккуратно сделанный скилл. Конвейер с пилотом, файловое состояние вместо раздувания контекста, синхронизация анимации со словами через `WordBoundary`, автоматическая скриншот-проверка. Но это **двухдневный проект одного автора**, привязанный к Opus 5.5 и неофициальному TTS. Демо проверены только на школьной математике. Чтобы попробовать, возьмите одну главу открытого учебника, закажите пилот и оцените качество и расход токенов до того, как запускать всю книгу.
