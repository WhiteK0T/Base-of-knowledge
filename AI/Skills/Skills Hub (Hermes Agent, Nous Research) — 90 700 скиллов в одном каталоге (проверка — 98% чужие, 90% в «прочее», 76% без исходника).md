# Skills Hub — официальный каталог скиллов Hermes Agent

> [!info] Короткий вывод
> Каталог **настоящий и официальный** — это страница на сайте Nous Research, часть репозитория [hermes-agent](https://github.com/NousResearch/hermes-agent) (MIT, 235 625 ★). Цифра тоже честная: скачал служебный JSON, на 24.08.2026 там **90 700 записей**. Пост назвал 90 684 — счётчик живой.
>
> Но «разрабы Hermes собрали тысячи умений» — это **не то, что произошло**. Своих скиллов у Hermes **199**: 82 встроенных плюс 117 опциональных. Остальные **90 501 (99,8%) — агрегация чужих реестров**, из них 69 150 у ClawHub и 19 967 у skills.sh. То есть Hermes сделал витрину поверх чужих складов.
>
> Что показал разбор самого каталога (скачал 47,8 МБ JSON и посчитал сам):
> - **82 115 записей из 90 700 (90,5%) лежат в категории `other`** — «190 категорий» из поста существуют, но девять из десяти скиллов не разложены ни по одной;
> - **у 90 501 записи (99,8%) нет ни лицензии, ни версии, ни описания-обзора**. Метаданные есть только у тех самых 199 своих;

> - **17,3% каталога — дубли по имени**. Скиллов с именем `skill` — 66 штук, `test` — 43, `my skill` — 20;
> - **у 76,5% нет ссылки на исходник** — все 69 150 записей ClawHub идут без `sourceUrl`, посмотреть, что за инструкции вы ставите, из каталога нельзя.

## Безопасность: почему 76% без ссылки — это важно

> [!danger] Скилл — это инструкции, которые агент выполнит вашими руками
> Скилл не песочница и не плагин с ограниченными правами. Это markdown с указаниями, который агент читает и выполняет **с вашими правами**: ходит в файлы, запускает команды, лезет в сеть. Установщик `npx skills` в других экосистемах прямо предупреждает: *«Review skills before use; they run with full agent permissions»*.
>
> Теперь сложите это с цифрами каталога:
>
> - **69 150 записей ClawHub идут вообще без `sourceUrl`** — из каталога вы не можете открыть и прочитать, что там написано. Только скопировать `hermes skills install clawhub/<имя>` и надеяться;
> - **у 99,8% нет лицензии** — непонятно, чей это код и на каких условиях;
> - **у 77,8% нет автора** — непонятно, кто это написал;
> - **17,3% — дубли по имени**, то есть на запрос `code-review` вы получите 20 разных скиллов с одинаковым названием и никакого способа отличить хороший от подделки.
>
> Это классическая поверхность для «путаницы имён»: злоумышленнику достаточно залить в ClawHub скилл с популярным именем, и он окажется в общем списке наравне с оригиналом, без автора и без исходника.

Практическое правило: **если скилл нельзя прочитать до установки — не ставьте его**. Записи skills.sh (22% каталога) в этом смысле лучше: у них 100% заполнен `sourceUrl`, и он ведёт на страницу с исходным GitHub-репозиторием. У ClawHub URL выводится вручную — `clawhub.ai/skills/<имя>` открывается, — но в самом каталоге ссылки нет.

## Как этим пользоваться на практике

### Своих 199 — вот они реально документированы

Единственная часть каталога с нормальными метаданными. Что я про них выяснил:

- платформы: macOS — 198, Linux — 195, **Windows — 163**, то есть **36 скиллов под Windows не работают**;
- **25 из 199 (13%) требуют внешних CLI-утилит**: `curl` (7), `python` (5), `jq` (4), `node`, `npx`, плюс экзотика вроде `memo`, `remindctl`, `imsg`, `pygount`;
- **7 требуют ключей API**: `NOTION_API_KEY`, `AIRTABLE_API_KEY`, `SHOPIFY_ACCESS_TOKEN`, `CANVAS_API_TOKEN`, три переменные Microsoft Graph и `TENOR_API_KEY`.

То есть даже «встроенные» скиллы — не всегда «поставил и работает».

### Если вы не в Hermes, а в Claude Code

Кнопка каталога даёт только `hermes skills install`. Но формат `SKILL.md` — открытый стандарт, поэтому обходной путь есть, и он тот же, что я проверял в [заметке про Taste Skill](Taste%20Skill%20%28Leonxlnx%29%20%E2%80%94%2013%20%D1%81%D0%BA%D0%B8%D0%BB%D0%BB%D0%BE%D0%B2%20%D0%BF%D1%80%D0%BE%D1%82%D0%B8%D0%B2%20%D0%98%D0%98-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D0%B8%20%D0%B2%D0%BE%20%D1%84%D1%80%D0%BE%D0%BD%D1%82%D0%B5%D0%BD%D0%B4%D0%B5%20%28%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B0%20%E2%80%94%2022k%20%D1%82%D0%BE%D0%BA%D0%B5%D0%BD%D0%BE%D0%B2%2C%20%D0%BA%D0%B8%D1%80%D0%B8%D0%BB%D0%BB%D0%B8%D1%86%D0%B0%2C%20%D0%B2%D1%8B%D0%B4%D1%83%D0%BC%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5%20%D0%B8%D1%81%D1%81%D0%BB%D0%B5%D0%B4%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F%29.md):

```bash
# 1. нашли скилл в каталоге, у записи есть sourceUrl вида
#    https://skills.sh/<автор>/<репо>/<скилл>
# 2. ставим установщиком Vercel (76 агентов, включая Claude Code)
npx skills add https://github.com/<автор>/<репо> --skill "<имя>" -a claude-code
```

Либо совсем вручную — скилл это просто папка с `SKILL.md`:

```bash
mkdir -p ~/.claude/skills/<имя>
curl -sL https://raw.githubusercontent.com/<автор>/<репо>/main/skills/<имя>/SKILL.md \
  -o ~/.claude/skills/<имя>/SKILL.md
```

Второй способ вдобавок **заставляет вас открыть файл глазами** — что при 76% непроверяемого каталога скорее плюс.

> [!tip] Помните про цену контекста
> Как я мерил в заметке про Taste Skill, флагманский скилл там весит 21 912 токенов при каждом срабатывании. Постоянно в контексте висят только заголовки (~75 токенов на скилл), так что держать много установленных скиллов дёшево — но каждый **сработавший** скилл вы оплачиваете целиком. Ставить «90 тысяч скиллов на всякий случай» не только небезопасно, но и бессмысленно.

### Просмотр каталога

Страница <https://hermes-agent.nousresearch.com/docs/skills> открывается в любом браузере, регистрации не требует. Учтите 8,2 МБ трафика на загрузку. Если хотите работать с каталогом локально и без браузера — данные лежат открыто:

```bash
curl -sL -o skills.json  https://hermes-agent.nousresearch.com/docs/api/skills.json
curl -sL -o meta.json    https://hermes-agent.nousresearch.com/docs/api/skills-meta.json

# например: только записи с ссылкой на исходник и без категории «other»
jq '[.[] | select(.sourceUrl != "" and .category != "other")] | length' skills.json
```

Это, на мой взгляд, самый практичный способ: отфильтровать 90 тысяч записей до пары сотен, у которых есть автор, ссылка и вменяемое описание, и уже их смотреть руками.

## Установка Hermes по системам

Если хотите пользоваться каталогом штатно, нужен сам агент. Hermes — Python-проект (MIT, 235 625 ★, коммиты идут сегодня).

| Система | Как | Примечание |
