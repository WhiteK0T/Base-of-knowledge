# 🎨 ai-design-skills (elayadesign) — скиллы для лендингов и Figma

[**ai-design-skills**](https://github.com/elayadesign/ai-design-skills) — набор скиллов дизайнера Elaya для ИИ-агентов кода: лендинги с готовой визуальной системой и работа в Figma. Формат — `SKILL.md`, подходит для Claude Code, Cursor, Codex, Windsurf и любого агента, который читает правила из markdown. Заметка по посту [«Не баг, а фича»](https://t.me/bugnotfeature/28643) от 27 октября 2026 года, сверена с репозиторием.

## 1. Что в наборе

### `landing-page-design` — лендинг с нуля

Две части, сначала первая.

**Часть A — стратегия и структура:**
- **Знакомство с продуктом.** Агент одним списком спрашивает недостающее:
  - целевое действие и что считать конверсией;
  - аудитория и её главные возражения;
  - откуда трафик и что посетитель уже знает;
  - доказательства: логотипы, отзывы, цифры;
  - ограничения: тон, стиль, приоритет мобильной версии.

  Если ответа нет, агент делает допущение, называет его одной строкой и продолжает.
- **Структура страницы и выбор раскладки.**
- **Правила конверсии и тексты.** Пишет продающий текст страницы, а не посты для соцсетей, как можно понять из поста.
- **Порядок сборки, SEO и AEO** (оптимизация под ответы ИИ-поисковиков), типичные ошибки.

**Часть B — визуальная система, правила которой «не обсуждаются»:**
- **Типографика.** Только Geist, Manrope, Geist Mono или Poppins, один шрифт на сайт. Запрещены Inter, Roboto, Arial, Open Sans, Helvetica, курсив и вес 900. Шкала размеров и именованные стили текста.
- **Отступы, скругления, фоны** (отдельно для тёмной темы), первый экран, иконки.
- **Анимация.** Своя кривая замедления вместо браузерных `ease` и `linear`, анимируются только `transform` и `opacity`. Обязательно учитывается `prefers-reduced-motion`.
- **Реализм контента:**
  - настоящие тексты вместо «рыбы»;
  - правдоподобные имена и бренды для демо;
  - на странице реального продукта — **никаких выдуманных фактов**: цены, отзывы и цифры только от пользователя, иначе явная заглушка;
  - список запрещённых штампов вроде «revolutionize» и «supercharge».
- **Состояния элементов, требования к сдаче, проверка ширины 390 пикселей.**
- **Обязательная секция с тэглайном.** Крупный текст ниже первого экрана, слова которого по одному проявляются при прокрутке.

В конце — формат ответа и чек-лист.

### `figma-designer` — работа в Figma «как дизайнер»

Правила работы в Figma: настоящие переменные (отступы, скругления, цвета в два слоя токенов), именованные стили текста, auto layout, компоненты со всеми состояниями. Плюс фрейм Foundations, который обновляется вместе с токенами. Шкалы — по Tailwind, в конце полный справочник токенов.

Скилл работает **поверх официального Figma MCP и скиллов Figma** (`figma-use`, `figma-generate-design`, `figma-generate-library`) и без них бесполезен: он добавляет только дизайнерские правила.

## 2. Что за словами поста

- **«Ультимативный набор».** На сегодня это два скилла. Третий, `design-to-motion`, появился 25 октября, а 27 октября — в день поста — его вынесли «в отдельный репозиторий». У автора такого публичного репозитория нет, адрес `elayadesign/design-to-motion` отвечает 404. Скилл остался только в истории коммитов (`5e57840`).
- **«Скилл, превращающий скрины и макеты из Figma в анимацию».** Это как раз `design-to-motion` — в текущем наборе его нет. `figma-designer` (добавлен 1 ноября) делает другое: рисует в Figma по правилам.
- **«Почти всё автономно».** Работа начинается с вопросов о продукте. Отвечать не обязательно — агент сделает допущения, но качество лендинга от этих ответов и зависит.
- **«Напишет SMM».** Скилл пишет тексты самой страницы и SEO, а не контент для соцсетей.
- **«Свои стили меняем в одном блоке»** — да, значения дизайна собраны в одном разделе в конце каждого файла. Правите его в своей копии, остальное следует за ним.
- **«Работает с Claude Code, Cursor, Codex, Windsurf»** — да, это обычный markdown.

## 3. На что обратить внимание

- **Очень широкий триггер.** Описание `landing-page-design` велит подключать его для **любой** страницы, маркетингового сайта, веб-интерфейса, секции, компонента или прототипа, «даже если пользователь не упоминает дизайн». Установленный в проект, он будет навязывать свои шрифты, отступы и обязательную секцию с тэглайном и там, где у вас уже есть дизайн-система. Ставьте его в проект лендинга, а не на уровень пользователя (`-g`).
- **Кириллица.** Из разрешённых шрифтов Geist, Geist Mono и Manrope поддерживают кириллицу, **Poppins — нет**. Для русского лендинга Poppins в своей копии лучше исключить.
- **Стоимость.** В фоне — только `name` и `description` (~150–180 токенов на скилл). При вызове файл целиком добавляет ~5,5 тыс. токенов в контекст.
- **Реклама в README.** Баннер ведёт на сервис SlopScan: он проверяет готовый сайт по тем же правилам и выдаёт промпт для исправления.

## 4. Установка

Через [skills CLI](https://skills.sh), нужен Node.js (Gentoo — `net-libs/nodejs`, Debian/Ubuntu — `nodejs npm`, Arch — `nodejs npm`):

```bash
npx skills add elayadesign/ai-design-skills --list                          # что есть
npx skills add elayadesign/ai-design-skills --skill landing-page-design     # один скилл в проект
npx skills add elayadesign/ai-design-skills -a claude-code -a cursor        # под какие агенты
npx skills update                                                           # обновить позже
```

Скиллы ложатся в `.claude/skills/` (Claude Code) и в `.agents/skills/` (Cursor, Codex и др.).

Без Node.js — скопировать папку скилла вручную:

```bash
git clone https://github.com/elayadesign/ai-design-skills.git /tmp/ai-design-skills
mkdir -p .claude/skills && cp -r /tmp/ai-design-skills/skills/landing-page-design .claude/skills/
```

Для Codex, Windsurf и Cline файл `SKILL.md` вставляют в `AGENTS.md`, `.windsurfrules` или `.clinerules`. Учтите, что так он попадёт в контекст целиком и постоянно, а не только при вызове.
