# human-review — визуальное ревью HTML/Markdown от AI-агента

> [!info] Короткий вывод
> **Инструмент настоящий, живой и делает ровно то, что обещает.** Это скилл (`SKILL.md`), который учит ИИ-агента (Claude Code, Codex и др.) открывать сгенерированный им HTML- или Markdown-файл в **локальном визуальном редакторе в браузере**. Ты правишь текст прямо на странице, оставляешь комментарии «как в Google Docs», удаляешь лишние блоки — и одной кнопкой **Send** отправляешь всю пачку правок обратно агенту. Тот применяет их к исходнику и перерисовывает страницу для следующего круга.
>
> **Автор** — Peter Yang (`petergyang`). Репозиторий: 1 236 ★, 98 форков, лицензия **MIT**, стек — **Node.js/JavaScript**. Создан 27.07.2026, последний коммит 04.09.2026 — проект молодой (пара месяцев).
>
> **Локально и без облака — правда.** README прямым текстом: *«Everything runs on your computer. Human Review doesn't require an account, cloud service, database, or API key»*. Подтверждается: MIT, весь код — CLI + локальный сервер + клиент к браузеру, никаких ключей.
>
> Нюансы, которых пост не подчеркнул:
> 1. **Нужен десктоп с браузером.** Клиент управляет Chrome/Chromium (`chrome-client.js`) — это инструмент рабочей станции, не сервера и не роутера.
> 2. **Нужен Node.js.** Ставится через `npx`, тянет node-окружение.
> 3. **«Подсветка ошибок» — преувеличение поста.** Инструмент даёт комментарии и правки руками, а не автоматический поиск ошибок. Подсвечиваешь проблемы **ты**, а не он.
> 4. **Ценность зависит от агента.** Скилл только «учит» агента — если харнесс не подхватит `SKILL.md` или не позовёт его, магии не будет (общая болячка скиллов).

> [!note] Дубля в базе нет
> Проверил: `human-review` в хранилище не встречается — ни по ID поста, ни по названию. Тематические соседи в [AI/Skills](./) есть (скиллы против «слопа» во фронтенде — [Taste Skill](Taste%20Skill%20%28Leonxlnx%29%20%E2%80%94%2013%20%D1%81%D0%BA%D0%B8%D0%BB%D0%BB%D0%BE%D0%B2%20%D0%BF%D1%80%D0%BE%D1%82%D0%B8%D0%B2%20%D0%98%D0%98-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D0%B8%20%D0%B2%D0%BE%20%D1%84%D1%80%D0%BE%D0%BD%D1%82%D0%B5%D0%BD%D0%B4%D0%B5%20%28%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B0%20%E2%80%94%2022k%20%D1%82%D0%BE%D0%BA%D0%B5%D0%BD%D0%BE%D0%B2%2C%20%D0%BA%D0%B8%D1%80%D0%B8%D0%BB%D0%BB%D0%B8%D1%86%D0%B0%2C%20%D0%B2%D1%8B%D0%B4%D1%83%D0%BC%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5%20%D0%B8%D1%81%D1%81%D0%BB%D0%B5%D0%B4%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F%29.md), [Ponytail](Ponytail%20%E2%80%94%20%D1%81%D0%BA%D0%B8%D0%BB%D0%BB%20%D0%BF%D1%80%D0%BE%D1%82%D0%B8%D0%B2%20%C2%AB%D0%B3%D1%80%D0%B0%D1%84%D0%BE%D0%BC%D0%B0%D0%BD%D0%B8%D0%B8%C2%BB%20AI-%D0%B0%D0%B3%D0%B5%D0%BD%D1%82%D0%BE%D0%B2%20%D0%B2%20%D0%BA%D0%BE%D0%B4%D0%B5.md)), но там агент правит сам, а здесь наоборот — **человек** правит вывод агента руками. ## Что обещает пост

Пост «Не баг, а фича» ([26946](https://t.me/bugnotfeature/26946)):

1. скилл `human-review` даёт HTML/Markdown интерфейс ревью «как Google Docs»;
2. можно комментировать сгенерированные агентом файлы прямо в документе;
3. предпросмотр страницы с подсветкой ошибок;
4. можно редактировать, менять форматирование и переставлять элементы;
5. все правки собираются в один файл и уходят агенту разом;
6. работает локально, без отправки данных в облако;
7. проект на GitHub.

## Что это на самом деле

Проблема, которую решает скилл: **описывать правки словами в чате — дорого и неточно**. «Сделай отступ побольше, а вот этот абзац убери, и заголовок не тот» — агент половину поймёт не так. human-review переворачивает цикл: агент отдаёт **готовую страницу**, а ты правишь её как обычный документ.

Цикл обратной связи (из README):

1. открываешь файл: `/human-review <файл>`;
2. в браузере рендерится визуальный редактор;
3. правишь текст, оставляешь комментарии, ресайзишь/удаляешь элементы;
4. жмёшь **Send** — все правки батчем;
5. агент получает сводку и обновляет исходник;
6. страница перерисовывается для следующего круга;
7. закрыл вкладку / «End review» — сессия завершена.

Что внутри репозитория (Node.js):

| Файл | Роль |
| :--- | :--- |
| `cli.js` | CLI: `setup`, поллинг сессии |
| `server.js` | локальный сервер сессии ревью |
| `sdk.js` | ядро: правки и сбор фидбэка |
| `chrome-client.js` | визуальный интерфейс в браузере |
| `markdown.js` | рендер Markdown |
| `SKILL.md` | «учебник» для агента: как звать инструмент (Claude Code, Codex и др.) |

Ключевое: агент **не смотрит на страницу** — он получает от тебя структурированный список правок и комментариев и применяет их к исходному HTML/Markdown. Визуальную часть держит браузер, оркестрацию — локальный Node-сервер.

## Кому и когда полезно

- **Лендинги, страницы, презентации, README, отчёты** — всё, что агент генерит как HTML/Markdown и что удобнее править глазами, чем словами.
- **Дизайнер/предприниматель без желания писать простыни в чат** — ткнул, поправил, отправил.
- **Мультистраничное ревью** — cmd-клик по ссылкам открывает несколько страниц, не теряя уже оставленный фидбэк.

Когда мимо:
- **Правка кода/логики** — это про визуальный вывод, а не про рефакторинг исходников проекта.
- **Автоматический QA** — «ошибки» находишь ты, инструмент их не ищет.
- **Headless-окружение** — без десктопного браузера смысла нет.

## Установка по системам

Нужен **Node.js** и десктопный **Chrome/Chromium**. Ставится через `npx`, отдельной сборки нет.

Быстрый путь (везде одинаково после установки Node):

```bash
# глобально поставить скилл
npx -y human-review setup --global
# либо попросить самого агента:
#   "Install the /human-review skill globally from https://github.com/petergyang/human-review"

# использование внутри агента:
#   /human-review путь/к/файлу.html
```

### Gentoo (основная)

```bash
sudo emerge --ask net-libs/nodejs        # USE="npm" для npx/npm
npx -y human-review setup --global
```

Браузер для визуальной части — уже стоящий `www-client/chromium` или `firefox`. Компиляции у самого скилла нет, тянется как обычный npm-пакет.

### Debian / Ubuntu

```bash
sudo apt install nodejs npm
# на старых LTS node в репозитории староват — при желании NodeSource:
#   curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt install nodejs
npx -y human-review setup --global
```

### Arch (планируется с июня 2026)

```bash
sudo pacman -S nodejs npm
npx -y human-review setup --global
```

### Entware (ASUS RT-AX56U)

> [!danger] Технически node есть, а инструмент — не сюда
> В Entware пакет Node.js существует (`opkg install node node-npm`), так что формально `npx` на роутере запустится. Но:
> 1. вся суть — **визуальный редактор в браузере на десктопе**, а RT-AX56U headless, GUI-браузера там нет;
> 2. ИИ-агент (Claude Code/Codex), которому скилл ассистирует, всё равно живёт на рабочей станции;
> 3. node на 512 МБ ОЗУ / 256 МБ флеша роутера — расход ресурсов без смысла.
>
> Правильное место — **десктоп рядом с агентом**. На роутере ставить нечего и незачем.
