# 🎭 Deep-Live-Cam — подмена лица на веб-камере в реальном времени

[**Deep-Live-Cam**](https://github.com/hacksider/Deep-Live-Cam) — открытая программа, которая подменяет лицо в видео с веб-камеры в реальном времени или в готовом ролике. Нужна одна фотография лица-источника. Работает на Windows, macOS и Linux, с видеокартой или на процессоре. Заметка по посту [«Не баг, а фича»](https://t.me/bugnotfeature/28876) от 6 ноября 2026 года, сверена с репозиторием. Это справка о технологии и о том, как от неё защищаться, а не руководство по выдаче себя за другого человека.

| | |
| :--- | :--- |
| Лицензия | **AGPL-3.0** (код); модели скачиваются отдельно (раздел 4) |
| Репозиторий | с сентября 2023 года, ~98 тыс. звёзд, ~14 тыс. форков |
| Основа | модель подмены лица `inswapper_128` (InsightFace) и улучшатель лица GFPGAN, работающие через ONNX Runtime |
| Готовые сборки | платные, на [deeplivecam.net](https://deeplivecam.net/): Windows, Apple Silicon, CPU, NVIDIA, AMD; версия «Ultimate» — с «30+ эксклюзивными функциями» |

## 1. Что умеет

- **Режим камеры.** Выбрать фото, выбрать камеру, нажать Live. Через 10–30 секунд появляется предпросмотр, который можно выводить в звонок или стрим через OBS.
- **Режим «картинка или видео».** Подмена лица в готовом файле.
- **Маска рта.** Оставляет настоящий рот, чтобы движения губ при речи выглядели естественно.
- **Face Mapping.** Разные лица разным людям в кадре одновременно.
- **Фильмы.** Подмена лица в видео прямо во время просмотра.
- **Встроенный фильтр.** Программа отказывается обрабатывать обнажённость, жестокий контент и чувствительные материалы вроде съёмок войны.

## 2. Что за словами поста

- **«Дипфейк по одной фотке в три клика»** — да: в README так и описано — лицо, камера, Live.
- **«Почти 98 тысяч звёзд»** — да.
- **«Залетел после того, как IShowSpeed затестил на стриме»** — в разделе Press README действительно есть ссылки на два стрима IShowSpeed. Внимание СМИ проект получил ещё в августе 2024 года, в том числе статью Ars Technica об опасениях мошенничества.
- **«Работает на Windows, Mac и даже без видеокарты»** — да, но режим без видеокарты заметно медленнее. Готовые сборки для всех платформ — платные. Бесплатная ручная установка, по словам самих авторов, «требует технических навыков и не для новичков».
- **«Становимся Райаном Гослингом на созвонах».** Чужое лицо без согласия — главный риск этой технологии (раздел 3). Сами авторы требуют получать согласие человека и помечать результат как дипфейк при публикации.

## 3. Право и этика

- **Согласие и пометка.** Дисклеймер проекта: если используете лицо реального человека, получите его согласие и явно помечайте результат как дипфейк. Ответственность за использование авторы возлагают на пользователя.
- **Подделка личности на созвоне ради денег, доступа или данных — мошенничество** в уголовном праве большинства стран. Это ровно тот сценарий, из-за которого проект попал в новости.
- **Изображение человека** во многих юрисдикциях охраняется отдельно, без его согласия использовать его нельзя. Дипфейк интимного характера во многих странах — отдельное преступление.
- **В ЕС** регламент об ИИ (AI Act) обязывает раскрывать, что контент — дипфейк. Конкретные нормы зависят от страны: перед публичным использованием их стоит проверить.

## 4. Технические детали

- **Python 3.11–3.14** (рекомендован 3.14), `pip`, `git`, `ffmpeg`; для интерфейса нужен `tkinter`.
- **Модели** `inswapper_128_fp16.onnx` и `gfpgan-1024.onnx` скачиваются с Hugging Face в папку `models/`. Модели InsightFace распространялись для некоммерческого исследовательского использования — перед коммерческим применением проверьте их текущие условия отдельно от лицензии кода.
- **Ускорение:** CUDA (NVIDIA), CoreML (Apple Silicon), DirectML (Windows) и OpenVINO (Intel) через соответствующие сборки ONNX Runtime.

| Система | Зависимости |
| :--- | :--- |
| Gentoo | `dev-lang/python` с USE `tk`, `media-video/ffmpeg`, `dev-vcs/git` |
| Debian / Ubuntu | `sudo apt install python3-venv python3-tk ffmpeg git` (Debian 13 — Python 3.13, Ubuntu 24.04 — 3.12, оба поддерживаются) |
| Arch | `sudo pacman -S python tk ffmpeg git` |
| Entware | неприменимо: нужны веб-камера, графический интерфейс и серьёзные вычисления |

Дальше — по README репозитория: виртуальное окружение, `pip install -r requirements.txt`, запуск `python run.py`.

## 5. Как распознать дипфейк на видеозвонке

Подмена лица в реальном времени хорошо держит анфас и спокойную мимику, но хуже справляется с нестандартными ситуациями:

- **Попросить повернуть голову** в профиль или наклонить её. Модель обучена в основном на лицах в анфас, на краях появляются искажения.
- **Попросить провести рукой перед лицом** или коснуться щеки. Перекрытие лица часто ломает подмену: появляются мерцание, «прилипшие» к руке фрагменты лица.
- **Смотреть на границы лица:** линия волос, уши, контур подбородка, очки. Там видны размытие, мерцание или несовпадение освещения с остальной сценой.
- **Сверять голос.** Программа меняет только лицо, голос остаётся настоящим, если его не подделывают отдельно.
- **Проверять просьбу, а не лицо.** Если на звонке просят перевести деньги, сообщить пароль или код, срочно что-то подписать, — перезвоните человеку по известному вам номеру или каналу. Договоритесь в семье или команде о кодовом слове для таких случаев.
- **В компаниях** важные действия по видеозвонку — платежи, смена реквизитов, выдача доступа — стоит подтверждать по второму, независимому каналу.
