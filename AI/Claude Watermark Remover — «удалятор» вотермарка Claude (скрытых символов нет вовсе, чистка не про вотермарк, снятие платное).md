# 🧽 Claude Watermark Remover — разбор «удалятора» вотермарков

Разбор [поста «Не баг, а фича» от 12.08.2026](https://t.me/bugnotfeature/27018) про [claudewatermarkremover.app](https://claudewatermarkremover.app/). Продолжение темы из заметки [Вотермарки Claude](%D0%92%D0%BE%D1%82%D0%B5%D1%80%D0%BC%D0%B0%D1%80%D0%BA%D0%B8%20Claude%20%28C2PA%20%2B%20%D0%BD%D0%B5%D0%B2%D0%B8%D0%B4%D0%B8%D0%BC%D1%8B%D0%B9%20%D1%82%D0%B5%D0%BA%D1%81%D1%82%D0%BE%D0%B2%D1%8B%D0%B9%29%20%E2%80%94%20%D0%BA%D0%B0%D0%BA%20Anthropic%20%D0%BC%D0%B5%D1%82%D0%B8%D1%82%20AI-%D0%BA%D0%BE%D0%BD%D1%82%D0%B5%D0%BD%D1%82%2C%20%D1%87%D1%82%D0%BE%20%D0%BF%D1%83%D1%82%D0%B0%D0%B5%D1%82%20%D0%BF%D0%BE%D1%81%D1%82%20%D0%B8%20%D0%BD%D0%B0%D1%81%D0%BA%D0%BE%D0%BB%D1%8C%D0%BA%D0%BE%20%D1%8D%D1%82%D0%BE%20%D1%81%D1%82%D0%BE%D0%B9%D0%BA%D0%BE.md) (там разобран сам механизм меток).

> [!important] Парадокс этого разбора
> **Сайт честнее поста, который его рекламирует.** Авторы инструмента прямым текстом пишут, что скрытых символов в тексте Claude нет, что их бесплатная чистка вотермарк не снимает и что проверить результат нечем. Пост утверждает ровно обратное по всем трём пунктам.

## 📌 Что говорит пост

1. Anthropic «на днях заявила, что весь сгенерированный текст помечен **скрытыми символами**»;
2. энтузиасты выкатили удалятор;
3. «достаточно **вставить текст и получить чистые буквы**»;
4. «**Имба для студентов**».

## 🔬 Что инструмент делает на самом деле — две разные кнопки

Разница между ними — вся суть разбора.

### 1. `Clean traces` — бесплатно, в браузере, и это **не про вотермарк**

Вытащил регулярки прямо из JS-бандла сайта:

```js
let n = /[\u200B\u200C\u200D\uFEFF]/g,                          // zero-width: ZWSP, ZWNJ, ZWJ, BOM
    s = /[\u00A0\u1680\u2000-\u200A\u202F\u205F\u3000]/g,     // экзотические пробелы
    i = /class\s*=\s*(["'])[^"'<>]*claude[^"'<>]*\1/gi,          // HTML class="...claude..."
    l = /\u2014/g,                                               // длинное тире —
    o = /[\u201C\u201D\u2018\u2019]/g;                          // «умные» кавычки
```

Пять операций, все — **гигиена копипаста**, а не снятие метки:

| Что чистится | Откуда берётся |
| :--- | :--- |
| 4 нулевой ширины: `U+200B`, `U+200C`, `U+200D`, `U+FEFF` | вставка из веб-интерфейсов и редакторов |
| NBSP и прочие экзотические пробелы | форматирование при копировании |
| HTML-атрибуты `class="...claude..."` | копипаст из веб-интерфейса Claude |
| Длинное тире `—` | стилистический маркер |
| «Умные» кавычки `“ ” ‘ ’` | стилистический маркер |

> [!note] Две последние строки — косметика против человека, а не против детектора
> Длинное тире и типографские кавычки — классические «приметы ИИ-текста», по которым люди опознают машинную писанину на глаз. К вотермарку Anthropic они отношения не имеют. Подробнее о том, почему стилистическая правка не равна «обходу детекторов» — в заметке [про промпт «человечного» стиля](Prompts/%D0%9F%D1%80%D0%BE%D0%BC%D0%BF%D1%82%20%D0%B4%D0%BB%D1%8F%20%C2%AB%D1%87%D0%B5%D0%BB%D0%BE%D0%B2%D0%B5%D1%87%D0%BD%D0%BE%D0%B3%D0%BE%C2%BB%20%D1%81%D1%82%D0%B8%D0%BB%D1%8F%20%D0%BF%D0%B8%D1%81%D1%8C%D0%BC%D0%B0%20%28%D0%B0%D0%BD%D1%82%D0%B8-AI-%D1%81%D0%BB%D0%BE%D0%BF%29%20%E2%80%94%20%D0%B8%20%D0%BF%D0%BE%D1%87%D0%B5%D0%BC%D1%83%20%C2%AB%D0%BE%D0%B1%D1%85%D0%BE%D0%B4%20AI-%D0%B4%D0%B5%D1%82%D0%B5%D0%BA%D1%82%D0%BE%D1%80%D0%BE%D0%B2%C2%BB%20%D1%8D%D1%82%D0%BE%20%D0%BC%D0%B8%D1%84.md).

Хорошая новость по приватности: это действительно **целиком в браузере**, текст никуда не уходит. Проверил по коду — обработка синхронная, локальная, без сетевых вызовов.

### 2. `Remove watermark` — платно, и текст уходит на сервер

Единственный сетевой путь в коде:

```js
await fetch("/api/neutralize", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ text: t }),
  signal: r.signal
})
```

Ограничение из того же кода: *«keep rewrite jobs under 20,000 words»*. Формулировка сайта — *«rewrites the passage with a non-Claude model»*, то есть твой текст **отправляется на их сервер и оттуда в стороннюю LLM**. Заявлено «Text is not stored», но это обещание, а не проверяемый факт.

> [!warning] Это не «удаление», а перефраз
> Метка живёт в выборе слов, поэтому единственный способ её ослабить — переписать текст другой моделью. Ровно это и указано в [предыдущей заметке](%D0%92%D0%BE%D1%82%D0%B5%D1%80%D0%BC%D0%B0%D1%80%D0%BA%D0%B8%20Claude%20%28C2PA%20%2B%20%D0%BD%D0%B5%D0%B2%D0%B8%D0%B4%D0%B8%D0%BC%D1%8B%D0%B9%20%D1%82%D0%B5%D0%BA%D1%81%D1%82%D0%BE%D0%B2%D1%8B%D0%B9%29%20%E2%80%94%20%D0%BA%D0%B0%D0%BA%20Anthropic%20%D0%BC%D0%B5%D1%82%D0%B8%D1%82%20AI-%D0%BA%D0%BE%D0%BD%D1%82%D0%B5%D0%BD%D1%82%2C%20%D1%87%D1%82%D0%BE%20%D0%BF%D1%83%D1%82%D0%B0%D0%B5%D1%82%20%D0%BF%D0%BE%D1%81%D1%82%20%D0%B8%20%D0%BD%D0%B0%D1%81%D0%BA%D0%BE%D0%BB%D1%8C%D0%BA%D0%BE%20%D1%8D%D1%82%D0%BE%20%D1%81%D1%82%D0%BE%D0%B9%D0%BA%D0%BE.md): «теряется при сильной перефразе/переводе». Инструмент автоматизирует известный приём, а не изобретает новый.

Насколько сильно меняется текст — видно из примера на главной странице сайта. Было:

> *«our team made meaningful progress on the onboarding redesign this week. We've clarified empty states, tightened the primary CTA hierarchy…»*

Стало:

> *«significant strides were taken by our group in revamping the introductory process. Efforts focused on refining the presentation of empty sections, reorganizing the main call-to-action sequence…»*

Активный залог превратился в пассивный, текст стал длиннее и канцелярнее. Это цена «снятия» — не бесплатная и не незаметная.

## 🎓 Про «имбу для студентов»

Здесь пост расходится с документацией собственного инструмента сильнее всего. С отдельной страницы сайта про детекторы:

> *«GPTZero, Turnitin, Originality.ai, and similar products classify **AI-like writing**. Anthropic's mark is a sampling bias in Claude word choice.»*
>
> *«Turnitin's AI-writing indicator is a school integrity product, **not a Claude-watermark product**.»*
>
> *«A green GPTZero dashboard is **not proof** the statistical mark is gone. A red one is not proof it is Claude.»*
>
> *«A public detect → rewrite → re-check loop is **not available yet**.»*

Три следствия:

1. **Вуз почти наверняка не проверяет вотермарк Anthropic.** Детект-API в закрытом превью для регуляторов и организаций; в Turnitin его нет. То есть снимать нечего от той проверки, которой студент реально боится.
2. **Классификаторы ловят другое** — «похоже на машинное письмо». Сильно перефразированный текст может пройти GPTZero, оставшись помеченным, и наоборот.
3. **Проверить результат нельзя.** Публичного детектора нет, значит после платного перефраза нет способа убедиться, что что-то изменилось. Ты платишь за действие с непроверяемым результатом.

Отдельно: вопрос академической честности решается не наличием метки. Правила вузов про авторство работы, а не про водяные знаки, и снятие метки на это никак не влияет.

## 🖼️ Побочная находка: бесплатный съём C2PA с картинок

На сайте есть страница `/remove-c2pa` — удаление C2PA Content Credentials из PNG/JPEG/SVG **в браузере, бесплатно**. Это дополняет раздел про картинки в [предыдущей заметке](%D0%92%D0%BE%D1%82%D0%B5%D1%80%D0%BC%D0%B0%D1%80%D0%BA%D0%B8%20Claude%20%28C2PA%20%2B%20%D0%BD%D0%B5%D0%B2%D0%B8%D0%B4%D0%B8%D0%BC%D1%8B%D0%B9%20%D1%82%D0%B5%D0%BA%D1%81%D1%82%D0%BE%D0%B2%D1%8B%D0%B9%29%20%E2%80%94%20%D0%BA%D0%B0%D0%BA%20Anthropic%20%D0%BC%D0%B5%D1%82%D0%B8%D1%82%20AI-%D0%BA%D0%BE%D0%BD%D1%82%D0%B5%D0%BD%D1%82%2C%20%D1%87%D1%82%D0%BE%20%D0%BF%D1%83%D1%82%D0%B0%D0%B5%D1%82%20%D0%BF%D0%BE%D1%81%D1%82%20%D0%B8%20%D0%BD%D0%B0%D1%81%D0%BA%D0%BE%D0%BB%D1%8C%D0%BA%D0%BE%20%D1%8D%D1%82%D0%BE%20%D1%81%D1%82%D0%BE%D0%B9%D0%BA%D0%BE.md): C2PA — это метаданные в файле, они действительно снимаются, и для этого не нужен ни этот сайт, ни платные кредиты.

Локальные способы ровно с тем же результатом:

```bash
# ImageMagick — пересохранить без метаданных
magick input.png -strip output.png

# exiftool — вычистить всё
exiftool -all= image.jpg

# на Gentoo / Debian-Ubuntu / Arch пакеты называются одинаково:
#   media-gfx/imagemagick, media-libs/exiftool | imagemagick, libimage-exiftool-perl
```

## 🔒 Приватность: что и куда уходит

| Функция | Где выполняется | Что уходит наружу |
| :--- | :--- | :--- |
| `Clean traces` (проверка и чистка) | **в браузере** | ничего |
| `/remove-c2pa` | **в браузере** | ничего |
| `Remove watermark` (перефраз) | сервер + сторонняя LLM | **весь текст целиком**, `POST /api/neutralize` |
| Покупка кредитов | Polar.sh | платёжные данные, аккаунт |

Вывод простой: бесплатной частью пользоваться безопасно, платная — это отправка документа третьей стороне. Для черновика диплома или рабочего документа под NDA это существенно.

## 💡 Итог

Инструмент сделан аккуратно и описан честно — редкий случай, когда претензии не к проекту, а к посту о нём. Что стоит запомнить:

- **скрытых символов в тексте Claude нет** — это выдумка поста, опровергнутая документацией самого инструмента;
- бесплатная кнопка чистит мусор копипаста, и на чистой вставке ей обычно **нечего делать**;
- реальное «снятие» — это платный перефраз чужой моделью, приём известный и без сайта;
- **проверить результат нечем**: публичного детектора не существует;
- Turnitin и GPTZero измеряют совсем другое, так что «имба для студентов» не выполняется даже по логике самого сервиса.
