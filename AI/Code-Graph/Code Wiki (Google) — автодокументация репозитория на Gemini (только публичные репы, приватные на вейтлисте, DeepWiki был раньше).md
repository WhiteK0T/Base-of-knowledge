# 📚 Code Wiki (Google) — автодокументация репозитория на Gemini

Разбор [поста «Не баг, а фича» от 15.08.2026](https://t.me/bugnotfeature/27078) про [codewiki.google](https://codewiki.google/). Продукт настоящий и действительно от Google, но пост опоздал на девять месяцев, умалчивает о главном ограничении и объявляет первооткрывателем того, кто пришёл вторым.

Проверено 09.09.2026. Часть проверок сделать не удалось — сайт целиком на JS, содержимое страниц без браузера не вытащить; ниже честно помечено, что взято из метаданных, что из официального анонса, а что не проверено.

> [!info] Факты
> | | |
> | :--- | :--- |
> | Официальное название | **Code Wiki** — в два слова, не «CodeWiki» |
> | Адрес | [codewiki.google](https://codewiki.google/) — домен `.google` выдаётся только Google, сервер отвечает `server: ESF` (инфраструктура Google) |
> | Запуск | **13.11.2025**, публичное превью |
> | Модель | Gemini |
> | Репозитории | **только публичные** |
> | Цена | бесплатно на время превью; про тарифы после GA не объявлено |

Собственное описание из метатегов страницы:

> *«Code Wiki provides automatically generated, up-to-date documentation for your code. Stop wasting time on manual docs and explore codebase insights, API references, and architecture overviews instantly.»*

## ✅ Проверка утверждений поста

| Утверждение | Вердикт | Что на самом деле |
| :--- | :---: | :--- |
| «Google **выкатили**» | ❌ Опоздание на 9 месяцев | Публичное превью открыто **13.11.2025**, пост от 15.08.2026 |
| «Из **ЛЮБОГО** репозитория» | ❌ **Только публичные** | Приватные — через расширение Gemini CLI, которое **всё ещё на вейтлисте** |
| Диаграммы, объяснение частей, туториалы, архитектура, чат-бот | ✅ Заявлено официально | Wiki обновляется после изменений в коде, чат понимает всю базу |
| «Нейросеть за минуты» | ⚠️ Не проверял | Официальных нормативов по времени генерации нет |
| «О CodeWiki в комьюнити **мечтали много лет**» | ❌ Ровно наоборот | **DeepWiki** от Cognition делает то же самое и вышел в апреле 2025 — на семь месяцев раньше |
| Что это Google | ✅ Верно | Домен `.google` зарезервирован за Google, анонс на Google Developers Blog |

## 🔒 Главное умолчание: приватных репозиториев нет до сих пор

Пост говорит «подключить нужный репозиторий, скинув ссылку». Для рабочего кода это не сработает.

Из официального анонса: Code Wiki обрабатывает **только публичные репозитории**, а для внутренних Google обещает *«a Gemini CLI extension for Code Wiki so teams can run the same system locally and securely on internal repositories»* — со статусом **Coming soon** и записью в лист ожидания.

Проверил, что с этим сейчас:

```bash
# все официальные расширения Gemini CLI
curl -s "https://api.github.com/orgs/gemini-cli-extensions/repos?per_page=100" \
  | grep '"name"' | wc -l
# 66 расширений — ни одного с "wiki" или "doc" в названии
```

> [!warning] Десять месяцев на вейтлисте
> Расширение анонсировали 13.11.2025 как «скоро». На 09.09.2026 в организации `gemini-cli-extensions` **66 расширений, и Code Wiki среди них нет**. То есть единственный заявленный путь для приватного кода за десять месяцев так и не открылся.
>
> Практический вывод: для рабочего репозитория под NDA сервис сегодня бесполезен, а для публичного — код и так публичный, так что вопрос утечки не стоит.

## 🥈 Google здесь не первый

Утверждение «мечтали много лет» не выдерживает проверки. Собственное описание **DeepWiki** от Cognition (создателей Devin):

> *«DeepWiki provides up-to-date documentation you can talk to, for every repo in the world. Think Deep Research for GitHub — powered by Devin.»*

Это дословно та же идея — автодокументация плюс чат по репозиторию, — и она работает с апреля 2025. Больше того, существует открытый клон [`AsyncFuncAI/deepwiki-open`](https://github.com/AsyncFuncAI/deepwiki-open): **17 916 звёзд**, MIT, создан 30.04.2025.

| Продукт | Кто | Появился |
| :--- | :--- | :--- |
| DeepWiki | Cognition (Devin) | апрель 2025 |
| deepwiki-open (открытый клон) | сообщество, MIT | 30.04.2025 |
| **Code Wiki** | **Google** | **13.11.2025** |

Для тебя важнее другое: `deepwiki-open` под MIT можно **поднять у себя** и скормить ему приватный репозиторий, не дожидаясь вейтлиста Google.

## ⚠️ Ловушка с названием: «CodeWiki» — это три разные вещи

При поиске легко нарваться на подмену, и один из вариантов особенно опасен, потому что содержит красивые цифры.

| Что | Где | Что это |
| :--- | :--- | :--- |
| **Code Wiki** (два слова) | codewiki.google | продукт Google, о котором пост |
| **CodeWiki** (одно слово) | [arXiv 2510.24428](https://arxiv.org/abs/2510.24428) | **научная работа**, подана 28.10.2025, авторы Anh Nguyen Hoang, Minh Le-Anh, Bach Le, Nghi D. Q. Bui. Совершенно отдельный исследовательский фреймворк |
| **codewiki.ai** | codewiki.ai | сторонний сервис; **проверить не смог** — отдаёт HTTP 451 |

> [!caution] Не приписывай Google чужие цифры
> В выдаче попадается утверждение, что «CodeWiki обходит DeepWiki: 68,79 % против 64,06 % по качеству документации». Эти числа — **из статьи на arXiv, про её собственную систему**, а не про продукт Google. Никаких опубликованных бенчмарков качества у Google Code Wiki нет.
>
> Академическая CodeWiki — это иерархическая декомпозиция и рекурсивная мультиагентная обработка для семи языков программирования. К codewiki.google она отношения не имеет, кроме совпадения имени.

## 🧾 Что заявлено официально

Из анонса и описания сервиса:

- **структурированная вики на каждый репозиторий**, которая перегенерируется после изменений в коде;
- **ссылки на каждый символ** и диаграммы, отражающие текущее состояние кода, а не снимок годичной давности;
- **чат на Gemini**, понимающий всю кодовую базу;
- обзоры архитектуры и справочники по API.

Ключевая идея — не «сгенерировать доки один раз», а **держать их живыми**. Это же отличает её от разовой генерации README агентом.

## 💻 На твоих системах

Это веб-сервис, поэтому ОС не важна — нужен браузер и, скорее всего, аккаунт Google. Отдельно ставить нечего, для Entware неприменимо.

Что имеет смысл сделать практически:

```bash
# посмотреть чужой большой проект перед тем, как в него лезть
# (открыть в браузере)
https://codewiki.google/

# для приватного кода — поднять открытый аналог у себя
git clone https://github.com/AsyncFuncAI/deepwiki-open
# дальше по его README: нужен ключ к LLM-провайдеру
```

> [!note] Чего я не проверил
> Сайт — SPA на Angular (`BoqAngularSdlcAgentsUi`), в HTML отдаётся только заголовок, поэтому без браузера не удалось проверить ни реальное качество вики, ни скорость генерации, ни ограничения на размер репозитория. Всё, что выше про возможности, взято из официального анонса Google и метаописания сервиса, а не из личного прогона.

## 💡 Итог

- Продукт настоящий, от Google, на Gemini, бесплатный в превью — и в этом пост прав.
- Он **не новый**: девять месяцев на момент поста, и **не первый** — DeepWiki занял эту нишу в апреле 2025.
- Главное ограничение пост не назвал: **приватные репозитории не поддерживаются**, а обещанное расширение Gemini CLI за десять месяцев так и не вышло.
- Для чужого публичного проекта, в который надо быстро вникнуть, — полезно. Для своего рабочего кода сегодня — нет, и `deepwiki-open` под MIT решает ту же задачу без ожидания.
