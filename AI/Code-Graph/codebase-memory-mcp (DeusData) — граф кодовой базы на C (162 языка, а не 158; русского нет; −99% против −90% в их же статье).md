# codebase-memory-mcp — граф знаний по кодовой базе одним нативным бинарником

MCP-сервер на **C**, который парсит репозиторий вкомпилированными грамматиками tree-sitter и складывает функции, классы, цепочки вызовов, HTTP-маршруты и межсервисные связи в персистентный граф на SQLite. 15 MCP-инструментов, свой диалект Cypher для запросов, без рантайма, без облака и без ключей API.

Пост в «Не баг, а фича»: *«преобразует всю вашу кодовую базу в граф знаний. Поддерживает 158 языков, среди которых РУССКИЙ, сокращает токены более чем на 99% и отвечает за миллисекунды»*.

## Про «99 %» и то, что README умалчивает

В README есть строка с ссылкой на препринт: *«83% answer quality, 10× fewer tokens, 2.1× fewer tool calls vs. file-by-file exploration»*. Ключевое слово там — чего именно 83 %. Открываем аннотацию arXiv:2603.27277:

> Evaluated across 31 real-world repositories, Codebase-Memory achieves **83% answer quality versus 92% for a file-exploration agent**, at ten times fewer tokens and 2.1 times fewer tool calls.

То есть за десятикратную экономию токенов платят **девятью процентными пунктами качества ответов**: 83 % против 92 % у обычного агента, который просто читает файлы. В README цифра 92 % не приводится, в посте — тем более.

И два числа про токены расходятся на порядок: маркетинговое «120×» (−99,2 %) получено на пяти структурных запросах, научное «10×» (−90 %) — на 31 репозитории с оценкой качества. Пост, естественно, взял первое.

Статья при этом настоящая: «Codebase-Memory: Tree-Sitter-Based Knowledge Graphs for LLM Code Exploration via MCP», arXiv:2603.27277, опубликована 28.03.2026, авторы Martin Vogel, Falk Meyer-Eschenbach, Severin Kohler, Elias Grünewald, Felix Balzer.

## Что реально умеет

- **Скорость индексации.** Средний репозиторий — за миллисекунды, ядро Linux (28 млн строк, 75 тыс. файлов) — за 3 минуты. Пайплайн работает в памяти: LZ4-сжатие, SQLite в RAM, слитый Aho-Corasick; память освобождается после индексации.
- **Hybrid LSP** — лёгкая реализация алгоритмов разрешения типов прямо в бинарнике для 10+ языков (Python, TS/JS/JSX/TSX, PHP, C#, Go, C, C++, Java, Kotlin, Rust, Perl). Без запуска отдельного языкового сервера. Языки без этого слоя откатываются к текстовому разрешению.
- **Качество парсинга по тирам** (бенчмарк на 64 открытых репозиториях): «отлично» (≥90 %) — Lua, Kotlin, C++, Perl, Objective-C, Groovy, C, Bash, Zig, Swift, CSS, YAML, TOML, HTML, SCSS, HCL, Dockerfile; «хорошо» (75–89 %) — Python, TypeScript, TSX, Go, Rust, Java, R, Dart, JavaScript, Erlang, Elixir, Scala, Ruby, PHP, C#, SQL; «работает» (<75 %) — OCaml, Haskell. Остальные ~120 языков в списке помечены как «поддерживаются, но не бенчмаркались».
- **Развесистая безопасность релизов:** SHA-256 в `checksums.txt`, SBOM, выгрузки результатов VirusTotal, подписи-бандлы к каждому артефакту.
- 45 клиентских интеграций (Claude Code, Codex, Cursor, Gemini CLI, OpenCode, Windsurf, Kilo, Aider и др.).

## Установка на своих системах

Релизы — самодостаточные бинарники под **linux-amd64, linux-arm64, darwin-amd64/arm64, windows-amd64/arm64**, включая полностью статические `-portable` сборки. Каждая около 39–41 МБ. Есть также формула Homebrew и `flake.nix`.

```bash
curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | sh
# либо вручную: скачать tar.gz нужной архитектуры, распаковать, запустить `install`
```

| Система | Как | Нюанс |
| :--- | :--- | :--- |
| **Gentoo** | Ebuild-а нет. Либо статический `linux-amd64-portable` из релиза, либо сборка из исходников — в репозитории `Makefile.cbm` и `flake.nix`, зависимостей почти нет (C + вендоренные библиотеки), что для сборки всего из исходников удобно | Проверять `checksums.txt` — они публикуются к каждому релизу |
| **Debian / Ubuntu** | Обычная сборка `linux-amd64` (использует системный ABI) либо `-portable`, если система старая | — |
| **Arch** | Пакета нет ни в официальных репозиториях, ни в AUR — ставить бинарник из релиза | — |
| **Entware (RT-AX56U, armv7)** | ❌ **не запустится**: сборок под 32-битный ARM нет вообще — только `linux-arm64` (aarch64). Роутер на armv7 остаётся за бортом | Проверено по списку артефактов релиза v0.10.8 |

## Итог

Технически это самая серьёзная вещь из пятёрки поста: настоящий C, вендоренные грамматики, статья на arXiv, SBOM и VirusTotal в релизах. Открытость — без вопросов.

Но два числа из поста надо поправить. Языков не 158, а 162 по собственному разделу документации (сам репозиторий здесь непоследователен), и **русского среди них нет** — это языки программирования, а не естественные. А «−99 % токенов» — маркетинговая цифра с пяти запросов; в рецензируемом препринте тех же авторов экономия **десятикратная**, и она стоит падения качества ответов с 92 % до 83 %. Это принципиально другой размен, чем «сокращает токены на 99 %» без единой оговорки.
