# Graft — граф кодовой базы, который агент читает вместо повторного обхода репозитория

Инструмент, который один раз строит из репозитория **граф markdown-узлов** (подсистемы, ключевые файлы, концепции) и подсовывает агенту нужные узлы в промпт, чтобы тот не переоткрывал одни и те же файлы в каждой задаче.

Из поста в «Не баг, а фича»: *«делает кодинг на Claude в 4 (!) раза дешевле и в 3 раза быстрее! При этом совместим с ЛЮБЫМ агентом»*.

Сразу нюанс, которого в посте нет: **ссылка из поста ведёт на `github.com/NanoNets/Graft`, а репозиторий переехал** — GitHub API отдаёт `301 Moved Permanently` на **`trailhq/Graft`**. Старый адрес пока редиректит, но канонический уже другой; пакет в npm при этом остался `@nanonets/graft`.

## Откуда взялись 4× и 3×

Заголовок README — `Up to **4× cheaper** and **3× faster**`. Формулировка «up to» в посте потерялась, а сами цифры в тексте репозитория не встречаются больше нигде. Что там есть на самом деле — два честно описанных стенда.

**1. Контролируемый прогон.** 162 запуска, два репозитория (сам Graft и реальный Node/Express-сервис аутентификации), по 3 попытки. Один и тот же агент на Claude Sonnet 5, судья корректности — Opus 4.8. Стоимость считалась с учётом кэша (чтение ≈0,1×, запись 1,25×):

| Метрика (среднее на задачу) | Cold Claude Code | С Graft |
| :--- | :--- | :--- |
| Деньги | $0,0429 | **$0,0292 (−32 %)** |
| Токены | 8 070 | **4 650 (−42 %)** |
| Вызовы инструментов | 4,2 | **2,3 (−46 %)** |
| Латентность | 39,8 с | **15,8 с (−60 %)** |
| Корректность | 93 % | 93 % (**поровну**) |

**2. SWE-bench Verified**, 50 инстансов, официальный грейдер `swebench` 4.1.0, одна и та же модель на обеих ветках:

| Метрика | Cold Claude Code | С Graft |
| :--- | :--- | :--- |
| Корректность | 27/50 (54 %) | **33/50 (66 %)** |
| Токены | 142,0 M | **109,4 M (−23 %)** |
| Деньги | $52,34 | **$42,43 (−19 %)** |
| Время | 13 094 с | **8 922 с (−32 %)** |

Отдельно стоит заметить, что **сводная табличка в шапке README смешивает два стенда**: экономию вызовов, токенов и времени берёт из первого прогона (+46 / +42 / +60 %), а корректность 54 % → 66 % — из SWE-bench. В одном эксперименте таких чисел одновременно не получалось: там, где −60 % времени, корректность была равной.

Ни в одной таблице Graft не отвечал хуже холодного агента — это подтверждается. Вариант «pull» (агент сам дёргает `graft_find_code`/`graft_file_api`, ничего не инжектится заранее) дал корректность 98 % против 93 % у холодного, отдав почти всю экономию времени.

## Что это технически

Граф строится в два прохода, **оба на языковой модели**: сначала каждый файл ужимается в короткое описание, потом описания группируются в узлы (подсистемы, ключевые файлы, концепции) с типизированными связями. Результат — папка `graft/` со связанными markdown-файлами прямо в репозитории. Никакого демона и переиндексации: граф — это просто файлы.

Узел хранит не адрес («это лежит в таком-то файле на такой-то строке»), а смысл: краткое описание, «crux» (как оно работает) и список файлов-источников с хешем содержимого — чтобы Graft понимал, когда узел протух. В Claude Code добавляется статуслайн с размером графа, процентом обогащения и предупреждением `⚠ N stale`.

Парсинг — tree-sitter, **23 языка** в трёх слоях: полная точность (TS/JS, Python, Go, Java, Kotlin, PHP, Swift, R), широкий слой (Rust, C, C++, C#, Ruby, Scala, Elixir, Solidity, OCaml, Zig, Dart, Clojure, Nix, Lua) и опциональные точные рёбра через LSP (`--lsp`, если в `PATH` есть rust-analyzer, clangd, gopls, pyright, typescript-language-server). Этот слой бесплатный и детерминированный — модель нужна только для «глубокого» построения.

### Два момента, о которых стоит знать заранее

**Пишет за пределы репозитория.** При выборе хоста `agents` Graft трогает пользовательский конфиг Codex: `~/.codex/config.toml` (регистрирует MCP-сервер), `~/.codex/hooks/graft/graft-hooks.cjs` и `~/.codex/hooks.json`. Отключается флагом `--no-global`; посмотреть всё заранее — `graft init --dry-run`.

**Телеметрия включена по умолчанию.** По их описанию — только «бакеты и фиксированные метки», без кода, путей, имён репозиториев, символов и запросов; есть `TELEMETRY.md` и команда `graft telemetry debug`, печатающая ровно то, что ушло бы с машины. Выключается тремя способами:

```bash
graft telemetry disable
export DO_NOT_TRACK=1
# либо снять галочку в graft init
```

В CI и в сборках из исходников она выключена изначально.

## Установка на своих системах

Ставится как обычный npm-пакет, нужен **Node.js ≥ 20**.

```bash
npm install -g @nanonets/graft
graft init                # спросит, какие агенты подключить
graft init --dry-run      # сначала показать, какие файлы будут тронуты
npx @nanonets/graft init  # без глобальной установки
```

Для «глубокого» графа нужен ключ провайдера — Graft вендоронейтрален:

```bash
export GRAFT_PROVIDER=openai     # openai | anthropic | litellm | orcarouter
export GRAFT_API_KEY=...
export GRAFT_MODEL=...
export GRAFT_BASE_URL=...        # для OpenAI-совместимого формата
graft build --deep
```

| Система | Как | Проверено |
| :--- | :--- | :--- |
| **Gentoo** | `emerge -av net-libs/nodejs` с USE `npm`, дальше `npm install -g @nanonets/graft`. Отдельного ebuild нет | Node в дереве есть, версия ≥ 20 доступна |
| **Debian / Ubuntu** | `apt install nodejs npm` (в старых релизах Node слишком древний — тогда репозиторий NodeSource), затем npm-установка | — |
| **Arch** | `pacman -S nodejs npm`, затем npm-установка. В AUR отдельного пакета нет | — |
| **Entware (RT-AX56U, armv7)** | ❌ **не поставится**: в репозитории armv7 `node` версии **v18.20.2**, а Graft требует **Node ≥ 20**. Плюс граф всё равно строится LLM-запросами, а не локально | Проверено по `Packages` для `armv7sf-k3.2` |

## Итог

Инструмент рабочий, замеры опубликованы честно и в двух независимых стендах — это редкость. Претензия ровно одна и она к маркетингу самого репозитория, а не только к посту: заголовок «up to 4× cheaper and 3× faster» не воспроизводится ни в одной из их собственных таблиц, где по деньгам выходит −32 % и −19 %, а по времени −60 % и −32 %.

Полезно, если агент постоянно перечитывает большой монорепозиторий. Помните про стоимость построения графа через ваш ключ и про то, что `init` может тронуть `~/.codex/`.
