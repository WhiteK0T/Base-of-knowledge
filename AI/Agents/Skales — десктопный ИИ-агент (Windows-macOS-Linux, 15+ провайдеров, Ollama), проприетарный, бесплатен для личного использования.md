# 🦎 Skales — десктопный ИИ-агент

**[Skales](https://skales.app/)** — ИИ-агент в виде обычного приложения для Windows, macOS и Linux (плюс мобильные клиенты). Ставится как обычная программа, без Docker и терминала. Получает доступ к файлам, браузеру, почте и календарю и выполняет многошаговые задачи сам. Автор — Марио Симич (Вена), проект с января 2026, текущая версия **12.9.50** (12.10.2026).

> [!warning] Это не open source
> Пост вышел в канале про открытое ПО и указывает язык TypeScript, но **исходного кода Skales в открытом доступе нет**. Репозиторий [skalesapp/skales](https://github.com/skalesapp/skales) содержит только README, журнал изменений, инструкции по установке и трекер issue. Старый снимок исходников версии 7 (лицензия BSL 1.1) удалили в релизе 12.9.30. Сейчас действует собственное лицензионное соглашение (EULA): программа **проприетарная** и, как прямо сказано в README, открытой не станет.

## 1. Условия использования

| | |
| :--- | :--- |
| Личное и учебное использование | **бесплатно**: частные лица, студенты, преподаватели, школы и университеты |
| Организации | 30 дней на пробу, дальше — **платная коммерческая лицензия** (`request@skales.app`) |
| Запрещено | разбирать и декомпилировать (кроме случаев, которые закон разрешает и так), менять и перепаковывать, встраивать в свой продукт или сервис, собирать вывод массово для обучения моделей |
| Сетевые обращения | проверка лицензии и обновлений; опциональные сервисы Skales IQ и Relay — со своими условиями |

Проверить, что программа делает на самом деле, по коду нельзя. Утверждения о приватности остаются на слове автора.

## 2. Что умеет (по README)

- **Провайдеры**: Anthropic, OpenAI, Google, OpenRouter, Groq, DeepSeek, Mistral, xAI, Cerebras, Moonshot, GLM, Qwen и другие, «15+» в README (в описании репозитория — 26). Плюс любой эндпоинт с протоколом OpenAI Chat Completions, Anthropic Messages или OpenAI Responses. Можно войти и через подписку ChatGPT.
- **Локальные модели**: Ollama, LM Studio, KoboldCpp, vLLM и встроенный Skales Local — тогда работает полностью офлайн.
- **Skales IQ** — бесплатный встроенный пробный доступ к модели без своего ключа. Запросы при этом идут через сервис Skales.
- **Skales Code** — режим для работы с репозиторием: план, правки с подтверждением, лог шагов.
- **Автоматизация**: управление рабочим столом и браузером, задачи по расписанию, плагины (например, утренняя сводка из календаря и задач).
- **Команды**: связь двух компьютеров для общей работы людей и их агентов; телефон подключается через сквозное шифрование Relay и получает доступ ко всем 260+ инструментам компьютера.
- **Мессенджеры**: Telegram, Discord, WhatsApp, Slack, Signal.
- **MCP, Agent Skills (`SKILL.md`), протокол Agent2Agent**, импорт истории из ChatGPT, Claude, OpenClaw и Hermes.
- Ключи API хранятся зашифрованными, данные — в `~/.skales-data/`, регистрация не нужна.

**Про «минимальное потребление памяти».** В README сравнение «около 300 МБ против 1,5–3 ГБ у типичных агентов» — это цифра самого автора. Skales собран на Electron (внутри Chromium), так что реальный расход стоит проверить на своей машине.

## 3. Установка на Linux

Готовые сборки — на [skales.app](https://skales.app/) и в [GitHub Releases](https://github.com/skalesapp/skales/releases): **AppImage** (x86_64) и **.deb** (amd64). Сборок под ARM для Linux нет. Поддержку Linux автор называет бетой.

| Система | Как поставить |
| :--- | :--- |
| **Gentoo** | AppImage; для него нужен FUSE 2: `emerge --ask sys-fs/fuse:0` |
| **Debian / Ubuntu** | `sudo apt install ./Skales-12.9.50-amd64.deb`, или AppImage + `sudo apt install libfuse2` (на Ubuntu 24.04+ — `libfuse2t64`) |
| **Arch** | AppImage + `sudo pacman -S fuse2`; пакета в AUR нет |
| **Entware** | не подходит: настольное приложение на Electron для x86_64 |

```bash
chmod +x Skales-12.9.50-x86_64.AppImage
./Skales-12.9.50-x86_64.AppImage
```

- **Ubuntu 24.04+**: AppArmor запрещает Chromium-песочнице создавать user namespaces. Skales в этом случае **сам запускается с `--no-sandbox`**, то есть без песочницы браузерного движка. Чтобы песочница работала, в `INSTALL-LINUX.md` дан профиль AppArmor для бинарника — лучше поставить его.
- **GNOME**: значок в трее появится только с расширением AppIndicator.
- **Wayland**: если окна мерцают, запускать с `ELECTRON_OZONE_PLATFORM_HINT=wayland`.
- Автозапуск не настраивается сам: нужен `.desktop`-файл в `~/.config/autostart/`.
- Удаление: стереть AppImage (или `sudo dpkg -r skales`) и `~/.skales-data/`.

## 4. Стоит ли пробовать

**Подойдёт**, если нужен агент «для всех» с графическим интерфейсом, без терминала: дать задачу, подключить свой ключ или Ollama, общаться с ним из Telegram.

**Чего ждать:**
- агент получает широкий доступ к файлам, почте, браузеру и командам, а проверить его код нельзя — доверие только автору;
- использование в работе на компанию требует платной лицензии;
- поддержка Linux в бете, по сути только x86_64;
- сборка для Windows пока без цифровой подписи (подписан только macOS).
