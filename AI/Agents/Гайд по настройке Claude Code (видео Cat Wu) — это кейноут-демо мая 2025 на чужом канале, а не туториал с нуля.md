# 🎥 Видео Cat Wu про Claude Code — что это на самом деле

Разбор [поста «Не баг, а фича» от 21.08.2026](https://t.me/bugnotfeature/27220): «мощнейший гайд от инженера Anthropic по созданию полной конфигурации Claude Code с нуля».

Видео опознано — это [Cat Wu Demo с конференции Code with Claude](https://www.youtube.com/watch?v=5nmVr9_CuJg). И оно совсем не то, чем его представили.

## ✅ Проверка утверждений поста

| Утверждение | Вердикт | Что на самом деле |
| :--- | :---: | :--- |
| «От **инженера** Anthropic» | ❌ Неверно | Cat Wu — **продакт-менеджер** Claude Code. Это написано и в самом описании видео |

| «Пустой терминал → готовая конфигурация» | ❌ Формат другой | Сценическая демонстрация возможностей, а не пошаговая настройка окружения |

## ⏳ Главное: материалу полтора года

Кейноут снят 22 мая 2025, пост вышел 21 августа 2026. За это время Claude Code изменился радикально, и часть показанного в демо просто устарела:

- **кастомные команды слились со скиллами** — `.claude/commands/deploy.md` и `.claude/skills/deploy/SKILL.md` теперь дают одно и то же;
- появились скиллы, хуки, субагенты, `/rewind`, режимы прав в цикле `Shift+Tab`, интеграции с Chrome, Slack, десктопом и вебом;
- в справочнике сейчас **65 встроенных команд и 66 флагов CLI** — на момент записи их было заметно меньше;
- концепция **петель**, которую пост приписывает этому видео, оформилась позже.

> [!warning] Брать как руководство по настройке не стоит
> Это выступление с анонсом на сцене, а не инструкция. Смотреть его имеет смысл как исторический срез — «каким Claude Code показывали при выходе в общий доступ». Для настройки бери актуальные источники, они ниже.

## 🛠️ Что смотреть вместо этого

Настройка Claude Code сегодня — пять слоёв:

| Слой | Зачем |
| :--- | :--- |
| `CLAUDE.md` | правила и память проекта |
| **MCP-серверы** | доступ к БД, логам, GitHub, браузеру |
| **Скиллы** | повторяемые многошаговые процедуры |
| **Хуки** | детерминированная автоматизация и проверки |
| **Субагенты** | изолированный ресёрч и ревью |

Начинать со всего сразу не нужно — один аккуратно написанный `CLAUDE.md` уже даёт заметный эффект.

## 💡 Итог

- Видео настоящее, но это **десятиминутное кейноут-демо мая 2025**, а не гайд по настройке с нуля. Единственное, что пост угадал точно, — хронометраж.
- **Cat Wu — продакт-менеджер, а не инженер.**
- Материалу **полтора года**, и ключевые вещи в Claude Code с тех пор изменились.
- Лежит на **стороннем канале-перезаливе** с 3,7 тыс. просмотров, а не на канале Anthropic.
- Рамку «промптинг → циклы → агенты → самоулучшение» пост притянул: концепция реальная, но появилась позже этого выступления.
