## 📖 Описание каждого агента

### **Claude Code**
*Разработчик:* Anthropic | *Лицензия:* Проприетарная | *Проверено:* 12.10.2026  
Агент через CLI, IDE, десктоп и веб: анализирует код, вносит изменения, запускает тесты, итеративно решает задачи. Модели — **Opus 5.5, Sonnet 5.5, Haiku 5.5** и **Fable 5.1** (Fable — по отдельному доступу). В Coding Agents Index первое место у связки с **Sonnet 5.5** (68,4), третье — с Opus 5.5 (66,0). Можно назначать отдельную модель субагентам и подключать «модель-советника» (`/advisor`). Репозиторий: ★150k, версия v2.1.296 (09.10.2026). Подробности — в [гайде](Claude%20Code%20%E2%80%94%20%D0%B3%D0%B0%D0%B9%D0%B4.md) и [шпаргалке](Claude%20Code%20%E2%80%94%20%D1%88%D0%BF%D0%B0%D1%80%D0%B3%D0%B0%D0%BB%D0%BA%D0%B0%20%D0%BA%D0%BE%D0%BC%D0%B0%D0%BD%D0%B4.md).  
*Цена:* Pro $20/мес (или ~$17 при годовой оплате), Max 5x — $100, Max 20x — $200. API: Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Fable 5.1 $10/$50 за 1 млн токенов.

### **Codex CLI**
*Разработчик:* OpenAI | *Лицензия:* Apache 2.0 | *Проверено:* 12.10.2026  
Официальный агент OpenAI: CLI, расширение IDE, облачный Codex Cloud для фоновых задач, iOS. Модели — **GPT-6.1 Sol** (основная на платных планах, `codex --model gpt-6.1-sol`) и флагман **GPT-6 Astra** ($10/$50 за 1 млн токенов). В Coding Agents Index связка Codex + GPT-6.1 Sol набирает 63. ★129k, **22 218 открытых issue** — самый большой поток среди всех агентов.  
*Цена:* в составе ChatGPT: Free, Go $8, Plus $20, Pro $100/$200/$500, Business $20 за место (по сторонним обзорам на октябрь; OpenAI публикует оценки лимитов, а не жёсткие квоты). Либо по API.

### **Muse Code** 🆕
*Разработчик:* Meta (Meta Superintelligence Labs) | *Лицензия:* Проприетарная | *Добавлено:* 13.10.2026  
Терминальный агент Meta: бета **5 августа 2026** на модели Muse Spark 1.2, выход из беты **31 августа**, с **12 октября** доступна **Muse Wonder Full** — только здесь, в API её нет. Работает на **macOS и Linux** (Windows нет), IDE-плагина и GUI на старте не было. В Coding Agents Index связка Muse Code + Wonder Full — **второе место (68,0)**, почти вровень с Claude Code + Sonnet 5.5.  
> [!warning] Данные по умолчанию идут в обучение
> Подписки по умолчанию в режиме **Contributor**: Meta может использовать промпты и ответы для улучшения моделей, а правила запрещают отправлять в этом режиме конфиденциальные и личные данные. Есть и дешёвый тариф Contributor по токенам ($0,10/$0,20) — за ту же цену в виде ваших данных. Для рабочего кода переключите режим.

*Цена:* сам CLI бесплатный; планы считают запросы, а не токены: Everyday $5, High $15 (×3 и свежие модели), Power $50 (×20 к Everyday, с Wonder Full), Maximum $200 (×80). По токенам: Muse Wonder $4/$20. Подробнее о модели — в [заметке о Muse Wonder](../Model/Muse%20Wonder%20%28Meta%29%20%E2%80%94%20%D0%BF%D0%B5%D1%80%D0%B2%D0%B0%D1%8F%20%D1%84%D1%80%D0%BE%D0%BD%D1%82%D0%B8%D1%80-%D0%BC%D0%BE%D0%B4%D0%B5%D0%BB%D1%8C%20Meta%20%28%D0%B1%D0%B5%D0%BD%D1%87%D0%BC%D0%B0%D1%80%D0%BA%D0%B8%20%D0%BF%D1%80%D0%BE%D1%82%D0%B8%D0%B2%20Opus%205.5%20%D0%B8%20GPT-6%20Astra%2C%20%D1%86%D0%B5%D0%BD%D0%B0%2C%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%20%D1%87%D0%B5%D1%80%D0%B5%D0%B7%20API%20%D0%B8%20Muse%20Code%29.md). ### **Grok Build**
*Разработчик:* xAI (SpaceXAI) | *Лицензия:* Проприетарная | *Проверено:* 12.10.2026  
Терминальный агент xAI на **Rust**, бета с **14 мая 2026**. **8 параллельных субагентов**, контекст **2 млн токенов**, план на утверждение до первой строки кода и **Arena Mode** (варианты решения соревнуются). ### **OpenClaw**
*Разработчик:* Peter Steinberger | *Лицензия:* **MIT** | *Проверено:* 12.10.2026  
Самостоятельно хостящийся **персональный AI-агент / computer-use**: шлюз между мессенджерами (Telegram, Slack, Discord, WhatsApp, iMessage, Signal, Teams) и LLM-агентами, которые выполняют реальные действия — файлы, почта, календарь, браузер, — по триггерам и расписанию. Поддерживает Anthropic, OpenAI и локальные модели; требует Node 24, ставится через `openclaw onboard`. В контексте кода — оркестратор: через проекты вроде `claw-orchestrator` запускает Claude Code, Codex, Gemini, Cursor Agent как единый рантайм. История имени: Clawdbot → Moltbot → OpenClaw.

**★392 тысячи — самый популярный проект в заметке**, релизы по календарной схеме (v2026.10.2), около 9,6 тысячи открытых issue.
> [!note] Не путать
> OpenClaw здесь — агент Питера Стайнбергера (`openclaw/openclaw`). Одноимённый ремейк игры Captain Claw — другой проект.

*Цена:* бесплатно (self-hosted, BYOK).

> [!tip] Практика октября 2026
> Выбирать по бенчмаркам по-прежнему бессмысленно: первые три места Coding Agents Index разделяют 2,4 балла, а внутри одного агента дешёвая модель может обойти дорогую. Решают обвязка (инструменты, контекст, песочница), цена под твой объём и поведение агента на **твоём** коде. Проверяется это одним способом — прогнать два-три кандидата на своей реальной задаче.
>
> Опытные разработчики держат «стек» из 2–3 инструментов: IDE-агент для повседневного, CLI во втором терминале для тяжёлого рефакторинга, фоновый для задач «сделай и покажи PR».

> [!caution] Три тренда, которые стоит держать в голове
> 1. **Консолидация и смена владельцев.** Cursor стал частью SpaceX, Windsurf — Devin Desktop, Gemini CLI уступил место Antigravity, Amazon Q — Kiro, Roo Code и Kimi CLI заархивированы. Инструмент, выбранный сегодня, через полгода может принадлежать другой компании. Закладывай стоимость миграции.
> 2. **Новые крупные игроки.** За два месяца на рынок вышли Meta (Muse Code) и DeepSeek (DeepSeek Harness) — и сразу в верхние строки по качеству и популярности.
> 3. **Открытые проекты не исчезают, а застывают.** Aider — без коммитов с мая, Continue — с июля, AutoResearch — с марта, Devika — с сентября 2025. Смотреть надо не на звёзды, а на дату последнего коммита и на то, вливаются ли PR.
