## 📖 Описание каждого агента

### **Claude Code**
*Разработчик:* Anthropic | *Лицензия:* Проприетарная | *Проверено:* 27.10.2026  
Агент через CLI, IDE, десктоп и веб: анализирует код, вносит изменения, запускает тесты, итеративно решает задачи. Модели — **Opus 5.5, Sonnet 5.5, Haiku 5.5** и **Fable 5.1** (Fable — по отдельному доступу). В Coding Agent Index v2.0 первое место у связки с **Opus 5.5** (61,7), второе — с Sonnet 5.5 (59,3), четвёртое — с Fable 5.1 (57,6). Можно назначать отдельную модель субагентам и подключать «модель-советника» (`/advisor`). Репозиторий: ★154k, версия v2.1.311 (26.10.2026). Подробности — в [гайде](Claude%20Code%20%E2%80%94%20%D0%B3%D0%B0%D0%B9%D0%B4.md) и [шпаргалке](Claude%20Code%20%E2%80%94%20%D1%88%D0%BF%D0%B0%D1%80%D0%B3%D0%B0%D0%BB%D0%BA%D0%B0%20%D0%BA%D0%BE%D0%BC%D0%B0%D0%BD%D0%B4.md).  
*Цена:* Pro $20/мес (или ~$17 при годовой оплате), Max 5x — $100, Max 20x — $200. API: Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 5.5 $0,10/$0,50 (до 100K токенов в запросе), Fable 5.1 $10/$50 за 1 млн токенов.

### **Codex CLI**
*Разработчик:* OpenAI | *Лицензия:* Apache 2.0 | *Проверено:* 27.10.2026  
Официальный агент OpenAI: CLI, расширение IDE, облачный Codex Cloud для фоновых задач, iOS. Модели:
- **GPT-6.1 Sol** — основная на платных планах (`codex --model gpt-6.1-sol`);
- **GPT-6.1 Terra** — легче Sol: на Plus за пять часов даёт примерно вдвое больше сообщений;
- флагман **GPT-6 Astra** ($10/$50 за 1 млн токенов);
- **GPT-6 Luna** — для бесплатного плана и Go.

GPT-5.5 из Codex со входом через ChatGPT убран 14.10.2026, по API-ключу он остаётся.

В Coding Agent Index v2.0 Codex + Astra набирает 54,7, Codex + GPT-6.1 Sol — 54,1, но задача с Sol стоит **$1,50** против $11,42 у лидера. Codex работает и со сторонними моделями: связка с DeepSeek V4.1 Flash — 47,3 при $0,39 за задачу.

★131k, релиз rust-v0.164.0 (23.10.2026), **24 905 открытых issue** — самый большой поток среди всех агентов.  
*Цена:* в составе ChatGPT: Free и Go $8 — только GPT-6 Luna в десктопе; Plus $20; Pro $100/$200/$500 (режим Ultrafast — на $500); Business $20 за место при годовой оплате ($25 помесячно). OpenAI публикует оценки лимитов, а не жёсткие квоты. Либо по API.

### **Muse Code** 🆕
*Разработчик:* Meta (Meta Superintelligence Labs) | *Лицензия:* Проприетарная | *Добавлено:* 13.10.2026  
Терминальный агент Meta: бета **5 августа 2026** на модели Muse Spark 1.2, выход из беты **31 августа**, с **12 октября** доступна **Muse Wonder Full** — только здесь, в API её нет. Работает на **macOS и Linux** (Windows нет), IDE-плагина и GUI на старте не было. В Coding Agent Index v2.0 связка Muse Code + Wonder Full — **третье место (58,9)**; в прежней версии индекса была второй.  
> [!warning] Данные по умолчанию идут в обучение
> Подписки по умолчанию в режиме **Contributor**: Meta может использовать промпты и ответы для улучшения моделей, а правила запрещают отправлять в этом режиме конфиденциальные и личные данные. Есть и дешёвый тариф Contributor по токенам ($0,10/$0,20) — за ту же цену в виде ваших данных. Для рабочего кода переключите режим.

> [!tip] Практика октября 2026
> Выбирать по бенчмаркам по-прежнему бессмысленно. В Coding Agent Index v2.0 первые три места укладываются в 2,8 балла, а смена набора тестов в октябре переставила лидеров местами. Внутри одного агента дешёвая модель может обойти дорогую, а цена задачи у соседей по таблице отличается в разы. Решают обвязка (инструменты, контекст, песочница), цена под твой объём и поведение агента на **твоём** коде. Проверяется это одним способом — прогнать два-три кандидата на своей реальной задаче.
>
> Опытные разработчики держат «стек» из 2–3 инструментов: IDE-агент для повседневного, CLI во втором терминале для тяжёлого рефакторинга, фоновый для задач «сделай и покажи PR».

> [!caution] Три тренда, которые стоит держать в голове
> 1. **Консолидация и смена владельцев.** Cursor стал частью SpaceX и продаётся одной подпиской с Grok; Windsurf стал Devin Desktop; Gemini CLI уступил место Antigravity, Amazon Q — Kiro; TRAE слила отдельные приложения обратно в одно; Roo Code и Kimi CLI заархивированы. Инструмент, выбранный сегодня, через полгода может принадлежать другой компании или продаваться по другой схеме. Закладывай стоимость миграции.
> 2. **Новые крупные игроки и свои модели.** За два месяца на рынок вышли Meta (Muse Code) и DeepSeek (DeepSeek Harness) — и сразу в верхние строки по качеству и популярности. Вендоры обвязок всё чаще ставят свою модель по умолчанию (SWE-2 у Devin, Grok в Cursor), а сторонние фронтир-модели уводят в оплату по API.
> 3. **Открытые проекты не исчезают, а застывают.** Aider — без коммитов с мая, Continue — с июля, AutoResearch — с марта, Devika — с сентября 2025. Смотреть надо не на звёзды, а на дату последнего коммита и на то, вливаются ли PR.
