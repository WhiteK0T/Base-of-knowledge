# Orca — десктопная оболочка для нескольких кодинг-агентов сразу

Приложение (Electron, macOS / Windows / Linux), которое запускает Claude Code, Codex, Cursor CLI, GitHub Copilot CLI, OpenCode, Amp, Pi, oh-my-pi, Rovo Dev **параллельно, каждого в своём git-worktree**, и показывает их в одном месте. Плюс терминал уровня Ghostty с WebGL-рендерингом, встроенный Chromium с «Design Mode» и мобильный компаньон.

Пост в «Не баг, а фича»: *«управляет сразу несколькими агентами для кодинга параллельно. Пока вы пьёте кофе, целая команда занимается вашим проектом»*. По сути — верно; ниже то, что к этому стоит добавить.

## Что умеет, кроме параллельного запуска

- **Параллельные worktree.** Один промпт на пять агентов, каждый в своей изолированной ветке; потом сравнение и мерж победителя. Это главная идея.
- **Мобильный компаньон.** iOS (App Store) и Android (APK 0.0.48 прямо из релизов): уведомление о том, что агент закончил, и возможность дослать уточнение с телефона.
- **Терминал.** Сплиты без ограничений, WebGL-рендеринг, скроллбэк переживает перезапуск.
- **Design Mode.** Клик по элементу в настоящем окне Chromium отправляет агенту его HTML, CSS и обрезанный скриншот.
- **Учёт расхода.** Показывает потребление и время сброса лимитов Claude и Codex, позволяет менять аккаунты без перелогина.
- **Headless-режим.** `orca serve` на сервере без графики — в репозитории есть отдельное руководство.

## Установка на своих системах

### ⚠️ Сначала про имя

В Linux-дистрибутивах пакет `orca` **уже занят** — это экранный диктор GNOME для незрячих:

- **Gentoo:** `app-accessibility/orca`
- **Arch:** `extra/orca` 50.2 — «Screen reader for individuals who are blind or visually impaired»

`emerge orca` или `pacman -S orca` поставит вам скринридер, а не это приложение. Нужные имена — другие.

### Gentoo (основная)

Ebuild-а нет ни в дереве, ни в известных оверлеях. Рабочий путь — **AppImage** из релиза:

```bash
wget https://github.com/stablyai/orca/releases/latest/download/orca-linux.AppImage
chmod +x orca-linux.AppImage
./orca-linux.AppImage
```

Для AppImage понадобится FUSE (`sys-fs/fuse`); либо распаковать через `--appimage-extract` и запускать напрямую. Собрать из исходников тоже можно — это Electron-приложение с pnpm-воркспейсом, см. `CONTRIBUTING.md`, но готовой сборочной инструкции под Gentoo авторы не дают.

### Debian / Ubuntu

Есть готовый пакет в релизе:

```bash
wget https://github.com/stablyai/orca/releases/latest/download/orca-ide_1.4.198_amd64.deb
sudo apt install ./orca-ide_1.4.198_amd64.deb
```

Для arm64 — `orca-ide_1.4.198_arm64.deb`.

### Arch

Единственная система из четырёх, где есть нормальный путь из репозитория пользователей — но пакетов в AUR **несколько с разными именами**, и это сбивает:

```bash
yay -S stably-orca-bin      # 1.4.198, 3 голоса — рекомендуется в README
# альтернативы: onorca-bin, orca-ide-bin (тоже 1.4.198), stably-orca-git (сборка из исходников)
```

Не перепутайте с `orca-slicer` (слайсер для 3D-печати, 43 голоса) и с `orca` из `extra` — скринридером.

### Entware (ASUS RT-AX56U, armv7)

❌ Неприменимо. Это Electron-приложение с графическим интерфейсом; сборки только под x86_64 и arm64, armv7 нет вообще. Ближайшее осмысленное — `orca serve` на настоящем Linux-сервере, но не на роутере с 512 МБ ОЗУ.

## Итог

Пост описал Orca точно — она действительно гоняет несколько кодинг-агентов параллельно, и это MIT-проект с живыми релизами и полноценными сборками под Linux, включая arm64.

Стоит добавить три вещи, которых в посте нет. Агенты работают **на ваших подписках** — «команда» бесплатна только в смысле оболочки. Очередь в репозитории огромная: **2 713 issue и 2 912 PR** открыты одновременно. И чисто практическое: на Gentoo и Arch команда `orca` ставит экранный диктор GNOME, а не это приложение — нужны `stably-orca-bin`, `.deb` из релиза или AppImage.
