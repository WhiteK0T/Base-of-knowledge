# 🧩 claude-ide.nvim — Neovim как «IDE» в связке с Claude Code

**claude-ide.nvim** ([github.com/HelpFreedom/claude-ide.nvim](https://github.com/HelpFreedom/claude-ide.nvim)) — плагин для **Neovim**, который превращает редактор в мини-IDE рядом с **[Claude Code](../Claude%20Code%20%E2%80%94%20%D0%B3%D0%B0%D0%B9%D0%B4.md)**, работающим в **отдельном терминале**. Даёт: справа — дерево файлов с **live-бейджами изменений** (`A`/`M`/`D`, `●` на папках), inline-**диффы** (старый код приглушённо-красным над новым) и **автоснапшоты проекта, листаемые «как страницы книги»** (`[p`/`]p`). GPL-3.0, Lua.

> [!caution] Трезво про «зрелость»: это свежий проект-однодневка автора канала
> - **Совсем новый и крохотный**: репозиторий создан и залит **18 июля 2026** (первый и последний пуш — в один день), на момент заметки **~11★**, форков нет, issue нет. Фактически проект выходного дня.
> - **Автор — Black Triangle** (тот самый канал [@black_triangle_tg](https://t.me/black_triangle_tg)), а «реализация» по README — **самим Claude**. То есть это личный проект автора, а не поддерживаемый комьюнити-плагин уровня официальных интеграций.
> - Вывод: **интересная идея на посмотреть/пощупать**, но не жди стабильности, экосистемы и долгой поддержки. Для рабочего ежедневного инструмента — с оглядкой.

> [!info] Что это по сути (без хайпа «IDE»)
> Не полноценная IDE, а **визуальная надстройка над Claude Code** внутри nvim:
> - **Дерево файлов** справа с пометками, какие файлы Claude трогал в этом ходу.
> - **Inline-дифф** прямо в буфере: заменённый/удалённый код показывается тускло-красным над новым (зелёным). Удобно глазами сверять правки агента.
> - **«Страницы»**: один ход Claude = один снимок состояния проекта. Листаешь историю правок вперёд/назад как книгу; старые страницы — только для чтения.

> [!info] Как устроено (важно понимать, что оно кладёт в проект)
> Механизм — на **хуках Claude Code** + **теневой git-репозиторий**:
> ```
> claude (другой терминал)
>   └─ hooks → bin/claude-ide-hook.sh → .claude-ide/events.jsonl
> nvim ── таймер читает события:
>   file_op    → бейджи в дереве + подсветка диффа
>   turn_start → правки пользователя коммитятся страницей [user]
>   turn_end   → коммит страницы [claude] в теневой git (.claude-ide/repo)
> ```
> - `:ClaudeIDEInit` создаёт теневой репозиторий **`.claude-ide/`** и **прописывает hooks в `.claude/settings.local.json`**. Теневой git не пересекается с твоим `.git` и уважает `.gitignore`.
> - **После init нужно перезапустить `claude`** в проекте — hooks считываются только при старте сессии.
> - При нескольких открытых nvim коммитит только один (pid-lock), остальные читают.

> [!warning] Нюансы и ограничения (некоторые прямо в README)
> - **Хуки заработают только после перезапуска `claude`** — забыл перезапустить, «магии» не будет.
> - **Правки пользователя во время хода Claude попадают в страницу `[claude]`** — авторство в истории может «смазаться».
> - Правки Claude **через Bash** (`rm`, `sed`, …) **не проходят через матчер hooks**, но подхватываются сверкой теневого репо в конце хода — то есть в реальном времени бейджи по таким правкам могут не появиться, только по итогу.
> - Скрипт `bin/install-nvim.sh` ставит официальный **nvim только под x86_64** (glibc ≥ 2.31). Тебе он не нужен: на Gentoo/Arch/Debian ставишь Neovim из своего пакетного менеджера.
> - Требуется **Neovim ≥ 0.10**, `git`, **`jq` или `python3`**, **Claude Code ≥ 2.x**.

> [!info] Команды/клавиши (по умолчанию)
> `:ClaudeIDEToggle` (`<leader>e`) — дерево; `:ClaudeIDEInit` — init+hooks; `[p`/`]p` — листать страницы; `<leader>gl` — к текущему; `<leader>gp` — список страниц; `<leader>gd` — вкл/выкл inline-дифф; `<leader>gc` — снять пометки; `:ClaudeIDEStatus` — диагностика. Всё настраивается (`setup{}`): ширина дерева, `poll_ms`, авто-открытие, `settings.local.json` vs общий `settings.json`, переназначение клавиш, свои highlight-группы.

## 🖥️ Применимость на системах владельца

Плагин живёт там, где у тебя **Neovim + Claude Code** (то есть на рабочих десктопах):

| Система | Как |
| :--- | :--- |
| **Gentoo (основная) / Debian-Ubuntu / Arch** | ✅ Neovim ≥ 0.10 из Portage/apt/pacman + Claude Code. Ставить через `lazy.nvim`/`vim-plug` (`HelpFreedom/claude-ide.nvim`), затем `:ClaudeIDEInit` и **перезапустить `claude`**. `install-nvim.sh` не нужен — nvim берёшь из пакетов |
| **Windows** | ⚠️ формально Neovim-плагин кроссплатформенный, но завязан на shell-хук (`.sh`) и `jq/python3`; на голом Windows без WSL/Git Bash могут быть шероховатости. Реалистичнее — под WSL |
| **Entware / RT-AX56U** | ➖ неактуально: роутер — не рабочая станция с Claude Code; редактируешь код не там |

> [!tip] Тебе по профилю (Claude Code + Linux)
> Ты и так работаешь через Claude Code — если сидишь в **Neovim**, это способ видеть правки агента **визуально** (дерево-бейджи + inline-дифф) и **отматывать историю ходов**, не полагаясь только на `git diff`. Альтернативы: **официальные IDE-интеграции** Claude Code (VS Code, JetBrains) и комьюнити-плагин `coder/claudecode.nvim` (там упор на MCP/шаринг выделения — другой подход). Фишка именно этого — снапшоты-«страницы» через теневой git. Помни про свежесть проекта: сначала попробуй на некритичном репо.
