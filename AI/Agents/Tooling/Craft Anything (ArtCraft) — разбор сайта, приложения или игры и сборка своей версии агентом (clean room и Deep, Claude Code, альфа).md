# 🛠️ Craft Anything (ArtCraft) — изучить программу и собрать свою версию руками агента

[**Craft Anything**](https://github.com/storytold/craft-anything) — приложение и CLI от сообщества художников ArtCraft. Оно изучает сайт, программу или игру, а затем поручает агенту кода собрать собственный проект «по мотивам» и сравнивает результат с оригиналом, пока они не станут похожи. Внутри — свой движок реверс-инжиниринга на Rust. Заметка по посту [«Не баг, а фича»](https://t.me/bugnotfeature/28827) от 3 ноября 2026 года, сверена с репозиторием.

| | |
| :--- | :--- |
| Авторы | ArtCraft (`storytold` на GitHub) — те же, что делают набор приложений Craft App Suite (раздел 3) |
| Лицензия | MIT или Apache-2.0 на выбор; название и логотипы ArtCraft — отдельно, это товарные знаки |
| Репозиторий | с 31 октября 2026 года, ~22 тыс. звёзд и ~4,4 тыс. форков за неделю |
| Состояние | **ранняя альфа**: установщики уже есть, но часть функций не проверена в деле |
| Системы | Windows, macOS, Linux (x86_64, aarch64, riscv64), FreeBSD; просмотрщик файлов в браузере на WebAssembly |

## 1. Как работает

Четыре шага. Когда решение за вами, приложение спрашивает простыми словами.

1. **Изучение** — оригинал разбирается: страницы на разной ширине экрана, интерфейс, а в режиме Deep ещё код, файлы и поведение при запуске.
2. **Сборка** — агент кода создаёт новый проект на языке, фреймворке или движке из вашего запроса. Например, «пересоздай этот сайт» или «повтори геймплей этой игры на Rust». Игры можно пересобирать в Unity, Unreal или Godot.
3. **Проверка** — сборка сравнивается с оригиналом:
   - страницы — на трёх ширинах экрана;
   - игры — их собственными самотестами;
   - приложения — запусками.

   Итог — список того, что ещё не совпадает.
4. **Готово** — результат можно открыть или поиграть, либо попросить доработок, и цикл повторится.

Режимов интерфейса два: **Simple** — «что хотите сделать?» и кнопка Start; **Advanced** — полный верстак со списком функций, псевдокодом C, дизассемблером, hex, графом вызовов и консолью агента.

### Clean room или Deep

| Режим | Что читает |
| :--- | :--- |
| **Clean room** (по умолчанию) | только то, что видно снаружи: скриншоты, видимый текст, раскладку, цвета, шрифты и отступы, открытые меню, а с вашего разрешения — снимок окна приложения. Инструменты, которые заглядывают внутрь, отказывают и подсказывают, как включить Deep |
| **Deep** | всё, «для личного использования»: код и файлы программы встроенными декомпилятором и дизассемблером (и Ghidra, если установлена), JavaScript сайта, загрузку его стартовой страницы |

Clean room — правило того, что Craft Anything предлагает и запрещает, а **не песочница**. Агент кода работает с вашими правами, и что он может прочитать или запустить, зависит от его собственных разрешений.

### Кто собирает

- **Claude Code — основной сборщик.** Craft Anything запускает ваш собственный, немодифицированный `claude` с вашим входом. Ваш аккаунт он не видит. Использование подпадает под ваше соглашение с Anthropic.
- **Copilot CLI и Grok Build** подключаются через протокол ACP, со своим входом. Адаптер Codex написан, но на реальной установке ещё не проверен.
- **Gemini CLI, Qwen Code, opencode, goose, Hermes, Maki** тоже говорят на ACP, но из них в деле проверен только Maki.
- **Для вопросов и анализа** можно подключить API Anthropic, OpenAI, OpenRouter, xAI или локальный OpenAI-совместимый сервер. Сборка через ключи API пока не проверена вживую.
- **Картинки и 3D-модели** генерируются по желанию, через ваш ключ fal.ai.

### Движок

320 инструментов, и каждый из них — одновременно команда CLI и инструмент MCP. Любой агент может гонять тот же движок, что и приложение. Разбор не требует ИИ вовсе. Движок понимает:
- нативные программы, .NET, Java;
- Android и приложения Apple;
- Electron и JavaScript, сайты;
- прошивки, дампы трафика, базы данных и файлы игр.

Свои декодеры, дизассемблер и декомпилятор работают без сторонних программ; Ghidra — по желанию.

## 2. Что за словами поста

- **«Клонируем любой сайт, игру или приложение в один клик».** Кнопка Start одна, но дальше идёт цикл «изучение → сборка → проверка» с вопросами и подтверждениями. Результат — новый проект, похожий на оригинал, а не его копия. И всё это ранняя альфа.
- **«Несмотря на баны от OpenAI и Anthropic» — наоборот.** Craft Anything работает на вашем же Claude Code. В [`docs/claude-code.md`](https://github.com/storytold/craft-anything/blob/main/docs/claude-code.md) авторы разбирают, почему это укладывается в условия Anthropic на октябрь 2026 года. Сторонним приложениям нельзя предлагать вход через Claude.ai и пропускать запросы через чужие токены, поэтому запускается немодифицированный `claude` пользователя. И даже это авторы советуют подтвердить у Anthropic, особенно для будущего управляемого тарифа.
- **«Разбирает вёрстку, интерфейс, цвета, шрифты, меню и код».** Код читается только в режиме Deep. По умолчанию работает «чистая комната» — только то, что видно снаружи.
- **«Юзеры уже собрали замену почти всему пакету Adobe».** Речь, видимо, о Craft App Suite — собственных приложениях ArtCraft (раздел 3). Их создавали 30 сентября – 9 октября, до выхода Craft Anything, и это не сборки пользователей.
- **«Летит в топ GitHub»** — да, ~22 тыс. звёзд за первую неделю.

## 4. Право и безопасность

- **Чьё ПО.** README просит применять инструмент к своему ПО или к тому, которое вам разрешено изучать. Craft Anything не обходит DRM, авторизацию и античиты. Агенту велено не копировать логотипы, фотографии и тексты без подтверждения прав.
- **Режим Deep.** Декомпиляция может быть запрещена лицензией программы или законом страны. Похожий результат не даёт права распространять чужой дизайн или товарные знаки.
- **Установка зависимостей запускает код.** Когда сборщик ставит зависимости проекта, пакеты npm, скрипты сборки Rust и пакеты Python выполняют свой код на вашей машине. Craft Anything спрашивает перед командой нового вида (`npm`, `cargo`…). «Всегда разрешать» для `npm` стоит выбирать только для проектов, зависимостям которых доверяете. Есть `npm install --ignore-scripts` — установка без скриптов.
- **Flatpak-сборка изолирована** и не может запустить браузер, а он нужен для изучения сайтов. Для сайтов берите другую сборку.

## 5. Установка

Готовые сборки — на странице [релизов](https://github.com/storytold/craft-anything/releases), к каждому файлу есть сумма в `SHA256SUMS.txt`.

| Система | Вариант |
| :--- | :--- |
| Любой Linux | AppImage (x86_64, aarch64) — внутри и CLI: `<AppImage> --cli <команда>`; tarball, в том числе riscv64 |
| Debian / Ubuntu | `.deb` из релизов |
| Gentoo | AppImage или tarball; из исходников — Rust 1.97+: `dev-lang/rust-bin` 1.99 или `dev-lang/rust` |
| Arch | AppImage или tarball; из исходников — `sudo pacman -S rust` (1.99) |
| FreeBSD | tarball x86_64 |
| Entware | неприменимо: настольное приложение плюс агент кода |

Сборка из исходников. Нужен Rust 1.97+: в Debian 13 даже в `trixie-backports` только 1.96, поэтому на Debian и Ubuntu — `rustup`. Для настольного приложения на Debian и Ubuntu нужны ещё `libxkbcommon-dev libwayland-dev libx11-dev libxrandr-dev libxi-dev libgl1-mesa-dev libgtk-3-dev`.

```bash
git clone https://github.com/storytold/craft-anything && cd craft-anything
cargo run --release -p craft-anything                  # настольное приложение
cargo install --path apps/craft-anything-cli           # CLI
craft-anything-cli doctor                              # что установлено и какой агент найден

craft-anything-cli rebuild https://example.com "Recreate this website"
craft-anything-cli rebuild - "A snake game in Rust" --rounds 1
craft-anything-cli mcp                                 # все инструменты как MCP-сервер
```

Проекты складываются в `Documents/Craft Anything`. В каждом:

| Что | Содержимое |
| :--- | :--- |
| `craft.json` | запрос и история |
| `capture/` | снятое с оригинала |
| `app/` | сам проект |
| `checks/` | сравнения |
| `investigation.cany/` | улики |
| `inbox/` | открытые вопросы |
