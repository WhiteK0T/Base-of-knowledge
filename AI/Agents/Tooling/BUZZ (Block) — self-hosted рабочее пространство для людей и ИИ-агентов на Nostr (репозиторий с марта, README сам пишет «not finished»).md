## 🧩 Что это на самом деле

Из собственного описания проекта: **самохостимое рабочее пространство, где люди и ИИ-агенты сидят в одних комнатах**. Технически — это **relay Nostr**: каждое сообщение, реакция, шаг воркфлоу, одобрение ревью и git-событие становятся подписанным событием в одном журнале. Одинаковая форма, одинаковая модель личности и общий аудит-след независимо от того, человек автор или процесс.

Отсюда главная идея: агент получает **те же возможности, что и человек в команде** — открывать репозитории, слать патчи, ревьюить код, запускать воркфлоу, править канвасы, создавать каналы, — с тем же аудит-следом, но другим ключом.

> [!note] Авторы иронизируют над собственной категорией
> В README прямо написано: *«Yes, it's another AI-adjacent developer tool. We're sorry»*. Разница, по их словам, в том, что агенты внутри реально **что-то делают**, а не просто отвечают в чате.

## ⏱️ Про «5 минут»

Сценариев четыре, и по времени они очень разные:

| Путь | Что нужно | Реально быстро? |
| :--- | :--- | :--- |
| Просто попробовать приложение | Готовый бинарник: `.dmg`, `.AppImage`/`.deb`, `.exe` | ✅ Да, но по умолчанию оно смотрит в `ws://localhost:3000` — релей всё равно нужен |
| Свой релей без возни с серверами | Деплой в Railway в один клик | ✅ Ближе всего к обещанию |
| Сборка из исходников | Docker + Hermit **либо** Rust 1.88+, Node 24+, pnpm 10+, `just` | ❌ Полная сборка Rust и Node |
| Прод на VPS | `docker compose`: Postgres, Redis, MinIO, опционально Caddy/TLS | ❌ Полноценный стек |

> [!caution] Windows-сборка не подписана
> В README отдельно оговорено: инсталлятор `*-setup_alpha-unsigned.exe` не подписан, поэтому SmartScreen покажет «Windows protected your PC». Плюс для агентского shell-инструмента нужен bash — ставится Git for Windows, либо путь задаётся через `BUZZ_SHELL`.

## 🤖 Чем это интересно именно тебе

Самое любопытное для практики — `buzz-cli`: **JSON на вход, JSON на выход**, спроектирован под LLM. И ACP-обвязка, которая по заявлению README работает с **Goose, Codex и Claude Code**.

То есть сценарий не «ещё один Slack», а «канал, куда можно посадить своего агента наравне с людьми, с правами и общим журналом событий». Для команды, которая уже гоняет [Claude Code](../Claude%20Code%20%E2%80%94%20%D1%88%D0%BF%D0%B0%D1%80%D0%B3%D0%B0%D0%BB%D0%BA%D0%B0%20%D0%BA%D0%BE%D0%BC%D0%B0%D0%BD%D0%B4.md), это ближе к рабочей идее, чем к хайпу.

Оговорка: гейты одобрения воркфлоу — в колонке «подключается». То есть автоматизации уже запускаются, а вот человеческое подтверждение перед действием агента ещё не доделано. Для команды это как раз тот кусок, ради которого всё и затевается.

| **Entware / RT-AX56U** | ❌ Неприменимо |
