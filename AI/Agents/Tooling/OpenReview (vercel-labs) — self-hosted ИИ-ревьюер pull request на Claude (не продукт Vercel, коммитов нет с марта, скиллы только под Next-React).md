# OpenReview — self-hosted ИИ-ревьюер pull request на Claude

Бот, которого вы разворачиваете **у себя** на Vercel и подключаете к своему GitHub App. Дальше в комментарии к pull request пишете `@openreview` — бот поднимает изолированную песочницу, клонирует ветку PR, читает диф, гоняет линтеры и тесты, оставляет замечания построчно и при желании сам коммитит правки в ветку.

Пост в «Не баг, а фича» подаёт его как *«жестокого оценщика кода от Vercel, который будет прогонять весь проект»*. Инструмент настоящий и сделан аккуратно, но три вещи в описании не сходятся, а одна перевёрнута с ног на голову.

## Главный подвох: скиллы только под Next.js и React

«Гибкие навыки» из поста звучат как «настраивается под что угодно». Из коробки же встроено **семь скиллов**, и все они про стек самого Vercel:

| Скилл | Про что | Файлов правил |
| :--- | :--- | ---: |
| `vercel-react-best-practices` | производительность React и Next.js | 61 |
| `vercel-react-native-skills` | React Native и Expo | 39 |
| `next-best-practices` | файловые конвенции, границы RSC, данные, метаданные | 20 |
| `vercel-composition-patterns` | паттерны композиции компонентов | 11 |
| `next-cache-components` | PPR, `use cache`, `cacheLife`, `cacheTag` | 1 |
| `next-upgrade` | обновление Next.js по официальным гайдам | 1 |
| `web-design-guidelines` | доступность и Web Interface Guidelines | 1 |

Итого 134 файла в `.agents/`, и **ни одного про Python, Go, Rust, Java, C++ или SQL**. Все семь тянутся из `vercel-labs/next-skills` и `vercel-labs/agent-skills` (зафиксированы хешами в `skills-lock.json`).

Для проекта на Next.js это отличный набор. Для всего остального «жестокий оценщик» приходит с пустыми руками — знания уровня «общий здравый смысл модели» плюс то, что вы напишете сами.

Механика загрузки, кстати, та же, что у скиллов Claude Code: *«The agent sees only skill names and descriptions in its system prompt. When a request matches a skill, it calls `loadSkill` to get the full instructions»* — постоянно в контексте только имена и описания.

## Как это устроено внутри

Пайплайн (`workflow/steps/`, 13 шагов): проверка прав на пуш → создание песочницы → `depth: 1` клон ветки PR → установка зависимостей → настройка git → запуск агента → проверка незакоммиченных изменений → коммит и пуш → остановка песочницы.

Агент (`lib/agent.ts`) — это `DurableAgent` из Vercel Workflow с пятью инструментами: `bash`, `readFile`, `writeFile`, `reply` и `loadSkill`. Системный промпт заканчивается инструкцией *«Start by running `gh pr diff <PR>` to see what changed in this PR»* — отсюда и вывод про «диф, а не весь проект».

Стек: Next.js, Vercel Workflow (`workflow@4.1.0-beta.56`, **бета**), Vercel Sandbox (`@vercel/sandbox@1.7.1`), AI SDK 6, Chat SDK, Octokit. В `package.json` стоит `"private": true`.

## Сколько это стоит

Расклад по деньгам честнее, чем можно ждать: у **Vercel Sandbox есть реальная бесплатная квота** на тарифе Hobby, проверено по их документации:

| Ресурс | Hobby (включено) | Pro |
| :--- | :--- | :--- |
| Sandbox Active CPU | 5 часов/мес | $0,128/час |
| Provisioned Memory | 420 ГБ-часов/мес | $0,0212/ГБ-час |
| Создание песочниц | 5 000/мес | $0,60 за 1 млн |
| Трафик наружу | 20 ГБ/мес | $0,15/ГБ |

И важное: *«Sandbox is free for Hobby users within the usage quotas… You **will not be charged** for any additional usage. Once you exceed the quotas, sandbox creation is paused»* — то есть на Hobby внезапного счёта не будет, просто перестанут создаваться песочницы.

**А вот Claude бесплатным не бывает.** `ANTHROPIC_API_KEY` — обязательная переменная окружения, и каждое ревью с чтением файлов, запуском линтеров и написанием комментариев оплачивается вашим ключом. Именно здесь, а не в хостинге, живёт настоящая стоимость.

## Что настораживает

**Репозиторий заморожен.** 77 коммитов уложились в шесть дней, с 1 по 6 марта 2026 года, и с тех пор — ничего. На момент проверки это **шесть месяцев тишины** при 12 открытых issue. README сам называет проект бетой и внутренним экспериментом.

Следствие видно в коде: модель зашита строкой `"anthropic/claude-sonnet-4.6"`, то есть на поколение назад от актуальных. Чтобы поставить свежую, придётся править исходник — благо это одна строка.

**Лицензия заявлена, но не оформлена.** В README есть раздел `## License — MIT`, но файла `LICENSE` в репозитории нет, и GitHub лицензию не распознаёт (`license: null` в API). Формально для форка и коммерческого использования это серая зона: строчка в README — не то же самое, что лицензионный файл. Для собственного использования неважно, для встраивания в рабочие процессы — стоит уточнить у авторов.

**Права GitHub App широкие.** Contents / Issues / Pull requests на запись плюс возможность пушить в ветку PR. Это необходимо для автопочинки, но означает, что бот с ключом Claude может менять код в ваших репозиториях. Ставить стоит точечно, на конкретные репозитории, а не на всю организацию.

## Установка

Сервис облачный по своей природе — он живёт на Vercel, локальной установки «под систему» у него нет. Порядок из README:

1. Развернуть репозиторий в свой аккаунт Vercel (есть кнопка Deploy, шаблон подтягивает Upstash KV).
2. Создать GitHub App: webhook `https://<деплой>.vercel.app/api/webhooks`, права Contents / Issues / Pull requests на чтение-запись, Metadata на чтение; подписка на события Issue comment и Pull request review comment.
3. Прописать переменные: `ANTHROPIC_API_KEY`, `GITHUB_APP_ID`, `GITHUB_APP_INSTALLATION_ID`, `GITHUB_APP_PRIVATE_KEY`, `GITHUB_APP_WEBHOOK_SECRET`, опционально `REDIS_URL` (без него состояние в памяти).
4. Установить App на нужные репозитории и написать `@openreview` в комментарии к PR.

Локально для разработки — `bun install && bun dev`. Bun есть везде: **Gentoo** — оверлеи (в основном дереве пакета нет, ставится официальным скриптом или из исходников), **Debian/Ubuntu** и **Arch** — официальный установщик `curl -fsSL https://bun.sh/install | bash`, в AUR есть `bun-bin`. На **Entware (armv7)** это неприменимо: Next.js-приложение с песочницами Vercel на роутере не живёт, да и смысла нет — рабочая часть всё равно исполняется в облаке Vercel.

Полностью автономной альтернативы у этого пайплайна нет: Vercel Sandbox и Vercel Workflow — проприетарные сервисы, отвязать бота от них означает переписать половину.

## Итог

Хорошо сделанный демонстратор технологий Vercel, который действительно умеет то, что обещает по механике: изолированная песочница, построчные подсказки с кнопкой применения, автопочинка с пушем в ветку, расширяемые скиллы.

Но «оценщик от Vercel, который прогоняет весь проект» — не то, что здесь есть. Это **эксперимент лаборатории**, замороженный с 6 марта 2026 года; работает он **по одному pull request** за вызов, стартуя с `gh pr diff` в пятиминутной песочнице; из семи встроенных скиллов **все семь про Next.js, React и React Native**. И самый заметный ляп поста — реакции: 👍/👎 ставит человек комментариям бота, а не бот коду агента.

Разумное применение: свой Next.js-проект, свой ключ Anthropic, точечная установка GitHub App и понимание, что апстрим за проектом больше не следит.
