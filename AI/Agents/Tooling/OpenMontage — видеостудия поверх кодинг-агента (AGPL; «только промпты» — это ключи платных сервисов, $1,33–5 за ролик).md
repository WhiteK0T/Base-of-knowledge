# OpenMontage — производство видео руками кодинг-агента

Система, которая превращает Claude Code (или Cursor, Copilot, Codex) в конвейер видеопроизводства: исследование темы, сценарий, раскадровка, генерация или подбор ассетов, озвучка, субтитры, монтаж и рендер. Композиции собираются на **Remotion**, склейка — **FFmpeg**.

Пост в «Не баг, а фича»: *«делает из агента для кодинга полноценную студию для производства видео. Раскадровка, сценарий, ассеты, монтаж и рендеринг — всё только на промптах»*.

Описание в целом верное. Не сказано главное — **чем за это платят**.

## Что там внутри

Структура репозитория (2 115 файлов): `.agents/` — 994 файла, `.claude/` — 432, `tools/` — 174, `skills/` — 157, `tests/` — 126, `remotion-composer/` — 41, `pipeline_defs/` — 13. То есть «700+ файлов скиллов и производственных знаний» из описания — не преувеличение, скорее наоборот.

Заметная и честная деталь: авторы отделяют «анимировали пару картинок и назвали это видео» от настоящего видео. Есть путь, где агент собирает корпус из бесплатных стоков и открытых архивов, достаёт реальные клипы движения и монтирует их в таймлайн.

**Backlot** — локальная доска, на которой видно, что конвейер делает прямо сейчас: этапы, сценарий как страница сценария, карточки сцен, каждое решение провайдера и каждый потраченный доллар.

Перед выдачей результата система прогоняет самопроверку: валидация через `ffprobe`, выборка кадров, анализ уровней звука, сверка обещаний по хронометражу и проверка субтитров. Выбор провайдера оценивается по 7 измерениям с журналом решений.

Ещё один вход: можно начать **с чужого ролика** (YouTube, Shorts, Reels, TikTok или локальный файл) и получить производственный план с 2–3 концепциями, честным путём по инструментам, оценкой стоимости и образцом до полной генерации.

## Установка на своих системах

Нужны **Python 3.10+**, **FFmpeg** и **Node.js** (для `remotion-composer`).

```bash
git clone https://github.com/calesthio/OpenMontage && cd OpenMontage
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements.txt
cd remotion-composer && npm install && cd ..
python -m pip install piper-tts
cp .env.example .env      # ключи вписывать по мере надобности
```

| Система | Команды | Нюанс |
| :--- | :--- | :--- |
| **Gentoo** | `emerge -av dev-lang/python media-video/ffmpeg net-libs/nodejs` (USE `npm`), дальше venv как выше | FFmpeg собирать с нужными USE-флагами кодеков — без них рендер упадёт на этапе склейки. Пакета самой OpenMontage нет |
| **Debian / Ubuntu** | `apt install python3-venv ffmpeg nodejs npm`, дальше venv | — |
| **Arch** | `pacman -S python ffmpeg nodejs npm`, дальше venv. В AUR пакета нет | — |
| **Entware (RT-AX56U, armv7)** | ❌ Не вариант. Формально `python3` (3.13.9) и `ffmpeg` (6.1.4) в репозитории armv7 есть, но `node` там **v18.20.2**, а на 512 МБ ОЗУ и 256 МБ флеша ни Remotion, ни рендер видео не живут | Версии проверены по `Packages` для `armv7sf-k3.2` |

Отдельно про лицензию: **AGPL-3.0** означает, что если поднять на этом публичный сервис, исходники модификаций придётся открыть. Для личных роликов неважно, для продукта — принципиально.

## Итог

Проект крупный, живой и, что редкость, честный в деньгах: к каждому демо-ролику приложены реальные затраты. Претензий к нему нет.

Претензия к посту — формулировка «всё только на промптах», которая читается как «бесплатно». На промптах здесь управление; картинки, видео и голос генерируют внешние платные сервисы по вашим ключам, и репозиторий сам называет цену: **от $1,33 за минутный ролик**. Плюс не упомянута AGPL — для личного пользования всё равно, для сервиса на этой базе это ключевое условие.
