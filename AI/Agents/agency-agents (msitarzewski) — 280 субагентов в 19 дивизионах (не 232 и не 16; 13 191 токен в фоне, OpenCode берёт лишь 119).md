# agency-agents — «целое агентство» из субагентов для Claude Code и других агентов

Набор markdown-файлов, каждый из которых описывает специализированного субагента (личность, миссия, рабочие процессы, критерии успеха). Ставится в `~/.claude/agents/` и конвертируется под другие инструменты.

Пост в «Не баг, а фича» описывает его так: *«целое агенство ИИ с 232 специализированными субагентами аж в 16 областях»*.

Пересчитал по репозиторию: цифры другие, причём **в бо́льшую сторону**.

| Параметр | Значение (на 09.09.2026) |
| :--- | :--- |
| Репозиторий | `msitarzewski/agency-agents` |
| Звёзды / форки | 151 174 / 24 330 |
| Лицензия | **MIT** |
| Основной язык | Shell (сами агенты — Markdown) |
| Создан / последний коммит | 13.10.2025 / 09.09.2026 |
| Открытых issue | 140 |
| Размер | ~4,4 МБ, 362 файла |

## Главная цена: 13 191 токен постоянно в контексте

У субагентов Claude Code, как и у скиллов, `name` и `description` попадают в контекст **главного** агента всегда — иначе он не сможет выбрать, кого позвать. Тело файла грузится только при вызове. Замер токенизатором `o200k_base`:

| Что | Токенов |
| :--- | ---: |
| `name` + `description` всех 280 агентов (**всегда в контексте**) | **13 191** — это **6,6 %** окна на 200k |
| Весь фронтматтер целиком | 23 271 |
| Тела агентов (по требованию) | 831 050 |
| В среднем на агента (имя + описание) | 47 |

Самые «тяжёлые» описания: `specialized/specialized-fedramp-rmf-compliance.md` (135 токенов), `engineering/engineering-section-508-specialist.md` (130), `marketing/marketing-multi-platform-publisher.md` (100).

Для сравнения с другими наборами из базы знаний: [rampstack-skills](../Skills/rampstack-skills%20%E2%80%94%20103%20%D1%81%D0%BA%D0%B8%D0%BB%D0%BB%D0%B0%20%C2%AB%D0%B2%D0%BC%D0%B5%D1%81%D1%82%D0%BE%20%D0%BA%D0%BE%D0%BC%D0%B0%D0%BD%D0%B4%D1%8B%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B8%C2%BB%20%28%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B0%20%E2%80%94%2014%20163%20%D1%82%D0%BE%D0%BA%D0%B5%D0%BD%D0%B0%20%D0%B2%20%D1%84%D0%BE%D0%BD%D0%B5%2C%20%D0%BD%D0%B5%D0%B9%D1%80%D0%BE-CEO%20%D0%BD%D0%B5%D1%82%2C%20%D0%BF%D0%BB%D0%B0%D1%82%D0%B5%D0%B6%D0%B8%20%D0%B2%D0%BD%D0%B5%20%D0%BE%D1%85%D0%B2%D0%B0%D1%82%D0%B0%29.md) — 14 163 токена на 103 скилла. То есть здесь агентов почти втрое больше, а фоновая цена сопоставима: описания короче.

Вывод простой: **ставить все 280 разом не надо**. Установщик умеет ставить по дивизионам (`--division`), и это правильный режим.

## Ограничение OpenCode: молча теряется больше половины

Прямо в README есть предупреждение, которое стоит прочитать до установки:

> **OpenCode note:** OpenCode's runtime currently registers only ~119 agents and **silently drops the rest**. Installing a subset with `--division` keeps you under that limit.

То есть на OpenCode из 280 агентов доедет около 119, без сообщения об ошибке. Установщик предупреждает, если выбор превышает лимит.

## Как ставить

Четыре пути из README:

```bash
# 1. Десктопное приложение (macOS / Linux / Windows), отдельный репозиторий, MIT
#    https://github.com/msitarzewski/agency-agents-app

# 2. Claude Code
./scripts/install.sh --tool claude-code
cp engineering/*.md ~/.claude/agents/      # или только один дивизион

# 3. Просто читать файлы как справочник

# 4. Другие инструменты (Copilot, Gemini CLI, OpenCode, Cursor, Aider,
#    Windsurf, Kimi Code, Codex, Osaurus, Hermes, Mistral Vibe, Antigravity)
./scripts/convert.sh
./scripts/install.sh                       # интерактивно, с автодетектом
./scripts/install.sh --tool gemini-cli
```

Активация в сессии — обычным текстом: `«Hey Claude, activate Frontend Developer mode and help me build a React component»`.

### По системам

Здесь нет бинарников и зависимостей — это markdown плюс скрипты на bash, поэтому платформенных различий почти нет.

| Система | Что нужно |
| :--- | :--- |
| **Gentoo** | `git`, `bash` — и всё; `git clone` + `./scripts/install.sh --tool claude-code`. Для десктопного приложения ebuild-а нет, только AppImage/бинарь из релизов `agency-agents-app` |
| **Debian / Ubuntu** | То же самое; приложение — из релизов на GitHub |
| **Arch** | То же самое; в AUR отдельного пакета нет |
| **Entware (RT-AX56U)** | Формально `git` и `bash` в репозитории armv7 есть, файлы скопируются. Практического смысла ноль: агента, который их читает, на роутере не запустить |

## Итог

Набор реальный, живой (коммиты сегодняшним днём), под MIT, и десктопное приложение к нему тоже открытое — по части «полного опенсорса» к посту вопросов нет.

Вопросы к цифрам: не 232 агента, а **280**, и не 16 областей, а **19** — пост занизил. И он не упомянул главного: 280 агентов означают **13 191 токен, постоянно занятых в контексте** (6,6 % окна на 200k), а на OpenCode больше половины набора вообще молча не зарегистрируется. Ставить стоит один-два дивизиона под конкретную задачу, а не «всё агентство».
