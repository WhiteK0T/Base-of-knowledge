Главное следствие: **разрыв между топами схлопнулся**. Разница между первым и вторым местом — доли процента, и она меньше, чем разница между «хорошим» и «плохим» промптом. Выбирать агента по бенчмарку в 2026 году бессмысленно; выбирать надо по обвязке — инструментам, контексту, песочнице, цене и тому, как он ведёт себя на **твоём** коде.

## 📖 Описание каждого агента

### **Claude Code**
*Разработчик:* Anthropic | *Лицензия:* Проприетарная | *Проверено:* 11.08.2026  
Агент через CLI или IDE: анализирует код, вносит изменения, запускает тесты, итеративно решает задачи. Работает на моделях Claude 5 (**Opus 5**, **Fable 5**, Sonnet 5, Haiku 4.5). В августовских рейтингах занимает первое место — за счёт Opus 5 и возможности назначать **отдельную модель каждому субагенту**. 6 мая 2026 Anthropic вдвое поднял лимиты использования на всех платных планах.  
*Цена:* Pro $20/мес (или $17 при годовой оплате), Max 5x — $100, Max 20x — $200. Отдельной цены на Claude Code нет, бесплатного тарифа для CLI тоже; в Team он входит только в Premium-места ($100/место при годовой оплате, минимум 5 мест).

### **Codex CLI**
*Разработчик:* OpenAI | *Лицензия:* Apache 2.0 | *Проверено:* 11.08.2026  
Официальный CLI от OpenAI на моделях GPT-5.x Codex, держит опубликованный рекорд Terminal-Bench. Есть облачный режим Codex Cloud для фоновых задач. В августовских рейтингах — второе место после Claude Code. ★105k, при этом **12 277 открытых issue** — самый большой поток жалоб среди всех агентов, что говорит и о масштабе аудитории, и о темпе.  
*Цена:* BYOK либо в составе подписки ChatGPT.

### **OpenCode**
*Разработчик:* **Anomaly** (ранее публиковался как SST) | *Лицензия:* MIT | *Проверено:* 11.08.2026  
Самый популярный открытый кодинг-агент: **★196k**, TypeScript, 75+ провайдеров, LSP, полная приватность. Доступен как CLI, десктоп и расширение IDE. Текущая версия — v1.18.16.  
> [!warning] Сменился адрес репозитория
> Команда открыто назвала себя **Anomaly** (имя компании было таким всегда, просто не использовалось публично) и перенесла всё под `anomalyco/`. **Это не поглощение.** Практические последствия: старые ссылки `sst/opencode`, Docker-образы и GitHub Action по старому пути перестают работать — обнови пути в CI.

*Цена:* бесплатно (BYOK).

### **Antigravity** 🆕
*Разработчик:* Google | *Лицензия:* Проприетарная | *Добавлено:* 11.08.2026  
Агентная платформа Google, представленная в версии 2.0 на I/O 2026 и **заменившая собой Gemini CLI**. Четыре поверхности поверх одной агентной обвязки:

- **Antigravity 2.0** — десктоп-приложение с панелью **Agent Teams**: отряды субагентов работают параллельно, каждый в своей песочнице;
- **Antigravity IDE** — исходный продукт (запущен в ноябре 2025 вместе с Gemini 3), продолжает выходить;
- **Antigravity CLI** — переписан на **Go**, для клавиатурной и удалённой работы; перенёс из Gemini CLI Agent Skills, Hooks, Subagents и Extensions (теперь как плагины);
- **Antigravity SDK** — хостинг собственных агентов на своей инфраструктуре.

*Цена:* $0 для частных лиц с метрированной квотой; выше лимиты — по подпискам Google AI: Pro $19.99/мес, Ultra $99.99/мес (~5× квоты Pro), топовый тариф $200/мес (~20×). Программный доступ через SDK — по API-прайсу.

### **Gemini CLI** ⚠️
*Разработчик:* Google | *Лицензия:* Apache 2.0 | *Проверено:* 11.08.2026  
> [!danger] Розничный доступ отключён 18 июня 2026
> Gemini CLI и расширения Gemini Code Assist для IDE **перестали обслуживать запросы** бесплатных пользователей, а также подписчиков Google AI Pro и AI Ultra. Доступ сохранён только организациям с лицензиями **Gemini Code Assist Standard/Enterprise** и интеграциями через Google Cloud, по платным API-ключам.
>
> Куда мигрировать: **Antigravity CLI**. Agent Skills, Hooks, Subagents и Extensions перенесены.

Репозиторий остаётся активным (★106k, коммиты идут), но как розничный инструмент продукт закончился.

### **Grok Build** 🆕
*Разработчик:* xAI | *Лицензия:* Проприетарная | *Добавлено:* 11.08.2026  
Терминальный агент xAI, вышедший в бету **14 мая 2026**. CLI написан на **Rust**, работает на модели `grok-build-0.1`. Отличительные черты: **8 параллельных субагентов**, контекст **2 млн токенов**, план-первый воркфлоу (план на утверждение до первой строки кода) и **Arena Mode** — несколько вариантов решения соревнуются между собой.  
*Цена:* сначала только для SuperGrok Heavy ($299/мес), с 25 мая 2026 — всем подписчикам SuperGrok и X Premium+; была промо-ступень SuperHeavy $99/мес на первые полгода. Через OpenRouter — оплата по токенам.

### **Cursor** ⚠️
*Разработчик:* Anysphere → **SpaceX** | *Лицензия:* Проприетарная | *Проверено:* 11.08.2026  
IDE на базе VS Code со встроенным агентом и лучшим в классе предсказанием следующих правок.  
> [!warning] Крупнейшее поглощение стартапа в истории
> **16 июня 2026** SpaceX согласилась купить Anysphere за **$60 млрд** акциями класса A — раскрыто в форме 8-K через несколько дней после IPO SpaceX. Сделка выросла из опциона, полученного SpaceX в апреле 2026 (либо купить за $60 млрд, либо заплатить $10 млрд за партнёрство). Закрытие ожидается в **третьем квартале 2026**; до этого Cursor работает как прежде.
>
> Контекст: выручка выросла со $100 млн ARR в январе 2025 до примерно $4 млрд ARR к июню 2026, более 60 % компаний из Fortune 500 — клиенты. Что поглощение означает для приватности кода и дальнейшей политики продукта — пока неизвестно; **если код чувствительный, это повод присмотреться к альтернативам заранее**.

*Цена:* от $20/мес.

### **GitHub Copilot**
*Разработчик:* GitHub/Microsoft | *Лицензия:* Проприетарная  
Самый массовый AI pair programmer; помимо автодополнения есть агентный режим и отдельный **Copilot CLI**. По замерам jcode — один из самых тяжёлых по памяти CLI (~158 МБ на дополнительную сессию).  
*Цена:* от $10/мес.

### **Devin Desktop** ⚠️ (бывший Windsurf)
*Разработчик:* Cognition | *Лицензия:* Проприетарная | *Проверено:* 11.08.2026  
> [!warning] Windsurf больше не существует как отдельный продукт
> **2 июня 2026** Windsurf переименован в **Devin Desktop**. Владелец тот же (Cognition купила Windsurf за ~$250 млн, сделка закрыта в мае 2026), обновление приезжает существующим пользователям автоматически.

Собственная IDE с агентом Cascade, встроенным Devin, функцией **Codemaps** и проприетарными моделями **SWE-1.5** (Cognition заявляет 13-кратное превосходство в скорости над Claude Sonnet 4.5) и бесплатной **SWE-1.6**. Смысл собственной модели — не платить «ренту за фронтир-модель» на каждой правке.  
*Цена (июнь 2026):* Free $0, Pro $20/мес, Max $200/мес, Teams от $80/мес плюс $40 за место, Enterprise — по договорённости. Подписчики Pro до 19.03.2026 сохранили $15/мес.

### **Devin**
*Разработчик:* Cognition | *Лицензия:* Проприетарная  
Автономный «AI-инженер»: получает задачу, планирует, пишет код, гоняет тесты и открывает PR в облачной среде с собственным браузером и терминалом. После Devin 2.0 цена упала с $500 до $20/мес.  
*Цена:* от $20/мес.

### **Kiro** 🆕
*Разработчик:* AWS | *Лицензия:* Проприетарная | *Добавлено:* 11.08.2026  
Полноценная IDE вокруг **spec-driven development**: сначала формальная спецификация, затем код под неё. Примитивы — Specs, Hooks, Steering, кастомные субагенты, Powers — аналогов в Amazon Q Developer не имеют. Международный запуск — **7 мая 2026**. Свежие модели (Opus 4.7 и новее) доступны **только здесь**, не в Q Developer.

### **Amazon Q Developer** ⚠️
*Разработчик:* AWS | *Лицензия:* Проприетарная | *Проверено:* 11.08.2026  
> [!danger] Продукт сворачивается

### **Cline**
*Разработчик:* Сообщество | *Лицензия:* Apache 2.0 | *Проверено:* 11.08.2026  
Расширение для VS Code: создаёт и правит файлы, выполняет команды в терминале, управляет браузером, умеет работать полностью автономно. ★66k, активная разработка. После закрытия Roo Code — официально рекомендованный апстрим (`.roorules` → `.clinerules`).  
*Цена:* бесплатно (BYOK).

### **Roo Code** ❌

### **jcode**
*Разработчик:* Solo Systems (1jehuang) | *Лицензия:* MIT | *Добавлено:* 11.08.2026  
Терминальный агент на **Rust** со ставкой на **параллелизм**: девиз проекта — не ждать одного агента, а раздавать задачи десятку.

- **Рои (swarm) с разрешением конфликтов.** Сервер помнит, кто какой файл читал: если агент A правит файл из контекста агента B, **B получает уведомление** и может посмотреть диф. Есть DM между агентами и броадкаст; агент умеет сам породить рой и стать координатором. Это дальше, чем субагенты Kimi или Orchestrator у Kilo Code.
- **Векторная память.** Каждый ход эмбеддится, память хранится графом, поиск — по косинусной близости, извлечением занимается отдельный sideagent. Другой класс решения, чем `MEMORY.md` у MiMo Code.
- **Ресурсы.** ~10,4 МБ на каждую **дополнительную** сессию против ~212,7 МБ у Claude Code и ~318 МБ у OpenCode. Десять сессий: 261 МБ против 2,3 ГБ.
- **Провайдеры.** Claude, OpenAI/Codex, Gemini, Copilot, Azure, Alibaba Coding Plan, Fireworks, MiniMax, профили OpenAI-совместимых (OpenRouter, DeepSeek, Kimi, Z.ai, HuggingFace, Nebius…), **Ollama и LM Studio**.
- **Resume чужих сессий** — codex, claude code, opencode, pi.

> [!warning] Что проверить до установки
> - Рекламные **«245× быстрее Claude Code»** — это время до первого отрисованного кадра. По практической метрике «когда можно печатать» разрыв **72×** (48,7 мс против 3512,8 мс).
> - Рекламные **«28 МБ»** — сборка с **выключенным** локальным эмбеддингом. С включённым (а он и даёт ту самую память) первая сессия занимает **167 МБ**.
> - **Телеметрия включена по умолчанию и не описана в README**; в трекере открыты баги о том, что install-событие уходит до применения `jcode telemetry disable`.
> - Версия **0.75.x**, ~277 открытых issue при релизах по нескольку в день. Ставить лучше фиксированную версию.
>
> Подробный разбор с полными таблицами замеров — в [отдельной заметке](jcode%20%281jehuang%29%20%E2%80%94%20%D1%82%D0%B5%D1%80%D0%BC%D0%B8%D0%BD%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9%20%D0%98%D0%98-%D0%B0%D0%B3%D0%B5%D0%BD%D1%82%20%D0%BA%D0%BE%D0%B4%D0%B0%20%D0%BD%D0%B0%20Rust%20%28%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B0%20%C2%AB%D0%B2%20245%20%D1%80%D0%B0%D0%B7%20%D0%B1%D1%8B%D1%81%D1%82%D1%80%D0%B5%D0%B5%20Claude%20Code%C2%BB%2C%20%D1%80%D0%BE%D0%B8%2C%20%D0%BF%D0%B0%D0%BC%D1%8F%D1%82%D1%8C%2C%20%D1%82%D0%B5%D0%BB%D0%B5%D0%BC%D0%B5%D1%82%D1%80%D0%B8%D1%8F%29.md).

*Цена:* сам агент бесплатен (BYOK, без урезанных функций); у компании есть платный хостинг инференса — $10/мес дают $20 кредита, дальше −10 % от цен API, потолок по умолчанию $100/мес.

| Спецификация до кода (spec-driven) | **Kiro**, Quest 1.0 |
| Самообучение и память между сессиями | Hermes Agent, jcode (векторный граф), MiMo Code (`MEMORY.md`) |
| Полный контроль над каждым шагом | Pi (Pie — только если готов к нишевому проекту) |
| ML-эксперименты без человека | AutoResearch (с оговоркой про застой и отсутствие лицензии) |
| Промышленная автоматизация задач | Forge, Droid, Quest 1.0 |
| Персональный агент-автоматизатор (мессенджеры, computer-use) | OpenClaw |
| Открытая альтернатива Devin (self-hosted) | OpenHands |
| Максимальный результат («стек» из нескольких) | IDE-агент (Cursor/Copilot) + CLI (Claude Code/Codex) + фоновый (Devin/Codex Cloud) |

> [!tip] Практика августа 2026
> **Выбирать по бенчмаркам больше нельзя** — разрыв между лидерами меньше процента. Решают три вещи: обвязка (инструменты, контекст, песочница), цена под твой объём работы и то, как агент ведёт себя на **твоём** коде. Проверяется это одним способом — прогнать два-три кандидата на своей реальной задаче.
>
> Опытные разработчики по-прежнему держат «стек» из 2–3 инструментов: IDE-агент для повседневного, CLI во втором терминале для тяжёлого рефакторинга, фоновый для задач «сделай и покажи PR».

> [!caution] Два тренда, которые стоит держать в голове
> 1. **Консолидация.** За два месяца: Cursor куплен SpaceX, Windsurf стал Devin Desktop, Gemini CLI закрыт в пользу Antigravity, Amazon Q свернулся в пользу Kiro, Roo Code заархивирован. Инструмент, выбранный сегодня, вполне может через полгода принадлежать другой компании или называться иначе. Закладывай стоимость миграции.
> 2. **Открытые проекты живут по-другому.** Они не исчезают, а **застывают**: Aider — без коммитов с мая, AutoResearch — с марта, Devika — с сентября 2025. Смотреть надо не на звёзды, а на дату последнего коммита и на то, влиты ли PR.
