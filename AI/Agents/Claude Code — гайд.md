# Claude Code — гайд

**Claude Code** — агентный инструмент для программирования от Anthropic, работающий в терминале (а также в IDE и десктоп-приложении). Он сам читает и редактирует код, запускает команды и тесты, разбивает задачи на шаги и итеративно их решает поверх моделей Claude.

> [!note] Актуальность
> Сверено с документацией code.claude.com (зеркало claude-code-docs) **2026-10-12**. У многих команд в доках указана минимальная версия Claude Code: если команды нет, обновитесь (`claude update`) и проверьте `/release-notes`.

## 🚀 Базовый цикл работы

Команды полезны в конкретных точках сессии — от настройки проекта до отправки изменений:

- **Первая сессия в репозитории.** `/init` создаёт стартовый `CLAUDE.md` (если найдёт конфиги Codex или Gemini CLI — предложит их учесть; перенести их целиком можно через `/import`), затем `/memory` дорабатывает его. `/mcp` подключает MCP-серверы, `/permissions` — правила одобрений. Субагентов создают, попросив об этом Claude или положив файл в `.claude/agents/`.
- **Во время задачи.** `/plan` — режим планирования перед крупным изменением. `/model` и `/effort` регулируют, сколько reasoning ты тратишь. Когда диалог разрастается — `/context` показывает, чем занят контекст, а `/compact` сжимает его. `/btw` — быстрый вопрос «в сторону», не засоряющий историю. `/goal <условие>` — Claude продолжает работать ход за ходом, пока условие не выполнено.
- **Параллельная работа.** `/subtask <задача>` — фоновый субагент с копией всего диалога, его результат вернётся сюда; `/fork` — копия диалога в отдельную фоновую сессию; `/tasks` — что крутится в фоне (шеллы и субагенты); `/background` — увести всю сессию в фон (смотреть — `claude agents`); `/batch` — разложить большое изменение на 5–30 независимых юнитов, каждый делает свой фоновый субагент в отдельном git-worktree.
- **Перед отправкой.** `/diff` — что изменилось; `/code-review [low…max]` — ревью диффа, PR, ветки или пути на баги (на высоких уровнях — и на упрощения); `--fix` применяет находки, `--comment` постит их в PR/MR GitHub или GitLab; `/review` — просто псевдоним `/code-review`; `/code-review ultra` — глубокое мульти-агентное облачное ревью. `/security-review` — отдельная проверка диффа ветки против ветки по умолчанию `origin` на инъекции, проблемы авторизации и утечки данных. `/simplify` — четыре параллельных ревьюера ищут, что упростить, и сразу правят.
- **Между сессиями.** `/clear` — начать новую задачу, сохранив память проекта; `/resume` и `/branch` — вернуться к диалогу или ответвить его.
- **Когда что-то не так.** `/rewind` (`/undo`) — откат кода и диалога к контрольной точке; `/doctor` (`/checkup`) — проверка установки, настроек и `CLAUDE.md` с предложением исправлений, `/doctor prompt-audit` — аудит ваших инструкций; `/debug` — включить отладочный лог и разобраться по нему; `/bug` или `/feedback` — отчёт с выбором, сколько истории сессии приложить.

## 🔀 Режимы прав (`Shift+Tab`)

| Режим | Что выполняется без запроса | Для чего |
| :--- | :--- | :--- |
| `default` (в интерфейсе — **Manual**) | Только чтение | Сам одобряешь каждое действие |
| `acceptEdits` | Чтение, правки файлов и простые файловые команды (`mkdir`, `touch`, `mv`, `cp`) | Итерации над кодом, который ты просматриваешь |
| `plan` | Чтение (и одобренные классификатором команды, если доступен auto) | Изучить код и выдать план до изменений |
| `auto` | Всё, но с фоновыми проверками безопасности (классификатор) | Длинные задачи без постоянных запросов |
| `dontAsk` | Чтение в рабочих каталогах и заранее разрешённые инструменты; всё остальное **запрещается** | CI и скрипты |
| `bypassPermissions` | Всё | Только изолированные контейнеры и ВМ |

`Shift+Tab` циклически переключает `default` → `acceptEdits` → `plan`, дальше — опциональные режимы (`auto`, `bypassPermissions`), если они доступны. Если сессия стартовала в `auto`, первое нажатие переводит в `default`. Запустить сразу в нужном режиме: `claude --permission-mode plan`. В plan-режим можно войти и командой `/plan [задача]`; одобрение плана переключает сессию в выбранный режим, и Claude начинает править. Правила `deny` из `/permissions` работают во **всех** режимах, включая `bypassPermissions`.

## 🧠 Контекст, модель и «усилия»

- `/context` — визуализация занятости окна контекста + подсказки по «тяжёлым» инструментам и раздутой памяти.
- `/compact [фокус]` — суммаризация диалога для освобождения контекста.
- `/clear` — полностью чистый старт (предыдущий диалог остаётся в `/resume`).
- `/model [model]` — смена модели и сохранение по умолчанию; стрелками ←/→ регулируется уровень reasoning, `s` на строке — сменить только для текущей сессии.
- `/effort [level]` — уровень усилий: `low` / `medium` / `high` / `xhigh` / `max` или `auto` (вернуть умолчание); `max` действует только на сессию; `/effort status` — показать текущий.
- **Ultracode** — не уровень, а отдельный переключатель: с ним Claude оркеструет динамические workflow для крупных задач на текущем уровне усилий. Включить: `/effort ultracode` (выключить — `/effort ultracode off`, в слайдере `/effort` — `Tab`), настройкой `"ultracode": true` или запуском `claude --effort ultracode` (этот флаг ещё и ставит `xhigh`). Смена уровня ultracode не выключает.
- `/advisor [модель|off]` — второй «модель-советник», с которым Claude сверяется в ключевые моменты задачи.
- `/autocompact [auto|<токены>]` — при каком заполнении окна сжимать диалог автоматически.
- **Кэш промптов**: на подписке основной диалог кэшируется на час, а субагенты — на 5 минут; продлить для них — `"subagentPromptCacheTtl": "1h"`. Что сбрасывает кэш и когда час выгоднее — в [отдельной заметке](Claude%20Code%20%E2%80%94%20%D0%BA%D1%8D%D1%88%20%D0%BF%D1%80%D0%BE%D0%BC%D0%BF%D1%82%D0%BE%D0%B2%20%28TTL%205%20%D0%BC%D0%B8%D0%BD%D1%83%D1%82%20%D0%B8%201%20%D1%87%D0%B0%D1%81%2C%20subagentPromptCacheTtl%2C%20%D1%87%D1%82%D0%BE%20%D1%81%D0%B1%D1%80%D0%B0%D1%81%D1%8B%D0%B2%D0%B0%D0%B5%D1%82%20%D0%BA%D1%8D%D1%88%29.md).

## 📝 Память: `CLAUDE.md`

- `/init` — создать `CLAUDE.md` (инструкции и факты о проекте, которые подхватываются каждой сессией). Поддерживается и `AGENTS.md`.
- `/memory` — редактировать файлы памяти, включать/выключать и смотреть **auto memory** — заметки, которые Claude сам пишет по вашим поправкам и предпочтениям.
- `CLAUDE.md` хранит **факты** о проекте; повторяющиеся **процедуры** лучше выносить в skills (см. ниже), т.к. их тело грузится только при вызове.

## 🧩 Skills и кастомные команды

- Кастомные команды объединены со **skills**: файл `.claude/commands/deploy.md` и skill `.claude/skills/deploy/SKILL.md` оба дают `/deploy`.
- Skill — это `SKILL.md` с инструкциями; Claude вызывает его сам по релевантности или ты явно через `/имя`.
- `/skills` — список доступных skills (`t` — сортировка по цене в токенах, `Space`/`Enter` — скрыть skill от Claude и меню); `/reload-skills` — пере-сканировать без перезапуска; `/skill-doctor` — сколько каждый skill стоит в контексте и как часто используется.
- Совместимы с открытым стандартом [Agent Skills](https://agentskills.io).

## 🔌 MCP, субагенты, чекпоинты

- **MCP** (`/mcp`) — подключение внешних серверов инструментов и OAuth; `/mcp reconnect <server>|all` — переподключить без меню. MCP-серверы могут отдавать промпты-команды: в меню `/` они видны как `/server:prompt (MCP)`, запустить можно и как `/mcp__server__prompt`. Подробнее — [MCP — серверы Model Context Protocol](Tooling/MCP%20%E2%80%94%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D1%8B%20Model%20Context%20Protocol.md).
- **Субагенты** — делегирование побочных задач агентам со своим контекстом и инструментами (антипод `/btw`, который видит весь диалог, но без инструментов). Создаются просьбой к Claude или файлами в `.claude/agents/` / `~/.claude/agents/`. Команда `/agents` в новых версиях лишь напоминает об этом (интерактивный менеджер был до v2.1.197).
- **Checkpointing** (`/rewind`, двойной `Esc` на пустой строке) — откат кода/диалога к прошлой точке.

## 🐚 Shell-режим и горячие клавиши

- Префикс `!` — выполнить shell-команду напрямую, добавив вывод в контекст: `! npm test`. Выход — `Esc` / `Backspace` / `Ctrl+U` на пустой строке.
- `Ctrl+B` уводит в фон запущенные bash-команды и агентов (в tmux — нажать дважды); вывод пишется в файл, Claude читает его при необходимости.
- Многострочный ввод: `\`+`Enter` или `Ctrl+J` (работают везде), `Shift+Enter` (из коробки в iTerm2, WezTerm, Ghostty, Kitty, Warp, Windows Terminal; для VS Code, Alacritty, Zed — после `/terminal-setup`).
- Прочее: `Ctrl+O` — транскрипт, `Ctrl+R` — поиск истории, `Ctrl+T` — чек-лист задач Claude (фоновые задачи — это `/tasks`), `Ctrl+S` — отложить введённый промпт и вернуть его позже, `Ctrl+G` — редактировать промпт во внешнем редакторе, `@` — упоминание файла, `Alt/Option+P` — модель, `Alt/Option+T` — расширенное мышление (на моделях с постоянным мышлением, например Opus 5.5 и Sonnet 5.5, не действует), `Alt/Option+O` — fast mode.

## 💡 Полезные мелочи

- `/btw <вопрос>` — эфемерный вопрос «в сторону» (не попадает в историю, без доступа к инструментам).
- `/recap` — однострочное резюме сессии; авто-recap появляется после паузы.
- `/usage` (`/cost`, `/stats`) — стоимость и лимиты; на платных планах — разбивка по skills/субагентам/MCP.
- `/team-onboarding` — гайд для коллеги из истории твоих сессий за 30 дней.
- `/insights` — HTML-отчёт по последним сессиям: проекты, приёмы работы, где что идёт не так, что стоит попробовать.
- `/loop [интервал] [промпт]` — повторять промпт, пока открыта сессия (без интервала Claude сам выбирает паузу).
- `/cd <путь>` — перенести сессию в другой каталог, сохранив диалог (в отличие от `/add-dir`, который лишь даёт доступ к файлам).
- `/focus` — режим, где видны только последний промпт, сводка вызовов инструментов и ответ (в полноэкранном интерфейсе, `/tui fullscreen`).
- `/release-notes` — что нового в версиях.

## 📚 Офлайн-зеркало документации (claude-code-docs)

Если нужно искать по докам офлайн или дать самому Claude Code локальную базу знаний о себе — есть сторонний репозиторий **[thevibeworks/claude-code-docs](https://github.com/thevibeworks/claude-code-docs)** (MIT): авто-обновляемое (4 раза в день через GitHub Actions) зеркало markdown-документации Anthropic — ~4100 файлов из 6+ источников (Claude Code и Agent SDK, API-референс, MCP-спека, официальные skills и плагины, cookbooks, support). Клонируешь и натравливаешь агента:

```bash
git clone https://github.com/thevibeworks/claude-code-docs
cd claude-code-docs
claude "how do I set up hooks in the Agent SDK?"
```

- Обновить вручную: `uv run scripts/fetcher.py` (нужен [uv](https://docs.astral.sh/uv/); для GitHub-источников — `GITHUB_TOKEN`). Ничего не конвертируется из HTML: источники сами отдают `.md`-вариант каждой страницы.
- Есть и **MCP-сервер** (`mcp/`) с инструментом `search_docs` — ставит доки в `~/.claude/claude-code-docs/` и ищет по ним прямо из агента.
- ⚠️ «Вся документация» — с оговоркой: сами доки (Claude Code, API, MCP, skills, cookbooks) полные, а блог Anthropic заморожен на 2026-07-08, research собран на ~46%, news на ~22% (anthropic.com отдаёт только HTML, markdown-варианта нет). Для справочного поиска по продуктовым докам — полноценно; как архив инженерного блога — частично.
