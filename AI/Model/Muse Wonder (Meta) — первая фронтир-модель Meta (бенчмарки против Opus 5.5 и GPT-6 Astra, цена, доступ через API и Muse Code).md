# 🎨 Muse Wonder (Meta) — первая фронтир-модель Meta

**12 октября 2026** Meta Superintelligence Labs выпустила две модели: **Muse Wonder** и более сильную **Muse Wonder Full**. Это первая модель Meta уровня флагманов Anthropic, OpenAI и Google, после того как в августе 2025 Александр Ванг перестроил ИИ-подразделение компании. До этого у Meta была быстрая и дешёвая **Muse Spark** и агент **Muse**. Обучали Wonder в новом дата-центре Prometheus в Огайо.

Сильные стороны — **кодинг, длинные агентские задачи и «активная память»** (модель удерживает и сводит воедино то, что ей сообщил пользователь). По независимому сводному индексу Wonder Full входит в верхнюю группу, но не обходит лидеров по всем статьям (раздел 2).

---

## 1. Две модели и как их получить

| | **Muse Wonder** | **Muse Wonder Full** |
| :--- | :--- | :--- |
| Доступ | **Meta Model API** (`muse-wonder-1.0`), Muse Code, агент Muse (сначала платные подписчики) | **Только Muse Code** по подписке; в API нет |
| Цена | **$4** за 1 млн входных токенов, **$20** за 1 млн выходных, кэш входа $0,20; веб-поиск через API — $2,50 за 1000 запросов | Подписка Muse Code: **$50/мес** (Power, ×20 к базовому лимиту) или **$200/мес** (Maximum, ×80) |
| Контекст | ~1 млн токенов | ~1 млн токенов |
| Вход / выход | текст, изображения, аудио, видео → текст | то же |
| Открытые веса | нет | нет |

**Агент Muse** для обычных пользователей Meta запустила 8 сентября 2026 (сайт **[muse.ai](https://muse.ai/)**, приложения iOS и Android). Он сам отправляет письма, бронирует поездки, заполняет формы и делает покупки, работает в изолированной среде Muse Secure VM, а система Sentinel проверяет действия перед выходом в интернет и спрашивает подтверждение на чувствительных шагах. Пока **только США и только 18+**; бесплатно 100 млн токенов в неделю, платно — Power $20/мес и Maximum $100/мес, для регистрации нужна карта. Сначала агент работал на Muse Spark, теперь на него приходит Wonder. Ссылка в исходном посте ведёт на muse.ai с партнёрскими параметрами (`?pt=…`); чистый адрес — `https://muse.ai/`.

Не путайте тарифы: **агент Muse** ($20 / $100) и **Muse Code** для разработчиков ($50 / $200, именно там доступен Wonder Full).

> [!warning] Что важно знать про данные
> - Подписка **Muse Code по умолчанию в режиме Contributor**: Meta может использовать отправленное содержимое для обучения моделей, а правила прямо запрещают отправлять в этом режиме конфиденциальные и личные данные. Для рабочего кода проверьте настройки и переключите режим.
> - Режим **zero data retention** в API несовместим с серверным хранением диалога, фоновыми запросами, загрузкой файлов и встроенным веб-поиском, то есть как раз с частью «памяти» и длинных агентских сценариев.
> - Сама Meta советует подтверждать человеком важные действия агента: на незнакомых многошаговых задачах модель ещё ошибается.

> [!note] Россия
> Meta с 2022 года признана в РФ экстремистской организацией, её сервисы официально в России не продаются. Подписку и API через российские карты не оплатить; доступ, как и к другим западным ИИ-сервисам, возможен только из других юрисдикций.

## 2. Бенчмарки

### Независимый сводный индекс (Artificial Analysis Intelligence Index v4.3)

| Модель | Индекс | Стоимость прогона индекса |
| :--- | ---: | ---: |
| **Claude Opus 5.5** | **58** | $5,98 |
| **Muse Wonder Full** | 56 | — (по токенам не продаётся) |
| GPT-6 Astra | 53 | $3,26 |
| Claude Fable 5.1 | 53 | $7,63 |
| **Muse Wonder** | 52 | $4,52 |
| Muse Spark 1.3 (предшественник) | 48 | $1,60 |

### По задачам (Meta и Artificial Analysis, сведено VentureBeat)

| Бенчмарк | Wonder Full | Wonder | GPT-6 Astra | Opus 5.5 |
| :--- | ---: | ---: | ---: | ---: |
| DeepSWE 1.1 (разработка) | **79,0** | 78,8 | 74,1 | 74,2 |
| SWE-Marathon (длинные задачи) | **57,5** | 53,1 | 42,5 | 46,3 |
| AutomationBench-AA (агентская автоматизация) | **45,4** | 39,1 | 41,6 | 41,2 |
| JobBench | 75,3 | 70,5 | 66,1 | **75,4** |
| Terminal-Bench 4.0-AA | 57,1 | 52,0 | 59,1 | **59,6** |
| HealthBench Pro | 62,3 | 60,5 | 65,3 | **65,6** |
| Harvey LAB-AA (юридические задачи) | **13,1** | 10,0 | 8,6 | 4,2 |

Ещё по Artificial Analysis:
- **Coding Agents Index**: Wonder Full — 68 (на уровне Claude Code с Sonnet 5.5), Wonder — 63;
- **Terminal-Bench** у Wonder Full вырос с 33% у предшественника до 57%, и при этом модель тратит на 30% меньше выходных токенов;
- **фактические знания** (AA-Omniscience) — слабое место: Wonder Full 30, Wonder 25 против 46 у Opus 5.5, 43 у Astra и 42 у Gemini 4 Argon. Доля галлюцинаций у Wonder Full при этом снизилась с 33% до 23%;
- **MemoryBench**: по данным Meta, Wonder обходит Fable, Opus и Astra, но поклассовых цифр Meta не опубликовала.

**Итог по качеству.** Wonder Full — уровень лидеров и лучший в своём классе на длинных задачах разработки (SWE-Marathon, DeepSWE) и агентской автоматизации. По сводному индексу впереди остаётся Claude Opus 5.5, а в терминальных задачах и медицине Wonder Full уступает и Opus 5.5, и GPT-6 Astra. Заметьте, что в сравнении Meta смешаны собственные, вендорские и независимые замеры, а часть кодинговых тестов прогоняли с разными инструментами.

### Про цену

- **За токен** Wonder стоит **в 2,5 раза дешевле GPT-6 Astra** ($4/$20 против $10/$50) и **столько же, сколько Claude Opus 5.5** ($4/$20).
- **За задачу** картина другая: Wonder тратит на 28% больше входных токенов, и средний прогон индекса Artificial Analysis обходится в **$4,52** против **$3,26** у Astra и **$5,98** у Opus 5.5. Сравнивать цену моделей честнее по стоимости решённой задачи, а не по прайсу за токен.

## 3. Когда стоит попробовать

| Задача | Вывод |
| :--- | :--- |
| Длинные задачи разработки, многочасовые агентские прогоны | Стоит сравнить с текущим агентом: здесь Wonder Full — среди лучших |
| Агентская автоматизация через API | Wonder по цене Opus 5.5 за токен, но с лишним расходом входных токенов — считайте стоимость задачи |
| Вопросы на знание фактов, справки | Слабее Opus 5.5 и Astra — проверяйте ответы |
| Конфиденциальный код и данные | Только после отключения режима Contributor; помните про ограничения zero data retention |
| Самостоятельный хостинг | Невозможен: весов нет |
