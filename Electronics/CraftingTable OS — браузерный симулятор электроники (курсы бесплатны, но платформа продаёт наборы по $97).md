# 🔌 CraftingTable OS — браузерный симулятор электроники с курсами

Разбор [поста «Не баг, а фича» от 19.08.2026](https://t.me/bugnotfeature/27177). Симулятор действительно существует и работает в браузере, курсы бесплатны — тут пост прав. Но он умалчивает, что платформа выстроена **вокруг продажи физических наборов**, а её собственное описание прямо говорит «с наборами для сборки».

Проверено 09.09.2026: разобрал SPA-бандл, вытащил маршруты и открытый API курсов, сверился с магазином.

> [!info] Факты
> | | |
> | :--- | :--- |
> | Название | **CraftingTable OS**, адрес [computer.craftingtable.com](https://computer.craftingtable.com/) |
> | Магазин | [craftingtable.com](https://craftingtable.com/) — Shopify, продажа наборов |
> | Курсов | **6**, у всех `isFree: true` |
> | Цена набора | **$97** за Adventure Kit «30 Days Lost in Space» |
> | Аудитория по описанию | *«Perfect for kids, students, and beginners»* |

## ✅ Проверка утверждений поста

| Утверждение | Вердикт | Что на самом деле |
| :--- | :---: | :--- |
| «Симулятор прямо в браузере» | ✅ Верно | В бандле есть `SimulatorContext` на 124 КБ, `breadboardGeometry` и `ArduinoCompilationService` |
| «**БЕЗ железа**» | ⚠️ Ровно наоборот по замыслу | Собственное описание платформы: *«Build real circuits through story-driven courses **with hands-on kits**»*. Все шесть курсов названы по наборам, два прямо требуют `requiredKitId` |
| «Обучающие курсы» | ✅ Верно и бесплатны | 6 курсов, у всех в API `isFree: true`, от 12 до 60 часов |
| «От мигающего светодиода до починки пульта» | ⚠️ Сюжет другой | Сценарии: ремонт разбитого корабля, пост-апокалипсис, Python на Raspberry Pi Pico. «Пульта управления» в курсах нет |
| «Каждый день новая бесплатная задачка» | ⚠️ Не проверил | Маршруты `/daily-quest`, `/daily-quests`, `/daily-quest/archive` в SPA есть, но API отдаёт их только авторизованным — ежедневность подтвердить не смог |
| «Рай для техногиков» | ❌ Аудитория другая | Платформа сама позиционируется для **детей и новичков**, у курсов есть поле `ageRating` |
| Полностью бесплатно | ⚠️ Курсы да, наборы нет | Наборы продаются отдельно через Shopify, цена от **$97** |

## 🧪 Что действительно работает без железа

Симулятор настоящий, это не заглушка. Разобрал чанки бандла:

| Чанк | Размер | Что внутри |
| :--- | ---: | :--- |
| `SimulatorContext` | 124 КБ | ядро симуляции |
| `ArduinoCompilationService` | 2,8 КБ | компиляция скетчей |
| `breadboardGeometry` | 1,4 КБ | геометрия макетной платы |

Компоненты, которые нашлись в коде симулятора: **светодиод, резистор, потенциометр, фоторезистор, зуммер, серво, реле, OLED-дисплей** и плата **Arduino Uno**. Для базового курса «помигать светодиодом и снять показания с датчика» этого хватает.

У всех шести курсов включён **AI-тьютор** (`aiTutorEnabled: true`) — с настраиваемым характером, лимитом вопросов в день и уровнем подсказок.

## 💰 Как устроена монетизация

Открытый эндпоинт `/api/courses` отдаёт полную структуру, и в ней видно бизнес-модель:

| Курс | Часов | Квестов | Требует набор | Сложность |
| :--- | ---: | ---: | :--- | :--- |
| HERO Starter Kit: Cogsworth City | 15 | 20 | — | новичок |
| 30 Days Lost in Space | 30 | 31 | — | новичок |
| Adventure Kit: Pandora's Box | 60 | 50 | — | продвинутый |
| SensorKit (37 деталей) | — | — | — | новичок |
| Python Starter Kit: Neon Realm | 12 | 9 | **advk4** | новичок |
| Advanced Python Kit: Nebula Raiders | 30 | 25 | **advk3** | средний |

Все записи содержат поля `shopifyProductId` и `shopifyProductUrl`, ведущие в магазин. Проверил цену по ссылке из API — **$97,00** за набор «30 Days Lost in Space».

> [!important] Курсы бесплатны, но они — витрина
> Формально всё честно: `isFree: true` у всех шести, регистрация бесплатна, симулятор работает. Но каждый курс назван по набору, два курса на Raspberry Pi Pico прямо привязаны к `requiredKitId`, а в маршрутах SPA есть `/best-arduino-kit`, `/crate`, `/advertorial` и админский раздел с воронками.
>
> Это нормальная модель «бесплатный софт продаёт железо», но подавать её как «изучаем электронику БЕЗ железа» — значит показывать половину картины.

## 🧭 Если нужен именно симулятор без покупок

Для чистой browser-симуляции есть зрелые бесплатные варианты — проверил, все открываются:

| Инструмент | Чем хорош |
| :--- | :--- |
| [Wokwi](https://wokwi.com) | Arduino, ESP32, Raspberry Pi Pico, симуляция Wi-Fi и логического анализатора; бесплатный уровень щедрый |
| [Falstad Circuit Simulator](https://www.falstad.com/circuit/) | классика для аналоговых схем, наглядная анимация тока, полностью бесплатен |
| [Tinkercad Circuits](https://www.tinkercad.com/circuits) | Autodesk, Arduino с блочным и текстовым кодом, популярен в школах |
| [EveryCircuit](https://everycircuit.com) | наглядная динамика напряжений и токов |

Для микроконтроллеров, которые тебе ближе, полезнее всего **Wokwi** — он умеет ESP32 и Pico, а не только Uno. Про сам выбор платы — в заметке [ESP32 — обзор и выбор варианта](ESP32%20%E2%80%94%20%D0%BE%D0%B1%D0%B7%D0%BE%D1%80%20%D0%B8%20%D0%B2%D1%8B%D0%B1%D0%BE%D1%80%20%D0%B2%D0%B0%D1%80%D0%B8%D0%B0%D0%BD%D1%82%D0%B0%20%282026%29.md).

## 💻 Требования

Работает в любом современном браузере, ставить нечего. Регистрация нужна для прогресса и ежедневных квестов; есть `/parental-consent` — платформа рассчитана в том числе на детей и собирает согласие родителей.

Для роутера с Entware неприменимо — это веб-сервис.

## 💡 Итог

- **Симулятор реальный**, курсы бесплатны, AI-тьютор есть — в этой части пост не преувеличивает.
- Но «БЕЗ железа» противоречит замыслу платформы: она сама себя описывает как обучение **с наборами**, все курсы названы по наборам, а два без набора не пройти.
- Экономика простая: курсы бесплатны, наборы стоят **от $97**.
- Аудитория — **дети и новички**, а не «техногики». Для человека, уже знакомого с ESP32 и паяльником, содержание будет слишком базовым.
- Если нужен именно симулятор — **Wokwi** покрывает больше плат и ничего не продаёт.
