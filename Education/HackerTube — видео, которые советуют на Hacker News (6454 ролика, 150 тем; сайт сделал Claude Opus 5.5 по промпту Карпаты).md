# 📺 HackerTube — видео, которые советуют на Hacker News

[**HackerTube**](https://hackertube.org/) — каталог роликов YouTube, на которые пользователи Hacker News раз за разом ссылаются в комментариях. Лекции, доклады, курсы, документалки, разборы — с темами, цитатами из комментариев и поиском, без рекомендательной ленты YouTube. Заметка по посту [«Не баг, а фича»](https://t.me/bugnotfeature/28767) от 1 ноября 2026 года, сверена с сайтом и его открытыми данными.

| | |
| :--- | :--- |
| Объём | **6 454 видео** и 39 834 комментария HN со ссылками на них, 2007–2026 годы (выгрузка от 31.10.2026) |
| Темы | **150 категорий в 16 разделах**; у каждого видео 1–3 категории |
| Кто сделал | Claude Opus 5.5 в Claude Code — по промпту Андрея Карпаты (раздел 2) |
| Аккаунты | не нужны: лайки, история и «Смотреть позже» хранятся в браузере, видео идут через встраивание YouTube в режиме повышенной конфиденциальности |
| Данные | открыты: можно скачать, лицензия ODC-By 1.0 |
| Статус | независимый проект, не связан с YouTube, Google, Hacker News и Y Combinator |

## 1. Как отбирались видео

1. Весь архив комментариев HN 2007–2026 годов (открытый набор [open-index/hacker-news](https://huggingface.co/datasets/open-index/hacker-news)) просканирован на ссылки YouTube. Ссылка засчитывается, только если в комментарии хотя бы 100 символов собственного текста. Всего нашлось больше ста тысяч разных видео.
2. В каталог попадает видео, которое упомянули **минимум три разных человека в трёх разных месяцах**. Разовые ссылки отсеиваются, остаётся около 6,5 тыс. роликов. На видео хранится до 20 упоминаний — предпочтение разным авторам.
3. Claude Sonnet 5.5 прочитал каждое упоминание вместе с заголовком обсуждения и определил, что делает комментатор: **советует** видео, ссылается на него как на источник, шутит или критикует. Плюс темы, короткое «почему» и дословная цитата.
4. Для каждого видео Sonnet 5.5 написал карточку:
   - краткое содержание;
   - почему его любят на HN;
   - тип: доклад, лекция, курс, документалка, интервью и т. д.;
   - уровень и «срок годности».
5. Рейтинг — число месяцев, в которые видео советовали, плюс половина месяцев с сильными рекомендациями.

Сами авторы предупреждают, что разметка LLM хорошая, но не идеальная: несколько процентов позиций или описаний могут быть неточными.

## 2. Что за словами поста

- **«Карпаты запилил свой YouTube».** На странице About прямо сказано, что HackerTube построила Claude Opus 5.5 в Claude Code: конвейер данных, поиск, рекомендации и сам сайт. Карпаты задал задачу промптом. Подписи к комментариям, карточки видео и список тем писали команды агентов Claude Sonnet 5.5 под управлением Opus.
- **«С помощью Opus 5.5 за пару часов».** Модель подтверждается, срок на сайте не указан.
- **«6 454 видео по 150 темам»** — да, это цифры выгрузки от 31 октября.
- **«Всё, что юзеры HN советовали за 19 лет».** Период 2007–2026 верный. Но в каталог попадают видео, которые обсуждали неоднократно, а не только советовали: сами данные описаны как «recommended (or at least discussed)». Позиция каждого комментария видна в карточке.
- **«Кликбейта ноль: вместо обложек — кадры из середины роликов»** — да. По умолчанию включена настройка «Video frames»: показывается кадр, который YouTube сам берёт из середины видео (`hq2.jpg`), а не обложка автора. Если кадра нет — обычная обложка. Заголовки при этом остаются авторскими.

## 3. Что есть на сайте

- Просмотр по категориям, поиск, похожие видео (по тому, кто их советует) и «жемчужины».
- Фильтр длинных роликов, сортировка по свежести.
- Подборки-плейлисты, где видео идут в продуманном порядке.
- У каждого видео — что о нём на самом деле писали на HN, со ссылками на исходные комментарии.
- Лайки, история и «Смотреть позже» — локально, в браузере.

## 4. Открытые данные

На странице [Data](https://hackertube.org/data) — архив на 17,8 МБ:

| Файл | Что внутри |
| :--- | :--- |
| `videos.jsonl` | видео с карточками, категориями и статистикой HN, лучшие первыми |
| `mentions.jsonl` | размеченные комментарии HN: позиция, цитата, темы |
| `taxonomy.json` | дерево тем: 16 разделов, 150 категорий |
| `related.jsonl` | граф видео с общими рекомендателями |
| `embeddings.npy`, `embedding_ids.json` | эмбеддинги для смыслового поиска |
| `DATA.md` | описание набора, в том числе раздел «For AI agents: start here» |

- Лицензия — **ODC-By 1.0**, как у исходного архива HN: использовать можно для чего угодно, указывая HackerTube и архив HN.
- **Метаданных YouTube** (описания, просмотры, длительность) в выгрузке нет: правила YouTube API запрещают их распространять. В каждой записи есть id видео, а `DATA.md` объясняет, как бесплатно получить свой ключ YouTube Data API и дозапросить их.
- Набор удобен, чтобы собрать свою рассылку, рекомендательную систему или подборку по теме.
