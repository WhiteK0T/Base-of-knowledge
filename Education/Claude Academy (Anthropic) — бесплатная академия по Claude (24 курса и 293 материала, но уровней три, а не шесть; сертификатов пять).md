# 🎓 Claude Academy — бесплатная академия Anthropic

Разбор [поста «Не баг, а фича» от 21.08.2026](https://t.me/bugnotfeature/27204). Академия настоящая и официальная, два главных числа поста подтвердились. Но структуру он описал неверно: уровней **три**, а не шесть, а курсов с сертификатом **пять**, а не «пара».

Проверено 09.09.2026: разобрал каталог и метаданные из JS-бандла сайта.

> [!info] Факты
> | | |
> | :--- | :--- |
> | Адрес | [academy.claude.com](https://academy.claude.com/) |
> | Владелец | **Anthropic PBC** — на страницах копирайт и описание *«Free AI education from Anthropic»* |
> | Всего материалов | **293** (курсы + туториалы + сценарии использования) |
> | Курсов | **24** в предзагруженном каталоге, **27** по путям в бандле |
> | Суммарно по карточкам | **394 урока**, **43 квиза**, ориентировочно **~74 часа** |
> | Цена | бесплатно |

## 📊 Что внутри на самом деле

Каталог делится на три типа материалов: **Courses**, **Tutorials**, **Use cases** — всего 293 записи. Курсы — меньшая, но самая содержательная часть.

Крупнейший курс — **«Building with the Claude API»**: 67 уроков, 8 квизов, около 9 часов. Именно он закрывает почти весь список из поста: промптинг, работа с инструментами, RAG, агенты, MCP и продакшен-паттерны. То есть это **не шесть отдельных треков**, а один большой курс плюс несколько специализированных.

Отдельные курсы по продуктам:

| Курс | Объём |
| :--- | :--- |
| Building with the Claude API | 67 уроков · 8 квизов · 9 ч |
| AI Fluency: Framework & Foundations | 14 уроков · 1 квиз · 4 ч |
| Claude 101 | 13 уроков · 1 квиз · 2,5 ч |
| AI Capabilities and Limitations | 13 уроков · 1 квиз · 3,5 ч |
| Claude Code 101 | 12 уроков · 1 квиз · 1,5 ч |
| Claude Code in Action | 9 уроков · 1 квиз · 1 ч |

Заметная часть каталога — не про разработку, а про «AI Fluency» под конкретные аудитории: для преподавателей, для студентов, для школьных учителей (в партнёрстве с Teach For America), для НКО, для малого бизнеса, для творческих профессий. Все они построены вокруг одной рамки **4D — Delegation, Description, Discernment, Diligence**.

## 🔢 Три уровня, а не шесть

Пост обещает «6 уровней подготовки — от новичка до проф. разраба». В метаданных курсов есть поле `level`, и значений у него ровно три:

```
level: "beginner" | "intermediate" | "advanced"
```

Никакой шестиуровневой лестницы в данных сайта нет. Есть другие оси классификации, но и они не дают шести:

| Поле | Значения |
| :--- | :--- |
| `level` | beginner, intermediate, advanced — **3** |
| `products` | api, chat, code, cowork — **4** |
| `roleTier` | end_user, admin — **2** |
| `audience` | enterprise, consumer — **2** |

Похоже, число просто придумано либо получено перемножением каких-то из этих осей.

## 📜 Сертификаты: пять курсов

Пост говорит «пара курсов». Уроки с названием `certificate-of-completion` нашлись в **пяти**:

- AI Fluency: Framework & Foundations
- Claude 101
- AI Fluency for educators
- AI Fluency for students
- Teaching AI Fluency

> [!note] Чего стоит такой сертификат
> Это сертификат о прохождении бесплатного онлайн-курса, а не аккредитованная квалификация. В резюме он работает как строчка «прошёл официальный курс Anthropic» — не более, но и не менее. Про то, как вообще читать такие сертификаты, есть отдельная заметка: [awesome-certificates](awesome-certificates%20%28PanXProject%29%20%E2%80%94%20%D0%BA%D0%B0%D1%82%D0%B0%D0%BB%D0%BE%D0%B3%20200%2B%20%D0%B1%D0%B5%D1%81%D0%BF%D0%BB%D0%B0%D1%82%D0%BD%D1%8B%D1%85%20%D0%BA%D1%83%D1%80%D1%81%D0%BE%D0%B2%20%D1%81%20%D1%81%D0%B5%D1%80%D1%82%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%82%D0%B0%D0%BC%D0%B8%20%28IT-CS-%D0%B4%D0%B8%D0%B7%D0%B0%D0%B9%D0%BD-%D0%B1%D0%B8%D0%B7%D0%BD%D0%B5%D1%81%29%2C%20%D1%87%D1%82%D0%BE%20%D1%8D%D1%82%D0%BE%20%D0%B8%20%D0%BD%D1%8E%D0%B0%D0%BD%D1%81%D1%8B.md).

## 🎯 Что брать под свои задачи

Ты уже плотно работаешь с Claude Code, поэтому вводные курсы смысла не имеют. Полезное:

- **Building with the Claude API** — если понадобится строить что-то поверх API: инструменты, RAG, агенты, MCP, продакшен-паттерны в одном месте. Самый содержательный материал академии.
- **Claude Code in Action** — про длинные автономные сессии: как рулить, настраивать, автоматизировать и проверять результат. Короткий, час.
- **Model Context Protocol: Advanced Topics** — нашёлся в бандле отдельным курсом, дополняет заметку про [MCP](../AI/Agents/Tooling/MCP%20%E2%80%94%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D1%8B%20Model%20Context%20Protocol.md).
- **AI Capabilities and Limitations** — про то, чего модели не умеют: предсказание следующего токена, рабочая память, границы контекста. Полезно, чтобы трезвее читать посты вроде разбираемого.

Материал на английском, локализации не заметил. Регистрация, судя по всему, нужна для отслеживания прогресса и сертификатов.

## 💡 Итог

- Академия **настоящая, официальная и бесплатная**, объём приличный: 24 курса, 293 материала, около 74 часов.
- Два ключевых числа поста — «больше 20 курсов» и «сотни материалов» — **подтвердились**.
- **«6 уровней» — выдумка**: в данных сайта ровно три (beginner / intermediate / advanced).
- Сертификатов **пять**, а не «пара» — тут пост, наоборот, занизил.
- «Треки по MCP, RAG и агентам» — это темы внутри одного курса по API, а не отдельные направления.
- Значительная доля каталога — про «AI Fluency» для преподавателей, студентов и бизнеса, а не про разработку. Для разработчика реально интересны три-четыре курса.
