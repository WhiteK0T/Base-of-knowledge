# 🛡️ awesome-security (sbilly) — каталог security-инструментов по категориям

**awesome-security** ([github.com/sbilly/awesome-security](https://github.com/sbilly/awesome-security), **MIT**, ~15k★, с 2014) — курируемый список **инструментов и ресурсов по безопасности**, разбитый по категориям. В отличие от [Awesome-Hacking](Awesome-Hacking%20%28Hack%20with%20GitHub%29%20%E2%80%94%20%D0%BC%D0%B5%D1%82%D0%B0-%D0%BA%D0%BE%D0%BB%D0%BB%D0%B5%D0%BA%D1%86%D0%B8%D1%8F%20awesome-%D1%81%D0%BF%D0%B8%D1%81%D0%BA%D0%BE%D0%B2%20%D0%BF%D0%BE%20%D1%85%D0%B0%D0%BA%D0%B8%D0%BD%D0%B3%D1%83%20%D0%B8%20%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D0%BE%D1%81%D1%82%D0%B8.md) (список списков), здесь **сразу сами инструменты** с короткими описаниями.

---

## 📂 Категории

Network, Endpoint, Threat Intelligence, Honeypot, Network/Host monitoring (IDS/IPS), Forensics, Anti-virus / malware, Docker/контейнеры, Vulnerability scanners, Web, Security web-sites/feeds, книги/курсы и др. Удобно, когда известна **область задачи** («чем мониторить сеть», «сканеры уязвимостей») — открыл раздел и выбрал.

> [!note] Авторитетный, но обновляется неспешно
> Репозиторий заслуженный (с 2014, ~15k★), но правки нечастые — **часть записей датирована**, встречаются мёртвые/заброшенные проекты. Перед выбором инструмента сверять его актуальность по звёздам и дате последнего коммита. Для самых свежих тулзов дополнять более живыми источниками.

---

## 🖥️ На системах владельца

Контент — читать на GitHub или `git clone`. Инструменты из списка ставятся каждый своими средствами; многие популярные уже с разборами в хранилище (Semgrep, Bandit, Trivy-подобные SCA, Burp, Metasploit и т.д.).

> [!warning] Право
> В каталоге есть и наступательные инструменты — применять только по своим/авторизованным целям (ст. 272 УК РФ).
