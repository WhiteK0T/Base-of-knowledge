# 🗂️ Awesome-Hacking (Hack with GitHub) — мета-коллекция awesome-списков

**Awesome-Hacking** ([github.com/Hack-with-Github/Awesome-Hacking](https://github.com/Hack-with-Github/Awesome-Hacking), **CC0-1.0**, ~122k★, с 2016, живой) — не список инструментов, а **список списков**: единая точка входа к десяткам тематических awesome-репозиториев по хакингу, пентесту и ИБ. Ведёт проект **Hack with GitHub**. Один из самых авторитетных навигаторов в теме (122k★, 10k+ форков).

> [!note] Это каталог каталогов
> Внутри — ссылки на отдельные awesome-списки по направлениям, а не сами инструменты. Ты заходишь, выбираешь тему → попадаешь в профильный список → оттуда к инструментам. Удобно, когда не знаешь, с чего начать по конкретной области.

## 📂 Что внутри (направления)

Ссылки на профильные awesome-репозитории, среди них:
- **Awesome Hacking Resources**, **Awesome Pentest**, **Awesome Web Hacking**;
- **Awesome Malware Analysis**, **Awesome Incident Response**, **Awesome Forensics**;
- **Awesome Threat Intelligence**, **Awesome Honeypots**, **Awesome Fuzzing**;
- **Awesome CTF**, **Awesome Hacking Tools**, **Awesome Android/iOS Security**, **Awesome Vehicle Security** и др.

Плюс у Hack with GitHub есть сайт-портал, Telegram/соцсети с подборками — но ядро ценности именно в этом репозитории-навигаторе.

## 🧭 Как пользоваться

- Нужна **область целиком** («с чего начать по форензике/фаззингу») → сюда, выбрать профильный список.
- Нужен **конкретный инструмент под задачу** → быстрее [awesome-security (sbilly)](awesome-security%20%28sbilly%29%20%E2%80%94%20%D0%BA%D1%83%D1%80%D0%B8%D1%80%D1%83%D0%B5%D0%BC%D1%8B%D0%B9%20%D0%BA%D0%B0%D1%82%D0%B0%D0%BB%D0%BE%D0%B3%20security-%D0%B8%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BC%D0%B5%D0%BD%D1%82%D0%BE%D0%B2%20%D0%BF%D0%BE%20%D0%BA%D0%B0%D1%82%D0%B5%D0%B3%D0%BE%D1%80%D0%B8%D1%8F%D0%BC.md) (там инструменты по категориям напрямую).
- Как у любого awesome-списка — **часть вложенных списков стареет**, проверять актуальность по звёздам/дате.

На системах владельца ставить нечего — контент: читать на GitHub или `git clone` для офлайн-копии.
