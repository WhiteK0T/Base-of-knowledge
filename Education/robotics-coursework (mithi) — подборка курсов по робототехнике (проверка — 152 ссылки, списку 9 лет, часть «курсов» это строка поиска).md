# robotics-coursework — подборка курсов по робототехнике

Пост подаёт это как «на GitHub выкинули **все** курсы MIT, Стэнфорд, CMU и других мировых вузов». На деле это **компактный курируемый список на 152 ссылки**, которому **девять лет**, — и он от этого не хуже, просто это другая вещь.

Проверено 09.09.2026: скачаны все файлы репозитория, посчитаны ссылки, каждая из 152 проверена на доступность.

## Что из этого ставить на свои системы

Сам список — это текст на GitHub, ОС для него роли не играет. Практическая часть упирается в **ROS 2**, а вот с ним по системам всё по-разному.

**Debian / Ubuntu — единственный по-настоящему поддерживаемый путь.** Официальный репозиторий `packages.ros.org` собирает пакеты для Ubuntu (`jammy`, `noble` и новее) и Debian (`bookworm`, `trixie`):

```bash
sudo apt install software-properties-common curl -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
    -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
    http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) main" \
    | sudo tee /etc/apt/sources.list.d/ros2.list
sudo apt update && sudo apt install ros-jazzy-desktop
```

Актуальные LTS-дистрибутивы ROS 2 — **Humble Hawksbill** (Ubuntu 22.04) и **Jazzy Jalisco** (Ubuntu 24.04), плюс **Kilted Kaiju** и роллинг **Rolling Ridley**.

**Gentoo — есть оверлей, но он несвежий.** [`ros-overlay`](https://github.com/ros/ros-overlay) зарегистрирован в официальном списке репозиториев Gentoo, но **последний коммит — 04.06.2024**, больше двух лет назад:

```bash
sudo emerge --ask app-eselect/eselect-repository
sudo eselect repository enable ros-overlay
sudo emaint sync -r ros-overlay
```

Учитывая возраст оверлея и то, что на Gentoo всё собирается из исходников, для ROS 2 надёжнее сборка из исходников по официальной инструкции (`colcon`) либо контейнер с Debian-образом. Проверьте состояние оверлея перед тем, как закладываться на него.

**Arch — только AUR, и тонко.** В официальных репозиториях ROS 2 нет; в AUR 320 совпадений по запросу `ros2`, но популярность низкая (`ros2-humble` — 8 голосов, `ros2-arch-deps` — 6). Это значит мало кто их чинит:

```bash
yay -S ros2-humble        # готовьтесь чинить сборку руками
```

Для Arch практичнее либо `distrobox`/`docker` с Ubuntu-образом, либо сборка из исходников.

**Entware / ASUS RT-AX56U — неприменимо.** ROS 2 на armv7 с 512 МБ ОЗУ и 256 МБ флеша не живёт, десктопных пакетов в репозитории Entware нет. Роутер здесь ни при чём.

Для симуляции без железа хватит Gazebo или Webots в контейнере — учебные курсы из списка почти все рассчитаны на симулятор, а не на реальный манипулятор.
